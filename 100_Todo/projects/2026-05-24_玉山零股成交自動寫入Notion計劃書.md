# 玉山證券零股成交通知 → 自動寫入 Notion 計劃書

> 初版：2026-05-24

---

## 一、目標

收到玉山證券零股成交通知 Email 後，自動解析成交資料並寫入 Notion 台股個股成交明細資料庫，不需手動輸入。

---

## 二、流程架構

```
玉山證券成交通知 Email
        ↓
  Gmail MCP 掃描
  (搜尋條件：寄件人 + 關鍵字「成交」)
        ↓
  解析信件內容
  (股票代號、名稱、買賣別、成交股數、成交價、手續費、交割金額)
        ↓
  重複檢查
  (Notion 查詢是否已存在同一筆成交)
        ↓
  寫入 Notion 台股個股成交明細
        ↓
  在 Gmail 加上「已匯入Notion」標籤
```

---

## 三、觸發方式

| 選項 | 說明 | 推薦 |
|------|------|------|
| `/schedule` cron 每日定時掃描 | 每天固定時間（如早上 9:00）掃描昨日未處理信件 | ✅ 推薦 |
| 手動觸發 Skill | 需要時自己呼叫 `/零股入帳` | 備選 |

推薦每日 cron，零股成交通常隔日結算，早上掃描正好對應前一日。

---

## 四、Gmail 搜尋條件（待確認）

需執行前先確認玉山證券通知信的：
- **寄件人 email**（e.g. `noreply@esunbank.com.tw` 或類似）
- **信件主旨關鍵字**（e.g. 「零股成交」「委託成交通知」）

確認方式：請提供一封實際收到的玉山成交通知信截圖或轉寄。

---

## 五、解析欄位（目標）

| 欄位 | 說明 |
|------|------|
| 成交日期 | YYYY-MM-DD |
| 股票代號 | e.g. 2330 |
| 股票名稱 | e.g. 台積電 |
| 買賣別 | 買進 / 賣出 |
| 成交股數 | 零股張數（股） |
| 成交價格 | 元/股 |
| 成交金額 | 股數 × 成交價 |
| 手續費 | 元（含折扣後） |
| 交割金額 | 實際入/出帳金額 |
| 備註 | e.g. 零股定期定額 |

## 七、防重複機制

每次寫入前先查詢 Notion：
- 條件：`成交日期` + `股票代號` + `成交股數` + `成交價格` 全部相符 → 視為重複，跳過
- 防止重跑 cron 造成重複建立

---

## 八、實作步驟（確認資料後執行）

1. **確認玉山信件格式** — 提供一封實際信件
2. **確認 Notion 資料庫 ID 與欄位**
3. **建立 Gmail 標籤** `已匯入Notion`
4. **撰寫解析腳本**（Node.js 或 Python）
5. **測試單筆寫入**
6. **設定每日 cron**（`/schedule`）
7. **建立 Skill `/零股入帳`** 供手動補跑
