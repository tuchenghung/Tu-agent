# 報價建檔、單價分析、入庫與新案引用規則

2026-09-10 v0.1｜方案設計稿。對應 D01、D02、P05、N04。收尾更新：三份既有Skill及共用分析reference已按本稿整合；正式Notion schema、Excel、網站未改，實檔端到端驗收待做。下列舊Skill清單保留作修改依據。

## 核心流程

收到報價 → 原檔與版次辨識 → 逐項轉錄及驗算 → 規格／範圍與單價分析 → 原報價及分析入庫 → 新案按條件查價 → 留下採用依據 → 填內部成本 → 使用者核定對外售價。

採用、未採用、待決定的廠商均走分析及入庫；只有明確選定的報價才另轉發包。入庫不代表已驗證、可直接配價或已發包。公司記帳只處理 YASHI／YUSHI；宏祐報價、施工與價格參考可共用工程流程，但不進公司帳本。

## 現況證據

唯讀查詢 [工程報價資料庫](https://app.notion.com/p/a1e36c9ff0844965ac7633e51e53f711) 的 data source `e337fcbc-6bec-4415-be89-200682bda5a1`：本次 SQL 可見資料共 2,105 筆；單價空值 2、單位空值 1、案件 relation 為空 356、文件 relation 為空 104。缺漏可能重疊，不加總為問題筆數；不涵蓋封存資料或未開放內容。缺文件關聯不代表原檔遺失，仍須查頁面正文。

5筆初步樣本見「樘／組／M／式」；有些品項名稱內含尺寸，獨立規格欄為空。不能只按品名相似配價，也不能把「式」的總包價直接換成面積單價。此抽樣不代表全庫分布。

現有欄位可保留：供應商、案件、文件關聯、品名、規格、單位、數量、單價、工種、日期、行情評估。尚缺結構化版次、價格類型、稅基、包含／除外範圍、分析依據及查價採用紀錄。

## 每一步的輸入、輸出與完成條件

| 步驟 | 輸入 | 輸出 | 完成條件 |
|---|---|---|---|
| 1 身分與歸檔 | 原檔、廠商、案件／集團、報價日期 | 原檔識別、文件頁、版次與歸檔路徑 | 核對案件ID、複製原檔且不覆蓋；案件未知可暫存但禁止標可採用 |
| 2 逐項轉錄 | 文件每頁／表格 | 原項次、原文、數量、單位、單價、原複價 | 每列可回到頁碼或工作表／儲存格；含零價、未報價與小計列分類 |
| 3 驗算 | 原明細、折讓、稅額與總額 | 重算值、原值、差額、疑點 | 不把重算值覆寫原文；無法辨明折讓或計量時標待確認 |
| 4 單價分析 | 本列、圖說／規範及可比歷史 | 可比條件、價格依據、分析結論、工料拆解狀態 | 每列完成分析紀錄；資料不足也有原因，不以「合理」代替依據 |
| 5 入庫 | 原報價、逐項分析、來源 | 文件與價格明細關聯、分析報告、待補清單 | 讀回核對筆數、關聯、數值與原檔；部分失敗記錄可重續 |
| 6 新案查價 | 新案規格、計量與施工條件 | 候選價格及差異清單 | 排除不可比及來源不足資料，不用最低價或平均價自動定成本 |
| 7 採用與填成本 | 合格候選／已確認調整 | 新案採用紀錄、成本區、來源映射 | 原紀錄不變；可追溯舊案來源、採用當時價格與調整 |
| 8 對外報價 | 成本清單、核定售價 | 業主版報價單 | 售價由使用者核定；檢查輸出不含內部成本與分析註記 |

## 單價分析的粒度

**所有品項必做基礎分析**：核對數量×單價、計量單位、規格、稅別、供料／安裝／運輸／清運等範圍、報價時點與來源；查有無可比價並記錄結論。不能只比較整份總額。

**工料拆解**另記完成／部分／缺依據：有材料用量、人工工時／生產率、機具及其他成本依據才數值化拆解；只有連工帶料總價時保留整體單價，不能為湊成四類而編分攤。使用者確認的估算可另存為「核定估算」，不偽裝成廠商實報。

每單位分析成本＝有依據的材料用量×材料單價＋工時×工時單價＋機具用量×費率＋有來源的其他成本。各項皆須記單位、算式及來源。損耗、運輸、管理費若已包含不得重複加；缺值為未知，不當0。差額獨立保留，不用雜項吸收。

## 建議資料模型：保留原庫、逐步補齊

| 邏輯資料 | 存放建議 | 最少新增資訊 |
|---|---|---|
| 報價文件／版本 | 沿用工作文件中心；每個實際版次一筆文件紀錄 | 報價識別、版次、原檔雜湊、供應商、Projects、來源日期、前版、分析狀態 |
| 歷史價格明細 | 沿用工程報價庫 | 文件版次ID＋原行識別、價格類型、幣別、稅基／稅率依據、原文與標準化單位、規格鍵、範圍、來源定位、可引用狀態 |
| 單價分析 | 初期存價格頁正文的固定章節＋報告檔 | 依據、計算、比較來源、差異、工料拆解狀態、待補事項；有結構化運算需要才設分析子表 |
| 新案成本採用紀錄 | 後續獨立明細表或報價工作底稿，不能放回來源價格覆寫 | 目標案件／工項／數量、來源價格ID與版本快照、調整項及依據、採用成本、核定人／日期、Excel位置 |
| 工項與計量規則 | 從實案逐步建立共用規則表 | 工項碼、必要規格、單位、圖面算量方式、包含／除外範圍、規則版本 |

欄位實體化前另做schema差異及既有使用位置核對。不要一次複製全庫另建平行資料。舊價格保持原資料類型，沒有證據不得批次標「成交價」。

同一供應商、同日可能有多案或多版；既有「廠商簡稱＋日期＋序號」只是顯示編號，不當唯一鍵。建議用文件版次ID＋原始行識別＋價格類型辨識；內容指紋和operationId輔助查重。相同檔案跨案引用保留各案情境，不因雜湊一致自動併成同案。

原報價、議價成交、分析估算、業主售價分開，互不覆寫。整包議價無逐項分配依據時只留總額成交事件，不按比例捏造逐項成交單價。

## 查價與採用規則

| 等級 | 條件 | 處理 |
|---|---|---|
| 可直接引用 | 規格／計量／稅基／範圍一致，日期、数量級及施工條件適用，有可追溯來源 | 填成本候選與來源，不需每次重詢價；列入整份成本核對 |
| 可調整引用 | 差異明確，且換算或成本調整有依據 | 留原值、調整算式與依據；調整後屬新案估算，不改來源價 |
| 僅供比較 | 有來源但範圍、數量條件、價格時效或分析依據不完整 | 顯示差異與待補欄位，不自動填正式成本 |
| 待補詢價／資料 | 新工法、無可比資料、重大未知條件 | 僅針對缺口詢價；可繼續其他有依據工項，不等待整案 |

硬性核對：材質／品牌型號／厚度／性能、尺寸、施作高度、地點及進場條件、數量級、供料或含安裝、保固、含未稅及有效期限。各工種有不同必要欄位，不能用共同的模糊分數取代。

沒有统一的「半年失效」或「舊價加10%」預設。原報價有期限即遵循；其他依工種波動與實案規則制定。先顯示日期及新案差異，時效不確定標待核對，不自動要求所有舊價重詢。

未採用報價不是無效價格；品質、範圍與來源確認後可作參考。曾成交也不保證可直接用於不同尺寸或新施工條件。沒有理由不擅填未採用原因。

## 拆項與拆數量

先以「空間／區域 → 構件／系統 → 工項」列工項清單，每個量取紀錄保存圖號、版次、位置、尺寸來源、單位、算式、扣除項、重複計數與待確認項。圖面標註矛盾先列差異，不由AI渲染或像素猜尺寸。

重複工項套用經案例確認的組合清單與計量規則；使用者只需核對差異、例外及成果。尚未取得一般案件完整圖面＋最終報價範例，現階段不能宣稱自動算量已完成。

## 公共標單與一般草稿分流

- **公共工程正式標單**：原項次、品名、規格、單位、數量及輸出結構保持；成本以實際非列印區映射，不假設一律H–L。廠商多報項目存成本補充表；漏項標未報價，不清空標單。合包報價用對照表連多列，不把全額重複塞入各列；無拆價依據不平均攤單價。
- **一般工程自製草稿**：只有確認是可重編草稿的區塊，才按實際範圍增刪工項；廠商數量、設計算量及對外數量各自留來源，不直接用廠商數量覆蓋設計量。
- 兩者均先核對即時版次與公式、合併格、列高、列印範圍、隱藏欄、跨表引用；以副本操作及差異清單驗證。不要用簡單字串替換全表公式處理插列。未改售價欄但改了數量仍會改總價，不得回報「對外報價未動」。

## 舊 Skill 待修正清單

1. 報價主入口仍偏重未採用者的分析分支：改為所有廠商逐項分析入庫；三種採用狀態與分析狀態分開。
2. 契約分析允許無來源反推、機具固定10%、雜項吸差：不能作通用規則；有特定案例授權時只保留該例方法與限制。
3. 預算填表允許重寫／清空原列並同步廠商數量到報價欄：限明確可重編的一般草稿；不得套用公共標單。
4. 「案件relation必填」又容許空白：統一為可暫存待補、不標正式完成或可採用；不按最接近案名錯掛。
5. 原價、驗算價、議價後價和售價不得混寫。稅別未知、原總額有差異均保留疑點，不能只宣布自行重算為正式報價。
6. 授權完整批次匯入／分析／入庫後不逐項例行詢問；遇關鍵歧義只暫停相關品項，保留其他可完成成果。此次設計工作不等於匯入任何實際報價。

## 驗收案例（設計，尚未跑實檔）

| 情境 | 預期 |
|---|---|
| 同案三家，其中一家採用 | 三家原始明細與分析均保存；只有選定範圍轉發包 |
| 同檔重送／逾時續跑 | 沿用同版ID，核對已建結果，只補未完成步驟 |
| 同廠同日第二版 | 新版保留舊版；查價預設顯示可用最新版但可回看歷史 |
| 原算術差異／整包折讓 | 原值不改；差額或折讓另記，不捏造成交明細 |
| 只有連工帶料總價 | 保留整體價格；工料拆解標缺依據，不填固定比例 |
| 同名不同材質／每式對每平方公尺 | 不自動匹配，不推算未知工程量 |
| 未採用且價格偏高 | 保留、分析；不臆測未採用原因 |
| 公共標單漏項／廠商合報 | 標單原列不刪，漏項非0，合包不重複算 |
| 新案引用歷史價 | 新案採用紀錄有来源快照與調整依據，舊案原價不變 |
| 宏祐案件報價 | 可分析入共用參考庫；不產生YUSHI記帳分錄 |
