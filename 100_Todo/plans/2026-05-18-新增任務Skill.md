# 新增任務 Skill（Notion 行動任務庫）

> 建立時間：2026-05-18
> 類型：新功能
> 狀態：待執行

## 你要做的事（一句話版）
輸入 `/新增任務`，AI 互動問答後自動在 Notion Tasks（行動任務庫）建立一筆任務記錄。

## 背景和動機
目前 Notion 的 Tasks（行動任務庫）需要手動開啟 Notion 才能新增任務，步驟繁瑣。
透過 Skill 可在 Claude Code 對話中直接新增，並自動關聯 Project。

## 具體步驟

### Step 1：問任務名稱（必填）
用 `AskUserQuestion` 提示：「這個任務叫什麼名稱？」
- 純文字輸入

### Step 2：問優先級（必填）
用 `AskUserQuestion` 選擇：
- 高 / 中 / 低
- 緊急重要 / 緊急不重要 / 不緊急重要 / 不緊急不重要

### Step 3：問 Deadline（必填）
用 `AskUserQuestion`：「截止日期是？（YYYY-MM-DD，或選「不設定」）」
- 選項：今天 / 本週五 / 自訂 / 不設定

### Step 4：搜尋並關聯 Project（選填）
呼叫 `mcp__notion-win__API-post-search`，搜尋 Projects 資料庫：
```
filter: { "value": "page", "property": "object" }
query: ""（取最近 10 個進行中專案）
```
用 `AskUserQuestion` 列出搜尋結果讓使用者選，選項末尾加「不關聯」。

### Step 5：問備註（選填）
用 `AskUserQuestion`：「有備註要加嗎？（可跳過）」
- 選項：「不用」 / 「我自己輸入」

### Step 6：建立 Notion Task
呼叫 `mcp__notion-win__API-post-page`：
```json
{
  "parent": { "database_id": "f1dc0829-774c-493a-aa21-eefc6e35b034" },
  "properties": {
    "任務": { "title": [{ "text": { "content": "$TASK_NAME" } }] },
    "優先級": { "select": { "name": "$PRIORITY" } },
    "狀態": { "status": { "name": "待處理" } },
    "Deadline": { "date": { "start": "$DEADLINE" } },
    "負責人": { "people": [{ "id": "261d872b-594c-8188-8718-000252a44fde" }] },
    "Project": { "relation": [{ "id": "$PROJECT_PAGE_ID" }] },
    "備註": { "rich_text": [{ "text": { "content": "$NOTE" } }] }
  }
}
```
- 若未設定 Deadline：省略該欄位
- 若未關聯 Project：省略 Project 欄位
- 若無備註：省略備註欄位

### Step 7：輸出確認
```
✅ 已建立任務：「$TASK_NAME」
優先級：$PRIORITY｜Deadline：$DEADLINE｜關聯：$PROJECT_NAME
→ https://www.notion.so/$PAGE_ID
```

## 預計成果
- 輸入 `/新增任務` 後，約 5 步互動完成新增
- 自動設定負責人為政宏（預設）
- 狀態預設「待處理」

## 不包含在這次的範圍
- 修改或刪除現有 Task
- 查詢任務清單
- 設定預估工作天（之後可加）

## 可能遇到的風險
- Project 搜尋結果太多（超過 10 筆）：取最近編輯的 5 個進行中專案即可
- Deadline 格式錯誤：若使用者輸入不合格式，AI 自動修正為 YYYY-MM-DD
