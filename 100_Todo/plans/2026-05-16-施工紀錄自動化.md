# 施工紀錄自動化工作流（/site-record）

> 建立時間：2026-05-16 14:50
> 類型：新功能
> 狀態：待執行

## 你要做的事（一句話版）
現場拍照存 Dropbox → 告訴 Claude 資料夾路徑 → Claude 自動建 Notion 施工紀錄頁面（含照片 + AI 說明）

## 背景和動機
工地現場巡查後需要整理施工紀錄，目前照片散落各處、說明需手動輸入、Notion 建檔耗時。
希望一個指令完成：照片整理 → Notion 頁面 → 可對外分享。

## 具體步驟

### Step 1：你做的事（30 秒）
- 做什麼：現場拍照（iPhone Dropbox 自動同步），在 Claude 輸入 `/site-record 資料夾路徑`
- 產出：Claude 知道要處理哪些照片
- 注意：照片需先同步到 Dropbox 才能讀取

### Step 2：Claude 掃描並分析照片
- 做什麼：讀取資料夾內所有圖片，AI 分析每張照片生成說明
- 產出：照片清單 + 草稿說明文字（供你確認）
- 注意：說明文字你可以在確認步驟修改

### Step 3：取得 Dropbox 公開連結
- 做什麼：呼叫 Dropbox API，為每張照片取得 `dl=1` 直接連結
- 產出：可嵌入 Notion 的圖片 URL 清單
- 注意：需要 Dropbox API token（已有 `dropbox_notion_links.mjs` 可參考）

### Step 4：在 Notion 建立施工紀錄頁面
- 做什麼：在「案件施工紀錄」資料庫建新頁面，照片每 6 張一組排列
- 產出：Notion 頁面（含標題、基本資訊、照片格）
- 注意：需先取得「案件施工紀錄」資料庫 ID

## Notion 頁面格式

```
[ 案件名稱 ] — YYYY-MM-DD 施工紀錄

紀錄日期 / 工項 / 位置 / 追蹤項目

---
📸 第一組（1-6 張）
[圖] 說明文字    [圖] 說明文字    [圖] 說明文字
[圖] 說明文字    [圖] 說明文字    [圖] 說明文字
---
📸 第二組（7-12 張）...
```

## 預計成果
- 一個指令完成施工紀錄建立（含照片）
- Notion 頁面可直接分享給客戶或存檔
- 照片 AI 說明省去手動輸入時間

## 不包含在這次的範圍
- 手機直接拍照觸發（需額外 App）
- PDF 匯出（日後可擴充）

## 可能遇到的風險
- Dropbox 公開連結失效：使用 dl=1 參數的直接連結，長期有效
- 案件施工紀錄資料庫 ID：執行前需先從 Notion URL 取得
- 照片數量過多（>30 張）：分批處理，每次最多 12 張

## 執行前準備
- [ ] 從 Notion URL 取得「案件施工紀錄」資料庫 ID
- [ ] 確認 Dropbox API token 有效（Settings → OAuth 2 → Generate）
