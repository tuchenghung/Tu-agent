# 請購開單 Skill

> 建立時間：2026-05-20
> 類型：新功能
> 狀態：完成

## 你要做的事（一句話版）

輸入 `/請購開單`，自動找到 Dropbox 專案資料夾、複製最新請購單為範本並改名、填好基本欄位讓你謄寫品項內容；你完成後告訴 AI，自動輸出 PDF。

---

## 流程（確認版）

### Step 1：找到專案資料夾
- 問使用者「哪個專案」（關鍵字）
- 掃描 `D:\Dropbox\宏祐` 和 `D:\Dropbox\yushi`，找出對應資料夾
- 多個結果時讓使用者選擇

### Step 2：複製最新請購單並命名
- 進入 `P請購單/`，找日期最新的子資料夾
- 問使用者：「新請購單資料夾要叫什麼名稱？」
  - 預設建議：`YYYYMMDD{施工項目}請購單`
- 將最新資料夾整個複製 → 改名為新名稱
- 把複製來的舊 PDF、舊填好的 xlsx 刪除（只保留空白 xlsx）
- 將空白 xlsx 改名為與新資料夾相同名稱（例：`20260520機電請購單.xlsx`）
- 確保 `廠商報價/` 子資料夾存在，若有舊檔案一併清除
- 詢問使用者：「是否要將報價單放入廠商報價資料夾？」，若是則請使用者提供檔案路徑並複製進去

### Step 3：收集開單資料並填入 Excel
問使用者以下資訊：
- 施工項目／工種（例：機電、空調、木作）
- 預算金額
- 預算項目
- 廠商保固年限
- 建議廠商名稱

用 PowerShell Excel COM 填入（固定 cell 位址）：
| Cell | 欄位 | 填入內容 |
|------|------|---------|
| C1 | 提出日期 | 今天日期 |
| L3 | 工程種類 | 施工項目 |
| N3 | 預算金額 | 使用者輸入 |
| N4 | 預算項目 | 使用者輸入 |
| N5 | 廠商保固 | 使用者輸入 |
| N8 | 建議廠商 | 使用者輸入 |

填完後通知使用者：「請開啟 Excel 謄寫品項內容，完成後告訴我」

### Step 4：使用者確認 → 輸出 PDF → 開啟新郵件
- 使用者回覆完成
- PowerShell Excel COM 開啟 xlsx，匯出同名 PDF 到同一資料夾
- 回報 PDF 完整路徑
- PowerShell Outlook COM 自動開啟新郵件視窗，預填：
  - **收件者**：陳岱妤; 黃婉姍
  - **副本**：游勝基; 鄭至男; 楊芳瑜
  - **主旨**：`{案件名稱}{施工項目}請購單`
  - **內文**：空白
  - **附件**：剛匯出的請購單 PDF + Step 2 放入廠商報價資料夾的報價單（若有）
- 郵件視窗停在 Display()（不自動送出），由使用者確認後手動按傳送

---

## 不包含

- Notion 請購單紀錄
- 自動填入客戶名稱/內部案號（留給使用者填）
- 自動傳送 Email（只開視窗，由使用者手動按傳送）
- 請購狀態資料夾重命名（已發包/已驗收）

---

## 風險

| 風險 | 處理 |
|------|------|
| 找不到 P請購單 資料夾 | 提示使用者確認路徑 |
| Excel 欄位位置跑掉（不同版本） | 用欄位標頭文字搜尋定位，不用固定 cell |
| Excel COM 被佔用 | 提示使用者關閉其他 Excel 視窗 |
