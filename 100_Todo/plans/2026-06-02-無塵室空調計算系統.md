## 核心計算邏輯（已確認的基準值）

### 換氣次數（ACH）by 潔淨等級
| 等級 | Fed Std | ISO | ACH (次/hr) |
|------|---------|-----|------------|
| Class 100 | M3.5 | ISO 5 | 240–480 |
| Class 1,000 | M4.5 | ISO 6 | 150–240 |
| Class 10,000 | M5.5 | ISO 7 | 60–90 |
| Class 100,000 | M6.5 | ISO 8 | 10–25 |

### 風量公式
- **正壓風量**（MAU 需求）= 體積(m³) × ACH_正壓(5~10次) ÷ 60 → CMH
- **循環風量**（RCU/FFU）= 體積(m³) × ACH ÷ 60 → CMH
- **FFU 數量** = 循環風量 ÷ 單台 FFU 風量（~900 CMH）

### 冷凍噸換算
- 一般空調：1 RT ≈ 5坪（3.3 m²/坪 → 16.5 m²/RT）
- C/R-10K：參差因數 0.8
- 冰水流量：2.4 GPM/RT；冷卻水：3 GPM/RT

### 造價基準（成本未稅）
| 項目 | 單位造價 | 備註 |
|------|---------|------|
| MEP（主機+配管） | 1 RT = 30,000 | 含冰機/泵浦/水塔/變頻/保溫/監控 |
| 一般空調 | 1 m² = 2,000 | 含 FCU/AHU 風管/配電/水管 |
| C/R-10K | 1 RT = 22,500 | RCU+MAU 系統；不含一般/有機排氣 |
| FFU 設備 | 13,000/台 | 成本 10,000/台 |
| FFU 安裝 | 1,200/台 | |
| MAU 10RT 5400CMH | 275,000/台 | |
| 風管製作安裝 | 1,050/m² | |
| 風管保溫 | 500/m² | |

### 管徑選用（冰水管）
| 管徑 | USRT |
|------|------|
| 1-1/4" | 4~7 RT |
| 1-1/2" | 8~11 RT |

## 具體步驟

### Step 1：建立 Python 環境與專案結構
- 做什麼：建立 `/Users/tuzhenghong/Library/CloudStorage/Dropbox/Tu-agent/000_Agent/tools/cleanroom-hvac/` 資料夾，安裝 `streamlit`, `pandas`, `openpyxl`
- 產出：`requirements.txt`、可執行的 `app.py` 骨架

### Step 2：建立計算核心模組 `calculations.py`
- 做什麼：實作所有公式（ACH → 風量 → RT → 管徑 → 造價），以 dict 查表方式實現（方便更新）
- 產出：`calculations.py`，可 import 的純函式模組
- 注意：**公式與數字要加來源備註**（哪張表哪個欄位）

### Step 3：建立 Streamlit 介面 `app.py`
介面分 3 個 Tab：

**Tab 1：基本輸入**
- 空間面積（坪/m²，可切換）
- 天花高度（m）
- 潔淨等級（Class 100/1000/10000/100000）
- 系統型式（MAU+RCU / AHU全頂送 / FFU循環 / D/C / FCU / 混合）
- 設備發熱量（KW，可留空用預設值）

**Tab 2：計算結果**
- 換氣次數（ACH）
- 循環風量 + 正壓風量（CMH）
- FFU 台數（FFU 系統適用）
- MAU/AHU 冷凍噸需求
- 冰水主機 RT 需求
- 建議冰水管/冷卻水管管徑
- 估算風管面積（m²）

**Tab 3：造價估算**
- 依系統型式套用造價基準
- 設備費 / 安裝費 / 風管費 / 水管費 分項
- 總造價（成本）+ 建議售價（×1.3）
- 一鍵匯出 Excel 報告

### Step 4：嵌入參考資料查表

- 產出：測試截圖 + 驗算筆記

### Step 6：加入啟動快捷方式

## 可能遇到的風險
- **ACH 基準值差異**：不同廠規或業主規範可能要求更高 ACH → 介面加「自訂 ACH 覆蓋」欄位
- **造價資料時效性**：博訊龍潭廠為 2025/02 資料，物價有波動 → 加浮動係數調整功能
- **Streamlit 版本相容**：Mac M3 Pro 上 Python 3.9 vs 3.12 → 先確認 nvm node 版本不衝突
