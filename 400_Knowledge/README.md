# 知識庫 400_Knowledge

跨專案知識沉澱中心。由 Claude Code 自動寫入 + 手動補充。

## 資料夾說明

| 資料夾 | 用途 |
|--------|------|
| `工程/建材規格/` | 岩棉、防火板、吸音材等規格筆記 |
| `工程/工法踩坑/` | 每個工程專案的經驗教訓 |
| `工程/客戶/` | 客戶背景、需求、溝通紀錄 |
| `AI工作流/` | Claude Code 自動寫入的工作摘要 |
| `學習/` | 工具使用心得、個人學習筆記 |

## 寫入規則

- Claude Code 完成重要工作後自動寫摘要到 `AI工作流/`
- 工程踩坑：每個專案結束後由 Claude 整理寫入 `工程/工法踩坑/`
- 建材規格：遇到新規格時隨手記錄到 `工程/建材規格/`
- 檔名格式：`YYYY-MM-DD_主題.md`
