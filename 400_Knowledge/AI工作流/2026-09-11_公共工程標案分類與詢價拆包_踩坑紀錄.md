## 執行中發現的工具陷阱

| 陷阱 | 修正與檢查 |
| --- | --- |
| 全形斜線也造成桌面Excel頁籤修復 | 頁籤以頓號替代斜線，例如「電盤、機電」，S欄仍保留使用者「電盤/機電」文字。需用桌面Excel正常開啟驗證，不能只靠解析套件 |
| 預覽引擎出現#NAME?，但原Excel公式正常 | 不為預覽器擅改原公式。比對原公式，使用桌面Excel檢查實際值與列印；不把錯誤預覽當正式交付 |
| Excel正在使用來源，普通雜湊讀取失敗 | 使用允許共用讀取的方式核對檔案；不擅自關閉使用者Excel，也不把讀取失敗當內容不一致 |
| 只按目錄圖名及少量抽樣推定整份固定頁差 | 逐張核對圖框。實際PDF96為目錄未列的A8-21，PDF97才是A9-01，目錄A9-02未見；新增／缺圖可互相抵銷而總頁數仍相同，不能誤判為A9-01重號。先核對再匯出，未確認檔只留暫存 |
| PDF文字抽取看似缺少章節結尾 | 渲染原頁確認。施工規範PDF627頁實際含「計量與計價」及「本章結束」，是文字抽取漏讀，不能誤報原文缺頁 |
| 規範同章號出現多次 | 不因章號相同就去重。不同專業或版本的01330、01450、12494、13853、15105等按原章界保留 |
| RO專屬規範不在施工規範PDF | 圖說PDF103頁A9-08含RO系統施工規範、設備規格及流程，圖規交互核對，不將未見獨立章當作完全無規範 |

## 以後每次交付的檢查

1. 先讀最新使用者修改版，確認分類基準及已接受的格式，不再套回AI初稿。
2. 比對原檔保留、數值、公式、欄寬、列高、合併格及列印區；核對工項無漏項／重複。
3. 主表、分類頁、圖規包與追蹤表採同一工種基準；跨工種圖面可共用，報價工項不可重複。
4. 圖說及規範按實際PDF頁碼建立對照，包含必要目錄續頁、完整章節與附件；每包附來源。
5. 驗證正式檔可在使用者實際軟體開啟；成果放使用者指定專案位置。
6. 每次新的糾正立即補到此紀錄；穩定通用規則放AGENTS.md，MEMORY.md只留入口，避免同一問題反覆發生。

## 再次糾正：詢價包漏放可填標單
- 使用者指出：只有分類資料，沒有標單，廠商如何填價；要求參照B10的F供應商報價與資料。
- 錯誤做法：把要求拆分圖說與規範作狹義處理，只交PDF與清單，未檢查整個詢價流程是否可操作，也未先查看B10實際詢價包，即宣稱完成。前段149檔只完成圖規部分，不代表可直接使用的完整詢價包。
- 正確做法：每包加入獨立的工種空白標單.xlsx，原項次、名稱、單位、數量、備註、欄寬、列高及列印格式保留；單價欄為可填空白，複價在本檔內計算，不能連到未附的主標單。B10空調、泥作、廣告實檔均有各自空白標單。
- 原因：驗收須以廠商能否開檔填價及回報為準，不以分類數量／PDF檔案數作完成標準。已加入AGENTS.md通用規則。
- 後續檢查：37包逐項核對標單＋圖說＋規範＋來源清單；測試單價123、單價0、清空單價，以及空調數量空白／橫線均保持正確結果；測試值不得儲存進交付檔。

- 本次補正驗收：37份獨立標單／1105工項已存入正式F資料夾；逐格保真、Excel填價及清空、37份代表頁目視均通過，交付雜湊一致，原主檔未改。
