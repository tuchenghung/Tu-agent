## 圖說規範要求（A8-05）

### 耐磨PVC地毯（A色）
| 項目 | 規範值 |
|------|--------|
| 厚度 | ≧2.0mm |
| 規格 | 2M × 20M 捲 |
| 表面處理 | **PUR 防污強化處理** |
| 耐燃性 | CNS 8907，移開火源 5 秒內熄滅 |
| 止滑性 | ≧0.4 |
| 抗菌性 | JIS Z2801 金黃色葡萄球菌 ≧2.0 log |
| 撕裂強度 | ≧35 kgf/cm |
| 抗拉強度 | ≧68 kgf/cm² |
| 可塑劑 | CNS 15138 國家標準 |
| 焊接工法 | **Ø4mm PVC 焊條無縫焊接**（刻溝深度 1.5mm） |

### 耐酸鹼PVC地毯（治療室/汙物室）
| 項目 | 規範值 |
|------|--------|
| 厚度 | ≧2.0mm |
| PVC 含量 | THF 測試 ≧65% |
| 防焰性 | **CNS 7614 防焰一級**（較一般更嚴） |
| 耐藥品性 | 30% 硫酸、30% 雙氧水、優碘 無變化 |
| 防滑性 | 乾燥狀態 ≧0.6 |
| 抗菌性 | JIS Z2801 大腸桿菌、MRSA 有效 |
| 防黴性 | JIS Z2911 無黴菌生長 |

### 施工工法（兩種 PVC 皆適用）
- 底層：RC → **3mm 自平式水泥** → 地板膠 → PVC地毯
- 踢腳：**上牆式無縫踢腳板 10cm（100~130cm 牆毯上牆）**
- 焊接：Ø4mm PVC 焊條無縫焊接
