## 一、審查費：建築師公會法定規費，公式固定、分兩段級距（四案全部驗算吻合）

**100㎡ < 面積 ≤ 500㎡：**
```
圖說審查費 = (面積-100)×25 + 10,000
竣工查驗費 = (面積-100)×30 + 10,000
```

**面積 > 500㎡（500㎡以上級距費率降低）：**
```
圖說審查費 = (面積-500)×20 + 400×25 + 10,000
竣工查驗費 = (面積-500)×25 + 400×30 + 10,000
```
（400×25、400×30 為 100~500㎡ 級距的固定貢獻額）

這部分無議價空間，任何面積都可用公式精確驗算，不必詢價。

---

## 二、代辦費：與面積、是否需變更使用執照關聯性低，本質是「時間別」的固定行情價

四案代辦費淨額：97,612 / 97,869 / 97,919 / 117,163 — **前三案（115.01~115.05）緊密落在 97,600~97,900，與面積(320~546㎡)、是否需辦理使用執照變更皆無關**；僅第四案（115.07.21）跳升至 117,163。

**結論：陳樂屏建築師事務所於 115.05.18～115.07.21 之間調漲代辦費基準，漲幅約 +19,300（+20%），與案件面積或類型無關，純粹是報價時間點的費率調整。**

估價時應優先確認報價開立日期落在哪個費率區間，而非用面積內插估算代辦費。

---

## 三、辦理建築物變更使用執照：固定 150,000（與面積無關）

僅8F、1F兩案有此項，皆為 150,000 平價，未隨面積或時間變動（目前僅2個樣本，若未來出現漲價需更新本表）。

---

## 四、估價公式（供快速套用）

```
總計 = 代辦費(依報價時間點取對應費率) + 審查費小計(依面積公式精確計算) + 使用執照變更費(150,000，若適用)
```

**115.07.21起適用費率（目前應採用）：**
- 代辦費 ≈ 117,163（僅1個樣本，且該樣本為「有使用執照變更」案型；「無使用執照變更＋新費率」尚無實際報價驗證，屬推估，正式報價前建議向事務所確認）
- 使用執照變更（若需要）：+150,000

### 範例：197㎡、無需使用執照變更（2026-08-24詢問案）
- 審查費小計 = (197-100)×25+10,000 + (197-100)×30+10,000 = 12,425+12,910 = **25,335**（精確）
- 代辦費（新費率推估）= **117,163**
- **總計推估 ≈ 142,498**（代辦費部分為推估值，非實際報價）

## 關鍵發現

1. **3F的35,000不是「便宜」，是「半套」**：報價單明載「未含設備及竣工作業」，範圍只到圖審+機關會審就結束，不含竣工查驗/測試報告；S5F、8F則是圖審做到竣工代辦消檢的完整跑照服務，範圍完整度不同，總價不可直接比較。
2. **「圖說會審/設計及簽証」單項隨日期遞增**：25,000(01月)→28,000(06月)→33,000(07月)，方向與陳樂屏建築師代辦費的漲價時間點（115.05~07間）一致，但証安每案消防系統複雜度差異大（8F是全新R型主機大型系統，S5F僅既有系統擴充），訊號不如建築師代辦費乾淨，不能斷定純粹是時間調價還是案件複雜度墊高。
3. **跑照代辦費不含實際消防設備安裝費**：S5F案跑照61,000之外，硬體設備+施工另計約85,000（探測器、廣播喇叭、撒水頭等）；8F案跑照99,000之外，硬體設備+施工另計約1,275,534。硬體費用完全視空間實際消防系統範圍而定，無法用面積內插。

## 197㎡（無使用執照變更）消防跑照估算

最貼近的參考案例：**羅東聖母S5F**（同樣無使用執照變更）純跑照部分 **61,000（未稅）**，可作初估基準；若空間需求接近8F等級（大範圍系統/使用執照變更），應改參考99,000那組。正式報價前建議仍向証安（賴協隆消防師 0972-122-666）取得針對該案的正式跑照報價，硬體設備費用無法套用行情推估。

## 待確認事項（消防部分）

1. 「圖說會審/設計及簽証」單項的漲價是時間因素還是案件複雜度因素，樣本數不足以拆解，需累積更多同類跑照報價驗證。
2. 尚無「無使用執照變更＋大型系統」或「有使用執照變更＋小型系統」的交叉案例，無法排除面積/系統規模對跑照費的影響。
