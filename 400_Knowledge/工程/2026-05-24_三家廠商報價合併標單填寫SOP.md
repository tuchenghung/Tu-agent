# 三家廠商報價合併標單填寫 SOP
> 初版：2026-05-24｜案件：市醫和平院區醫療大樓8樓婦兒科病房整修

---

## 一、適用情境

- 招標前需彙整多家廠商報價、填入空白標單製作「合併版預算底稿」
- 各工種報價來源不同（PDF、XLS、圖片）
- 需保留原始 XLS 格式（顏色、字型、邊框、千分位）

---

## 二、檔案組織規則

### 目錄結構
```
案件資料夾/
├── D預算報價/
│   ├── 08-1_...(空白標單).xls          ← 永遠保留，每次腳本的 SRC
│   └── YYYYMMDD-廠商報價三家合併版.xls  ← 輸出成果，只改此檔
└── 廠商報價/
    ├── YYYYMMDD-廠商簡稱-工種.pdf/.xls/.jpg
    └── ...
```

### 廠商報價檔命名
格式：`YYYYMMDD-工地名稱-工種.副檔名`
- 日期以報價單日期（非收件日）為準
- 工地名稱：本案直接報價可省略（已在資料夾內），跨案借用的參考報價須標明來源工地
- 範例（本案直接報價）：`20260518-明登-地板工程.pdf`
- 範例（跨案借用）：`20211019-台大西址-護士呼叫系統.pdf`、`20240326-同位素病房-護士呼叫系統.jpg`
- 每次用到的報價單都要複製一份到此資料夾存檔

## 三、XLS 填值工具

使用腳本 `000_Agent/scripts/fill-xls-values.py`（保留格式）。

### 關鍵原則
1. **SRC 永遠用原始空白標單**，不得用已填過的版本（xlutils.copy 會把公式轉成靜態值）
2. **DST 是輸出檔**，每次執行直接覆蓋
3. 所有小計行需在 `SUM_ROWS` 字典明確寫入 FormulaCell，xlutils.copy 不會保留公式

### SUM 公式設計
- 子節小計：`SUM(Fstart:Fend)`（Excel row = 0-indexed row + 1）
- 章節總計（避免重複加總）：`Fa+Fb+Fc+...`（明確列出各子節小計格）

## 四、多廠商報價處理邏輯（本案實例）

### 工種與來源對應

| 工種 | 廠商 | 來源格式 | 備註 |
|------|------|----------|------|
| 天花輕隔間木門 | 祺晟工程行 | XLS | 直接讀取 |
| 地板工程 | 明登企業 | PDF | 人工對應 |
| 空調工程 | 一昌冷凍空調 | PDF | 人工對應 |
| 醫療氣體工程 | 巧裕工程（參考羅東聖母案） | XLS | 跨案件借用，15/23 項有對應 |
| 護士呼叫系統 | 丞偉科技 + 台大五西丞瑋發包 PDF | JPG + PDF | 兩者取高值，見下方規則 |

### 護士呼叫系統：雙報價取高值規則

**原則：兩份報價都乘 ×1.1，小數點第一位無條件進位，再取較高者。**

```
price_A = ceil1(丞偉原價 × 1.1)
price_B = ceil1(台大五西PDF原價 × 1.1)
填入值 = max(price_A, price_B)
```

`ceil1(x)` = 小數點第一位無條件進位 → `math.ceil(x * 10) / 10`

本案各項結果（參考值，非絕對）：

| 品項 | 丞偉×1.1 | PDF×1.1 | 填入 |
|------|---------|---------|------|
| 中英文護理站IP對講主機 | 82,500 | 99,000 | 99,000 |
| 電源與信號控制器含周邊 | 8,690 | 無 | 8,690 |
| 床邊呼叫對講盤 | 3,135 | 6,600 | 6,600 |
| 手握呼叫線 | 440 | 660 | 660 |
| 門口燈 | 1,155 | 880 | 1,155 |
| 浴廁呼叫盤 | 1,265 | 1,155 | 1,265 |
| 走道顯示器 | 22,990 | 25,300 | 25,300 |
| PVC管料及配管五金 | 無 | 11,000 | 11,000 |
| 線材與結線五金 | 5,060 | 8,800 | 8,800 |
| 安裝與測試 | 13,200 | 36,300 | 36,300 |

> 注意：丞偉報價單「中英文護理站IP對講主機」拆成兩個品項（呼叫中央控制器＋護理站對講盤機台），需先加總再 ×1.1，對應標單的單一品項。

### 跨案件借用報價（醫療氣體範例）

當本案無廠商報價時，可借用條件相近的舊案報價：
- 確認工程性質相近（同類型醫療院所、同施工廠商）
- 規格可對應的直接套用，規格差異過大的留空由業主補填
- 本案：借用「宜蘭聖母醫院7至9樓病房氣體配管 20250907」，15/23 項有直接對應

## 五、無法匹配的項目處理

- 標記 `# 待補` 並在腳本中 comment out
- 彙整清單告知業主，請業主手動填入
- 本案待補項目示例：
  - 伍.一：區域控制閥箱警報器修飾牆、醫療氣體出口面板、豪華式埋入室氣體出口、各尺寸球塞閥、焊接材料、金屬吊管架（共 8 項）
  - 伍.二：打鑿與復原（1 項）
  - 伍.三：門禁系統（整節，本案未取得報價）

## 六、評估新案時的 Checklist

- [ ] 確認空白標單版本（標案號、版次）
- [ ] 各工種是否有廠商報價？格式（PDF/XLS/JPG）？
- [ ] 是否有可借用的舊案報價（同廠商、同工種、近期）？
- [ ] 報價單價格需加幾趴（利潤空間）？本案：+10%
- [ ] 特殊合項品項確認（如護士呼叫主機拆單情形）
- [ ] 廠商報價日期是否過期（超過 6 個月需再確認）
