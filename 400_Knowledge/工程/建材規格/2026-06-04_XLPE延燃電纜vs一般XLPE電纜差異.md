## 核心差異

**XLPE 是「絕緣材料」；延燃（阻燃）是「耐火性能等級」。**

- **XLPE 電纜** = 以 XLPE 作絕緣的電纜
- **XLPE 延燃電纜** = 在 XLPE 絕緣的基礎上，整條電纜達到阻燃/低煙等防火等級的產品

## 如何從型號/說明書辨別

| 標示 | 意義 |
|------|------|
| 只寫 XLPE / PVC 或 CV | 多半只是 XLPE 絕緣 + PVC 被覆，**未必阻燃** |
| 標 FR、FR-LSZH/LSOH、ZH、LS0H | 有阻燃/低煙無鹵性能 |
| 列 IEC 60332-1/-3、IEC 61034、IEC 60754 | 真正的「延燃/低煙無鹵」電纜 |
| 標 IEC 60331 或 BS 6387（CWZ） | 耐火電纜（消防級） |

## 重要區別

**阻燃（Flame-retardant）≠ 耐火（Fire-resistant）**
- 阻燃：火源移除後自行熄滅
- 耐火：在火場中持續供電（消防用途）

## 工程選用建議

- 一般機房/辦公室走線 → XLPE 延燃（FR 等級）即可
- 消防系統配線 → 必須用耐火電纜（IEC 60331 / BS 6387）
- 無塵室 / 醫療院所 → 建議低煙無鹵（LSZH）型號，避免失火時有毒煙霧
