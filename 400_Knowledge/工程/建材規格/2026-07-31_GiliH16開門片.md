# Gili H16 開門片

## 產品資訊
- 品牌：Gili集力門(GILI DOOR TAIWAN)
- 型號：H16(搭配A16為H16-HA16，搭配D16為H16-HD16)
- 16mm極細框、45度對接，採Kansway緩衝鉸鍊
- 適用玻璃：5-8mm
- 通過10萬次來回開關測試

## 關鍵數據
| 項目 | 數值 |
|------|------|
| 門片寬度 | ≤110 cm |
| 門片高度 | ≤260 cm |
| 單片最大載重 | 60 kg |
| 現場環境規範 | 側落差≤4mm |
| 鋁框料尺寸(門片) | 見立面16mm，厚度40mm |
| 鋁框料尺寸(門斗) | 見立面18-30mm，厚度60mm |
| Kansway緩衝鉸鍊 | ≤80kg |

可搭配水平把手電子鎖。

## 選用判斷
| 需求 | 適合？ |
|------|--------|
| A16/D16連動門系統的開闔式出入門片 | ✅ |
| 需五金鎖具(電子鎖)的出入口 | ✅ |
| 超過110cm寬或260cm高、載重超過60kg | ❌ 應改用連動門系統(A16/F10) |

> [!warning] 施工禁令
> - 單片載重不可超過60kg，超過須改用A16/F10連動門系統

> [!tip] 施工要點
> - 門斗五金安裝須注意結構承重，比照Gili通用施工Q&A規範(RC/木夾板/黑鐵結構)
> - 側落差須控制在4mm內

> [!info] 驗收稽核清單
> - 型號對應是否正確(H16-HA16搭配A16 / H16-HD16搭配D16)
> - 電子鎖等五金是否於下單時確認選配
