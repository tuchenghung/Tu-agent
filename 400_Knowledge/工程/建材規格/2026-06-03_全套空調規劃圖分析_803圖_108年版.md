## 三、水側管線邏輯（配管系統架構）

### 冰水系統（Chilled Water Loop）

```
CH-1/CH-2（冰水主機，EVAP蒸發側）
  ↓ Φ65mm 出水主幹管（CHS，7°C）
  ↓ CHP-1（冰水循環泵，300LPM）→ 送至各末端
  ↓ Φ65mm → Φ50 → Φ40 → Φ32 → Φ25 → Φ20
  ↓ 分配至 AH-1 / PAH-01 冰水盤管
  ↑ Φ65mm 回水主幹管（CHR，12°C）
  → 回 CH-1/CH-2 蒸發側
```

### 冷卻水系統（Condenser Water Loop）

```
CH-1/CH-2（冷凝器 COND，進水37°C）
  ↑ Φ65mm 回水主幹管（CWR）
  ↑ CT-1/CT-2（屋頂冷卻水塔，出水32°C）
  ↑ CWP-1（冷卻水泵，400LPM）
  ↓ Φ65mm 供水主幹管（CWS）→ CH-1/CH-2 COND
```

### 補水系統

```
市政給水（由水電提供）
  → ET-1（FRP膨脹水箱）
  → SPP-1（補給水泵）→ 系統補水注入點
  → Φ20mm 補水管
```

### 管線幾何特性

| 回風管線 | 31 | 14 | 15 | 2 | 4.1m | 各區短回風段 |

### 送風主幹管走向邏輯（實測最長段分析）

```
主幹管一（最長，22m 水平）：
  從空調機房出口 → 沿走廊/天花板水平延伸 22m
  → 供應整層所有 FCU 的主要送風

主幹管二（9.4m 水平）：
  第一分歧點後 → 延伸覆蓋另一翼
  → 45×30cm 方形風管段

主幹管三（8m 水平）：
  另一方向送風分配

垂直主幹（7m 垂直）：
  → 向下分配至各空間分歧點
  → 接 Φ200 / Φ150 螺旋風管分叉

末端（螺旋風管段）：
  Φ200mm → Φ150mm → Φ100mm
  → 保溫軟管 Φ12"/10"/8"/6"
  → FCU 入口
```

### 實務風管配置原則（從本圖提取）

**原則一：主幹正交，斜管≤4%**
- 送風：只有 10/293 條（3.4%）斜管
- 水管：23/209 條（11%）斜管（管件轉接較多）
- **結論：方形主幹管全部走水平/垂直，斜管只用在末端接頭**

**原則二：主幹管沿走廊，分支進房間**
```
走廊天花板：45×30 → 35×30 主幹
  ↓ 每個房間入口分歧
  → Φ200/150 螺旋風管進入各房間天花板
  → 集風箱 → 軟管 → FCU 入口
```

**原則三：送風管與回風管分層**
- 送風管在上層（送風）
- 回風管在下層（空調箱回風）
- 兩者平行但不同高度布置

**原則四：方形風管縮管邏輯**
```
空調機房出口：最大斷面（45×30cm）
→ 第一分歧後縮減：35×30
→ 第二分歧後縮減：25×30
→ 各房間入口：20×30 → 15×25
→ 末端螺旋管：Φ200 → Φ150 → Φ100
→ 軟管：Φ12" → Φ10" → Φ8" → Φ6"
```

**原則五：新鮮外氣管垂直走多**
- 新鮮空氣管垂直段比例高（20/38條）
- 代表外氣取入口在屋頂，**豎管向下接 PAH 進氣口**
- 進機房後改水平：55×30cm 接 PAH-01

### 冰水管主幹走向

```
空調機房（空調箱集中區）：
  CH-1/CH-2 → CHP-1（冰水泵）
  → Φ65mm 水平主幹管（8.4m，機房內最長段）

  Φ50 → Φ40 → Φ32 → Φ25 → Φ20
  沿走廊天花板與送風管並行（同方向、同走向）
```

### 冷卻水系統位置

```
屋頂層（另一座標區域）：
  CT-1, CT-2 位置在屋頂平面
  → 冷卻水管向下穿樓板（垂直管 2.8m/段 重複出現 → 穿樓板立管）
  → 1F 機房 CH-1/CH-2 冷凝側
```

### 水管配置與風管並行原則

- **供/回水管雙管並行**（間距 150~350mm）：圖上成對的水平線
- **水管沿走廊與送風管相同走向**，同路由但不同高度
- 管徑縮減點 = 分歧到各 FCU 水管接頭

## 十二、DDC 控制邏輯（昇位圖文字提取）

```
空調箱 AH-1 控制邏輯：
  1. Timer 控制 AH-1 + PAH-01 聯動啟停
  2. 啟動後：
     風管型溫度感測器 → 感測回風溫濕度（R.A. TS/HS）
     DDC 比較感測值與設定值
     → 偏差量 → 比例積分控制
     → 電子比例式電動三通控制閥 → 調節冰水量
  3. 同步監測送風溫（S.A.）+ 外氣溫（O.A.）

PAH-01（外氣預冷箱）：
  同樣 Timer 連動 AH-1 啟停
  依外氣溫控制冰水盤管開度
```

### DDC 控制閥完整說明（AC-10 施工大樣）

> 原圖文字（逐字記錄）：
> 
> 「1. 風管型溫度感測器感測回風溫濕度，經由 DDC 比較二者感測值與設定值之信號偏差量，  
> 依偏差量控制冰水用電子比例式電動三通控制閥組之冰水量作降溫之功能，  
> 以維持空調區域恆溫需求，**電動三通控制閥組可設定最低開度**。」

### 臥式空調箱基礎台

- 需做**避震基礎台**（混凝土台 + 橡膠避震墊）

- 防震配管：主機出口必配**防震軟管**

### 水管穿牆防火填塞

```
管路穿越防火區劃牆/樓板：
  套管預留（直徑 = 管外徑 + 保溫厚度 × 2 + 餘裕）
  → 套管內填充防火泥
  → 外側以墊底材料收邊
  要求：CNS-14514 認證材料，受火膨脹型
```
