# 鍍鈦板 vs 鍍鈦烤漆（仿鍍鈦漆）材質與單價比較

## 產品資訊
兩種工法皆用於模擬金屬鍍鈦質感，但材質本質、成本、耐用度差異極大。

## 關鍵數據

| 項目 | 鍍鈦板（真材質） | 鍍鈦烤漆（仿鍍鈦漆） |
|------|-----------------|-------------------|
| 工法本質 | PVD真空離子鍍膜於不鏽鋼板表面 | 塗料噴塗模擬鍍鈦金屬光澤 |
| 材料單價 | $800~1,200/才（約$8,700~$13,100/m²） | $3,690~4,200/組（1公升裝），塗布率8~10m²/組，換算約$410~470/m² |
| 使用壽命 | 20年以上 | 塗層薄，遠不及真鍍鈦，長期有掉色磨損風險 |
| 抗鹽霧測試 | 600小時以上（一般304不鏽鋼約400小時） | 無對應數據 |
| 顏色 | 金色、香檳金、古銅、古咖、玫瑰金、黑色 | 香檳金、玫瑰金、古咖、古銅、黑色 |
| 表面質感 | 毛絲面、鏡面、霧珠、亂紋 | 依塗裝工藝，較難達到金屬鍍膜的立體光澤層次 |
| 厚度規格 | 0.3~10mm不鏽鋼板 | 塗層厚度極薄 |

**價差約20~30倍**（真鍍鈦板遠貴於仿鍍鈦漆）。

## 選用判斷

| 需求 | 適合？ |
|------|--------|
| 高濕度區域（浴室/廚房/玄關） | ✅ 鍍鈦板（抗潮不生鏽發霉） |
| 大面積外牆立面、精品櫃體 | ✅ 鍍鈦板 |
| 木作局部裝飾線條 | ✅ 兩者皆可，預算有限選仿鍍鈦漆 |
| 高碰撞磨損區域（如踢腳板、扶手） | ⚠️ 鍍鈦板優先，仿鍍鈦漆長期會掉色磨損 |
| 大量使用整面覆蓋 | ⚠️ 容易顯得俗氣浮誇，建議局部使用或作裝飾線條 |

> [!warning] 選材提醒
> - 仿鍍鈦漆是塗層而非金屬鍍膜，用在高頻碰撞/摩擦區域（如踢腳板）不建議取代真鍍鈦板，長期會有掉色磨損風險
> - 鍍鈦板價格($800-1,200/才)為網路一般行情，非特定廠商官方報價，實際訂購需依規格/顏色/廠商另外詢價
> - 仿鍍鈦漆售價來自美華漆行零售商品頁，非工程包工報價，實際施工另計工資
