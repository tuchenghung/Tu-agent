# 冷凍冷藏庫建置通用知識

> 來源：信天翁嘉義廠 2F 冷凍冷藏庫規劃討論 2026-06-24
> 適用：類似規模大型冷凍冷藏庫工程

---

## 庫板選型

| 芯材 | 用途 | 厚度 | 備注 |
|---|---|---|---|
| PIR 聚異氰脲酸酯 | -20°C 冷凍庫 | **150mm** | 防火較佳，生技廠推薦 |
| PIR | 4°C 冷藏庫 | **100mm** | |
| PU 硬質發泡（密度≥40kg/m³）| 地板隔熱 | **150mm** | 非庫板，專用地板材 |

庫板（壁板型）不能直接當地板，需另用地板隔熱系統。

---

## 地板施工層次（由下往上）

1. 原有 RC 結構樓板
2. 防潮塗料
3. **電熱線**（保護樓板，在隔熱板下方）
4. 硬質 PU 隔熱板 150mm
5. 防潮薄膜（PE 膜）
6. 鋼筋網（#4 雙層）
7. RC 面層 100mm

電熱線放 PU 板下方是為了保護 RC 樓板，不是放上方（放上方等於把熱送進冷凍庫）。

## 防凍裝置：電熱線 vs 架高地板

| | 電熱線 | 架高地板 |
|---|---|---|
| 初期 | NT$75萬（820㎡）| NT$312萬 |
| 10年總計 | NT$245萬 | NT$330萬 |
| 損益平衡 | — | 第15-17年 |
| 淨高影響 | 無 | 損失 350mm |
| 南台灣氣候 | ✅ 最適合 | 過度設計 |

→ 南台灣案子優先推薦電熱線。

## 有效儲存淨高計算

以 2F 樓高 5,000mm 為例：

```
5,000 - 200（頂板）- 300（天花庫板＋吊掛）- 650（冷風機）- 250（地板）= 3,600mm
```

- 冷風機高度：約 500mm
- 冷風機頂部離天花淨距：150mm
- 地板系統：PU 150mm + RC 100mm = 250mm

## 除霜系統

| 庫別 | 方式 | 頻率 | 每次時長 | 融霜結束溫度 | 建議時段 |
|---|---|---|---|---|---|
| -20°C | 電熱融霜 | 每日3次 | 25-30 分鐘 | 蒸發器表面 +8°C | 凌晨2:00、上午10:00、下午4:00 |
| 4°C | 自然停機 | 每日1次 | 20-30 分鐘 | +5°C | 凌晨3:00 |

### 除霜系統組件規格

| 組件 | 規格 | 說明 |
|---|---|---|
| 蒸發器電熱管 | 10 kW/台 | 穿插於鰭片間；3台蒸發器共30kW |
| 滴水盤電熱帶 | 100-200 W/m | 防融霜水在盤內再凍 |
| 排水管電熱帶 | 25-50 W/m | **穿越庫板隔熱段必裝**，否則結冰堵塞 |
| 庫板排水套管 | PP材質＋電熱帶 | 穿越隔熱庫板段 |
| 庫內排水溝 | SUS304 不鏽鋼 | 蒸發器正下方配置 |
| 融霜控制器 | 定時＋溫度感應雙重 | 達設定溫度自動結束融霜 |

### 除霜用電（以3台蒸發器為例）
- 電熱管總功率：30 kW
- 每日運轉：3次 × 30分 = 1.5小時
- 月耗電：約1,350度（佔總用電約3%）
- 融霜期間壓縮機停機，不同時耗電

**必裝（不可省略）：**
- 滴水盤電熱帶（防融霜水再凍）
- 排水管電熱帶（穿越庫板段，否則結冰堵塞）
- 庫板穿孔 PU 發泡密封（防冷橋）

## 冷凍機組配置

### 氣冷式（RF 露天遮雨棚常用）

- 壓縮機：螺桿型，選戶外型 IP54+
- 冷凝器：**V 型**（非 H 型），抗側風
- 電控盤：IP55 戶外防水
- 遮雨棚：四周不封牆（需通風），輕鋼構

### 嘉義/南台灣注意事項

- 東北季風：導流擋板＋排氣朝開放側＋冷凝器間距≥2m
- 颱風錨定：底座預埋螺栓，設計風速≥60 m/s
- 夏季 35°C：壓縮機選型留 10-15% 功率裕度

### 冷媒回油（壓縮機在上、蒸發器在下時）

- 吸氣立管每上升 3-5m 設反 U 型油彎
- 壓縮機加裝油分離器
- 吸氣管流速維持 6-10 m/s（垂直段）

## 用電估算參考值

### 設備單位參考係數

| 設備 | 參考值 |
|---|---|
| 壓縮機 COP（-20°C，氣冷式）| 1.3-1.5 |
| 壓縮機 COP（4°C，氣冷式）| 2.3-2.5 |
| 電熱線（-20°C 庫）| 15 W/㎡ |
| 蒸發器風扇 | 2-3 W/㎡ |
| LED 照明 | 10 W/㎡ |
| 電熱融霜 | 10 kW/台（蒸發器）|

嘉義氣候電熱線使用率：約 40%（年均）

### 實案用電明細（信天翁嘉義廠，1,577㎡，2026-06-24）

壓縮機與電熱融霜**不同時運轉**（融霜期間壓縮機停機），需分情境計算：

**情境A：正常製冷（決定契約容量的主要情境）**

| 設備 | 用電（kW）| 備注 |
|---|---|---|
| 壓縮機（冷凍＋冷藏，夏季修正+15%）| 42.3 | 夏季高溫補償 |
| 氣冷式冷凝器風扇 | 5.0 | |
| 室內冷風機（蒸發器風扇）| 4.0 | |
| 電熱融霜 | 0 | 製冷期間停用 |
| 滴水盤＋排水管電熱帶 | 3.0 | 連續 |
| 電熱線（820㎡防凍脹）| 12.3 | 依溫度啟停 |
| 照明（兩庫，LED）| 15.8 | 依使用率 |
| 控制系統 | 3.0 | 連續 |
| **合計** | **≈ 85 kW** | |

**情境B：融霜期間**（每日3次×30分，壓縮機停機）

| 設備 | 用電（kW）|
|---|---|
| 電熱融霜（3台）| 30.0 |
| 蒸發器風扇＋電熱帶＋電熱線＋照明＋控制 | 38.1 |
| **合計** | **≈ 68 kW** |

→ **實際最大同時用電：約 85 kW（情境A）**

**電力申請建議：150 kVA**
- 85 kW ÷ 0.85 × 1.25 = 125 kVA → 建議申請 **150 kVA**（有 25% 以上裕度）
- 月用電約 40,400 度、月電費約 NT$16-18 萬、年電費約 NT$192-216 萬

⚠️ **常見錯誤**：壓縮機用電 + 電熱融霜直接相加得到 ~110 kW，是錯的——兩者互斥運轉，不能疊加。

## 電力申請

- 大型冷凍冷藏庫（>300㎡）建議申請**高壓（11.4kV）供電**
- 台電高壓申請至通電：約 3-6 個月，工程規劃初期即提出
- 契約容量公式：尖峰需求（含夏季修正）÷ PF(0.85) × 1.25 裕度
- **壓縮機尖峰需加 10-15% 夏季高溫補償**後再套公式，南台灣案不可省略此步驟
