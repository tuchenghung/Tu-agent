## 一、空調箱種類定義

| 縮寫 | 全名 | 功能說明 |
|------|------|---------|
| **PAH** | 小型預冷空調箱 | 僅預冷，不加熱加濕 |
| **AHU** | 空氣調節箱（Air Handling Unit）| 專門處理外氣及室內空氣 |
| **RCU** | 循環空調箱（Recirculation Unit）| 僅處理室內回風，不引入外氣 |
| **MAU** | 外氣空調箱（Make-up Air Unit）| 僅處理外氣，不含回風 |

---

## 二、AHU 設計概念

### MAU 與 AHU 設計核心差異

| 機種 | 設計起點 | 推算方向 |
|------|---------|---------|
| **MAU** | 先算出所需**風量（CMM）** | 再由風量推算盤管噸數（RT） |
| **AHU** | 先算出室內**冷負荷（RT）** | 再由 RT 反推需求風量（CMM） |

> **AHU 主要目的**：冷卻室內溫度。

### AHU 系統三種設計方式

1. **AHU + MAU 分離**：加熱及加濕處理放在 MAU 段，AHU 只負責循環冷卻
2. **AHU 直接引入外氣**：加熱及加濕處理一並放在 AHU 段
3. **AHU 引入外氣 + 熱水盤管**：用於室內無熱負荷或業主無法提出相關資料時，以外氣條件選定熱水盤管

## 三、AHU 風量計算

### 外氣量（OA）計算公式

```
OA（外氣量）= C/R 正壓量 + C/R 內排氣量

C/R 正壓量 = C/R 體積(m³) × 換氣次數(1~2次/hr) ÷ 60 min
```

- **大型無塵室**：正壓換氣次數約 1 次/hr
- **小型無塵室**：正壓換氣次數可能達 2~3 次/hr

### 風量平衡

```
SA（出風量） = OA（外氣量） + RA（回風量）
RA = SA - OA
```

### 換算基準

| 換算 | 數值 |
|------|------|
| 1 RT | = 500 CFM = 850 CMH = **14.17 CMM** |

### 範例計算（74 RT 案例）

```
條件：冷凍能力 74RT，C/R 面積 737m²，高 4M，6" 排氣口共 8 口

SA = 74RT × 14.17 CMM/RT = 1,049 CMM

C/R 正壓量 = 737m² × 4m ÷ 1次 ÷ 60min = 49 CMM

排氣口風量 = π × (0.15/2)² × 5m/s × 60s/min = 21 CMM/口
8 口排氣 = 21 × 8 = 168 CMM

OA = 49 + 168 = 217 CMM（外氣量）
RA = 1,049 - 217 = 832 CMM（回風量）
```

## 四、混風溫度計算

### 公式（一）精確法

```
混風溫度差 = (外氣量 × 外氣溫度 + 回風量 × 回風溫度) ÷ 總風量 - 室溫

混風溫度 = 無塵室需求溫度 - 混風溫度差
```

### 公式（二）簡便估算法（外氣量≈總風量 1/10 時適用）

```
混風溫差 = (外氣溫度 - 室溫) ÷ 10
混風溫度 = 室溫 - 混風溫差
```

**範例**：
```
室溫 22°C、總風量 450 CMM、外氣 36 CMM（約總量 1/10）
外氣溫度 5°C（冬季）

混風溫差 = (22 - 5) ÷ 10 = 1.7°C
混風溫度 = 22 - 1.7 = 20.3°C
```

## 五、熱水盤管噸數計算

```
熱水 RT = CMM × 17.4 × ΔT ÷ 3024
```

- **CMM**：通過盤管的風量
- **ΔT**：盤管進出水溫差（通常取 5~6°C）

---

## 六、加濕量計算

```
加濕量(kg/HR) = (風量CMM ÷ 60) × 空氣密度(1.2 kg/m³) × (出口含濕量 - 入口含濕量)(g/kg) × 3600 ÷ 1000
```

**範例**：
```
(450 ÷ 60 × 1.2 × (8.4 - 7.75) × 3600 ÷ 1000) = 21 kg/HR
```

> 含濕量（g/kg）由空氣狀態圖（h-x 圖）查取。

## 七、AHU 空氣處理過程（夏季）

| 處理段 | 狀態點 | 說明 |
|--------|--------|------|
| 外氣入口 | 設計外氣條件 | 如 33°C DB / 28°C WB（台灣夏季設計值）|
| 混風後 | 混風條件 | 外氣 + 回風混合後溫濕度 |
| 冷卻盤管出口 | 無塵室供氣條件 | 如 22°C / RH 50~60% |

## 八、對程式設計的應用

### 外氣量自動計算邏輯
```
OA = 正壓量 + 排氣量
  正壓量 = 空間體積(m³) × 正壓換氣次數(1~2次) ÷ 60
  排氣口風量 = π × (排氣管半徑)² × 風速(5m/s) × 60 × 排氣口數量
```

### AHU RT → CMM 換算
```
CMM = RT × 14.17   （最精確）
CMM = RT × 500 CFM ÷ 35.3   （CFM→CMM 路徑）
```

### 關鍵公式整理

| 計算項目 | 公式 |
|---------|------|
| AHU 外氣量 | C/R體積 × 換氣次數 ÷ 60 + 排氣量 |
| AHU 回風量 | SA - OA |
| 1RT 換算 CMM | **14.17 CMM/RT** |
| 熱水盤管噸數 | CMM × 17.4 × ΔT ÷ 3024 |
| 加濕量（kg/hr）| (CMM÷60) × 1.2 × Δx × 3600 ÷ 1000 |
