## 二、電力系統架構

### 高壓系統（第7頁）

```
市電 11.4kV（3φ 60Hz）
    ↓
VCB-B PANEL（真空斷路器）
    ↓
┌───────────────────────────────┐
│   TR-1 (變壓器)   │  TR-2     │  緊急發電機
│   380/120-208V    │  380/120V │
│   Oil Type 100KVA │           │
└───────────────────────────────┘
    ↓
ACMP（空調主盤）
CTMP（冷卻塔主盤）
LAMP（照明主盤）
    ↓
ML1 PANEL → MLJ PANEL → 各末端
```

## 三、一般施工說明重點（第1頁）

### 重要規範節錄

1. **停電作業**：業主同意後，先行申請停電，所有送電、停電、分路電線等應由甲方委派之電力公司人員處理
2. **機房優先**：機房內之馬達、泵浦、空調設備等施工前須確認相關設備、位置圖及施工說明，完成後方能進行後續作業
3. **O.G.C. 型式**：使用 N.G.C. 時必須在圖面上標明可以承受大安培之容量
4. **竣工圖**：施工期間詳細紀錄圖面修改之工程，竣工後移交
5. **管材要求**：室內"排水分支管"使用 2" PVC 管；室外"排水分支管"使用 3/4" PVC 管
6. **管路斜度**：室內排水管系斜度 S=1:50
7. **彎管安裝**：所有排水管彎管型安裝 45 度角

## 四、配管系統（第22~24頁）

### 給水系統（第23頁）

**注意事項**：
1. 地下水源設置過濾引入"主幹管"後使用4"管及3" PVC管
2. 角落水負食天花板引入"主幹道"使用4" PVC管
3. 室內"排水分支管"使用 3/4" PVC管
4. 室外給水管如因閥間距大可閉型入水管口加閥管間距

### 污廢水系統（第24頁）

**規格要求**：
1. 污水管管徑均採用 4" 處理，採用 4" 管
2. 室內"排水分支管"使用 2" PVC管
3. 室內排水管系斜度 S=1:50
4. 所有排水管彎管安裝 45 度角

### 冷卻水系統（第22頁）

- 放水閥示意圖：含止水閥、Y型過濾器、排氣閥配置
- 冷卻水設備位置圖：設備機房冷卻水具配置

## 五、對本案（yushi）的應用價值

### 電力估算參考
- ML1 PANEL IC: 150A（3φ 4W 380V）→ 容量約 **100 KVA**
- 空調系統占總電力約 **40~50%**（ACMP + CTMP + 部分LAMP）

### 機房配置參考
- 緊急發電機需獨立空間（見第2頁平面）
- 高壓容稱控箱需靠近主進線側

### 配管規格直接應用
| 管路類型 | 規格 |
|---------|------|
| 室內給水主幹管 | 4" 管 |
| 室外給水分支 | 3/4" PVC |
| 室內污水管 | 4" 管 |
| 室內排水分支 | 2" PVC |
| 排水管斜度 | S=1:50 |
| 排水彎管安裝角度 | **45度** |
