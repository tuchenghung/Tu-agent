## 二、電力系統架構（已訂正）

### 高壓系統（第7、18頁）

```
台電 TPC LINE 3φ3W 11.4-22.8KV
    ↓ MOF / DS 630A 24KV / POF*3 100A24KV
    ↓ VCB 3P 24KV 630A 16KA
綜合大樓變電站
    ├─ TO VCB-A PANEL（既設）
    ├─ TO VCB-B PANEL（既設，TR 500KVA 11.4KV(22.8KV)/380-220V）
    │      └─ BEP PANEL（綜合大樓動力盤，既設）
    └─ TO VCB-C PANEL（既設）

本期新增（第7、13頁）：
綜合大樓變電站 25KV PEX Cable
    ↓
MVCB-2 PANEL（本期新增，IC:16KA）+ VCB-3 PANEL（本期新增，IC:16KA）
    ↓ CU BUSBAR 40x5x1-3
MVCB-B PANEL（既設）
    ↓ TR-D 750KVA 11.4KV(22.8KV)/380-220V
MP PANEL（既有）
```

### 新設機電房內部配電（第2、3頁）

```
MVCB
    ↓ CuBusBar(20cm) 80x10x1-4／CT-3 1200/5 40VA
MP PANEL（IC:30KA）
    ├─ NFB 150/250 → LAMP（照明主盤）100,000VA / 151.9A
    ├─ NFB 250/250 → CTMP（冷卻塔主盤）150,000VA / 228.0A
    ├─ NFB 150/250 → ACMP（空調主盤）100,000VA / 151.9A
    ├─ NFB 200/250 → TR1 100KVA 380/120-208V OIL TYPE → ML1 PANEL 65,388VA / 181.5A
    ├─ NFB 150/250 → SPACE（備用）
    └─ SC PANEL（IC:30KA）：4組三相式電容模組（40KVAR×2、80KVAR×2）
         3φ380V＝160KVAR／3φ460V＝240KVAR

MP PANEL 總計：415,388VA / 631.1A
```

## 三、一般施工說明重點（第1頁）

30項電氣設備符號圖例（動力配電盤、高壓隔離開關DS、高壓真空斷路器VCB、避雷器、高壓電力熔絲、高壓油浸導口型變壓器、四相/六相一體保護電驛、UPS、CTD、自動復閉保護電驛79、低壓比流器CT-LV、CTT/PTT測試端子、NFB、ELCB、電磁開關MS/接觸器MC、自動功因調整器APFR、進相電容器SC、指示燈PL、掌光式按鈕開關PBL、選擇開關CS、電力突波保護器TVSS、靜態切換電容器模組SCR、空氣斷路器ACB、接地銅板×20、測試點×2、接地測試箱×1、分電盤×1）。

施工規範重點：
1. 工程範圍除另有規定外，均以本工程地界範圍內容，盤體基礎台及定位放置及托架、配管均應保存在原位，建築開口須配合建築設備配線需求，經施工前先確認方可製作
2. 本工程機電依現有經濟部最新頒訂之用戶電力設備裝置規則施工，未盡事宜依施工圖之解釋為准
3. 所有配電、控制盤、分電箱皆須訂製前需先確認容量規格，並由承包商先繪製圖，送設計監造單位審核後方可製作
4. 承包商應詳研究建築物之結構完成情形，須配合影響配電結構或建築物線路，對建築物有不明確處，隨時洽詢工地監造解釋
5. 承包商應各項材料型號經送過工程司或監造單位同意方可施工
6. 本工程配管必須有事前配管動線，並配合建築工程施工圖說要求配管，配合現況及監造依合約辦理

## 四、接地與線槽系統（第14~17頁）

### 接地系統（第14、16頁）
- 接地銅板：W600×L600×T3mm，每片深≥1m、間距≥2.5m須20片
- 接地棒：長3000mm，鍍銅0.25mm，螺牙3/4"，棒體直徑7.2mm，每點0.5支×2
- 高壓接地測試箱箱體：W400×H350×D150mm
- 接地電阻計算式：Rg=ρ[Lc+7.20A(1+1/(1+h/20/A))]（範例：10Ω以下、N=20、ρ=400、h=1.2 → Rr=8.333）
- 接地測試箱共3個

### CABLETRAY（第15、17頁）
- 材質：鋁合金，表面霧面粉體塗裝50μm以上
- 產品規格：綠槽一體成型、厚度2.0mm、邊槽工型結構拉擠成型、固定螺栓SUS304
- 8種樣式：直式／水平L型／水平T型／水平X型彎接頭／垂直內彎／垂直外彎／水平可調連接片／垂直可調連接片／連接片
- 位置圖：機電專用 CABLE TRAY W500×H200；弱電專用 CABLE TRAY W500×H200；**兩者需相距100cm**

## 五、給排水系統（第22~24頁，已訂正）

### 給水系統（第23頁 P4-02）
1. 地下水源從屋頂引入「主幹道」使用 2" 白鐵管；自來水自走廊天花板引入「主幹道」使用 2" PVC 管路
2. 屋內「給水分支管」使用 3/4" PVC 管
3. 屋頂入水口加設閥接頭，各浴廁空間入水口增設閥接頭
4. 設備：二段式座式沖馬桶6、洗面盆全套配件8、小便斗全套配件4、拖布盆1、自來水表1、水龍頭5、閥接頭18

### 污廢水系統（第24頁 P4-03）
1. 污水管屋外埋設管使用 4"
2. 屋內「排水分支管」使用 2" PVC 管
3. 屋內排水管斜度 S=1:50
4. 所有排水管轉彎需 45 度角
5. 陰井 60cm×60cm×1、地板落水頭13、清潔口3、吸氣閥4

### 陰井/污廢水昇位圖（第22頁 P4-01）
- 密閉式污水陰井，材質混凝土，井深由現場實測樓高程定之，參考尺寸60×60cm（實際依現場測量）
- 6"清潔口、GL±0基準
- 承包商必須依圖審完竣之圖說施工，內徑超過5公分之管子最禁穿縮於柱內埋管
- 排水立管底端及管路轉向角度大於四十五度處，應裝清潔口

（**訂正說明**：原版本此節誤植為「放水閥示意圖＋冷卻水具位置圖／冷卻水系統」，經本次逐頁核對，第22頁實際內容為給排水設備圖例、索引表、陰井剖面示意圖、污廢水昇位圖，**全案並無冷卻水系統相關圖面**，原描述為錯誤內容，已刪除。）
