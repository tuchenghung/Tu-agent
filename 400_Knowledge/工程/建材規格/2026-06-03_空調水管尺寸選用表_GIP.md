## 換算基準（表格底部附注）

| 換算 | 數值 |
|------|------|
| 1 GPM | = 3.786 LPM |
| 1 RT（冰水側）| = 400 CFM = **2.4 GPM** = 9.09 LPM |
| 1.5 RT | = 600 CFM = 3.6 GPM |
| 2 RT | = 800 CFM = 4.8 GPM |
| 2.5 RT | = 1000 CFM = 6 GPM |
| 3 RT | = 1200 CFM = 7.2 GPM |

## 快速查表（常用工程規模）

### 冰水管主管

| 工程規模 | 建議管徑 |
|---------|---------|
| 10 RT 以下（小型無塵室）| **1-1/2" (40∮)** |
| 20 RT（中型空調）| **2" (50∮)** |
| 30~40 RT | **2-1/2" (65∮)** |
| 60 RT | **4" (100∮)** 主管 ＊ |
| 100~120 RT | **4" (100∮)** |
| 200~230 RT | **5" (125∮)** |

> ＊ 803圖（60RT，FCU系統）記錄水管 Φ65 = 2-1/2"，**可能為分支管或單冰機管段**，非主幹管。主幹管應選 4"（100∮）。  
> 建議設計時按實際系統分支拆算各段 RT 負荷後逐段選管。

### 冷卻水管主管

| 工程規模 | 建議管徑 |
|---------|---------|
| 20 RT | **2-1/2" (65∮)** |
| 30~50 RT | **3" (80∮)** |
| 60~80 RT | **4" (100∮)** |
| 100~200 RT | **5" (125∮)** |

### 流量換算（程式用）

```python
GPM_PER_RT_CHW = 2.4   # 冰水管
GPM_PER_RT_CDW = 3.0   # 冷卻水管
LPM_PER_GPM = 3.786

def rt_to_gpm_chw(rt): return rt * 2.4
def rt_to_lpm_chw(rt): return rt * 2.4 * 3.786
```
