# 氟碳素鋼板牆（PVDF氟碳烤漆鋼板）

## 產品資訊

鍍鋅/鍍鋁鋅鋼板表面塗覆 **PVDF（聚偏二氟乙烯）氟碳樹脂塗層** 之金屬建材，用於外牆帷幕、隔間、機房牆板、金庫牆等。

### 結構組成

| 層次 | 材質 |
|---|---|
| 表面塗層 | PVDF氟碳樹脂（含氟碳鍵，化學性質極穩定） |
| 基材 | 鍍鋅鋼板（GI）或鍍鋁鋅鋼板（Galvalume） |
| 底漆 | 環氧樹脂或聚酯底漆（增加附著力） |
| 背面漆 | 保護背面防鏽 |

## 關鍵數據

| 項目 | 數值 |
|------|------|
| 耐候年限 | 20年以上不明顯褪色（優於一般聚酯烤漆PE的5-8年） |
| 色差穩定度 | ΔE值小，長期維持原色 |
| 防火 | 金屬基材不燃，依塗層厚度及基材規格可達耐燃一級 |
| 耐化學腐蝕 | 抗酸雨、抗鹽害，適合沿海/工業污染環境 |

## 選用判斷

| 需求 | 適合？ |
|------|--------|
| 戶外長期曝曬、要求20年以上不褪色 | ✅首選 |
| 沿海鹽害環境 | ✅適合 |
| 金庫/機房等需高防護、易清潔、長期免維護牆面 | ✅適合 |
| 預算有限、室內短期使用 | ⚠️一般聚酯烤漆(PE)即可，氟碳較貴 |
| 需要石材/磚牆質感 | ❌金屬感明顯，不適合仿石材需求 |

## 施工方式

1. **放樣定位**：依圖面標記板材接縫線、開口位置
2. **骨架安裝（次結構）**：角鋼/C型鋼/鋁擠型骨架固定於RC牆面或鋼構主結構，間距依載重計算，常見600~900mm，骨架須防鏽處理
3. **防水層/隔熱層施作**（外牆帷幕適用）：骨架與RC牆面間鋪防水透氣膜或隔熱棉
4. **鋼板裁切與加工**：現場或工廠裁切折邊，板邊包邊防鏽，開孔預先加工
5. **鋼板安裝**：
   - 明釘式：自攻螺絲/鉚釘鎖固，接縫外露打矽利康，施工快但有釘孔
   - 隱扣式（乾式掛勾系統）：背面加工掛勾卡入骨架軌道，無釘孔外露，目前主流工法
6. **接縫處理**：留伸縮縫5~10mm，填耐候矽利康或鋁壓條收邊
7. **收邊收頭**：陰陽角、頂部、門窗周邊用專用收邊料包覆
8. **清潔驗收**：清除保護膜殘膠，檢查平整度、接縫一致性，必要時淋水試驗

> [!warning] 施工禁令
> - 完成塗裝的鋼板**不可在現場焊接**（破壞塗層並產生鏽蝕熱影響區）
> - 避免與鋁料直接接觸（電位差腐蝕），中間須加絕緣墊片
> - 大面積牆面務必分段留伸縮縫，忽略會導致鋼板變形/接縫爆裂

> [!tip] 施工要點
> - 板材搬運需雙面貼保護膜，避免刮傷氟碳塗層
> - 現場開孔須用專用刀具，避免高溫破壞塗層邊緣防鏽層
> - 隱扣式系統外觀較佳但成本較高，金庫等需高氣密/防護場合建議優先考慮

> [!info] 驗收稽核清單
> - 板面平整度、接縫一致性
> - 防水測試（必要時淋水試驗）
> - 收邊收頭是否完整包覆（陰陽角、頂部、門窗周邊）
> - 骨架防鏽處理是否確實

## 三種金屬/複合板材比較（氟碳烤漆鋼板 vs 琺瑯板 vs 塑鋁板）

### vs 琺瑯板（Enamel/搪瓷鋼板）

| | 氟碳烤漆鋼板（PVDF） | 琺瑯板（Enamel/搪瓷鋼板） |
|---|---|---|
| 塗層原理 | 有機塗料噴塗烤漆（樹脂類，化學鍵結附著） | 無機玻璃質釉料，高溫(約800℃)燒結融合成一體化玻璃層 |
| 耐候性 | 極佳，20年以上不褪色 | 更頂級，理論壽命50年以上，色彩永不氧化褪色 |
| 抗刮抗污 | 良好 | 更優，表面硬度接近玻璃，抗刮抗塗鴉、易清潔 |
| 耐火 | 金屬基材不燃，塗層本身可燃(薄層影響小) | 釉料無機不燃，耐火等級更高 |
| 加工彈性 | 可現場裁切、折邊、開孔 | 燒製後不可再加工，須燒製前定案尺寸開孔，客製化周期長 |
| 成本 | 中等 | 較高(燒製工藝+良率控制成本高) |
| 常見應用 | 廠房、機房、金庫牆、一般外牆帷幕 | 高鐵站、捷運站等大量人流、要求極致耐久/抗污的公共空間 |

### vs 塑鋁板（ACP，鋁塑複合板）

| | 氟碳烤漆鋼板 | 塑鋁板（ACP） |
|---|---|---|
| 結構 | 實心鍍鋅/鍍鋁鋅鋼板+PVDF塗層 | 兩片薄鋁板夾PE(聚乙烯)塑膠芯材，三明治結構 |
| 防火性 | 基材金屬不燃 | ⚠️PE芯材可燃，是全球多起大樓惡火元凶(英國Grenfell Tower等)，台灣現行建築法規對ACP用於高層/防火要求區已有限制，須用FR耐燃芯材版才合規 |
| 重量 | 較重 | 較輕(施工吊裝較省力) |
| 結構強度/抗撞 | 強，實心鋼板抗撞擊不易變形 | 較弱，大面積易凹陷、長期易鼓起變形(芯材PE熱脹冷縮) |
| 抗腐蝕 | 鋼板需靠鍍層+烤漆雙重防鏽，塗層破損處會生鏽 | 鋁本身不生鏽(氧化層自我保護)，但表面塗層仍會老化 |
| 成本 | 中等 | 較低(ACP最大優勢) |
| 加工彈性 | 可折邊開孔，強度足以做結構性骨架固定 | 易加工(可雕刻彎折)，但不適合承重/結構用途，僅能當非結構性裝飾面材 |
| 常見應用 | 廠房外牆、機房、金庫、要求耐久防護的場合 | 招牌、廣告塔、預算有限的外牆裝飾、室內裝修 |

### 三者定位總結

| 材質 | 定位 | 選用時機 |
|---|---|---|
| 氟碳烤漆鋼板 | 中價位、可加工、結構防護兼具 | 需要現場配合開孔走管線、要求結構強度與防護性的場合（如金庫、機房） |
| 琺瑯板 | 高價位、不可加工、耐久性天花板 | 一次施工、要求數十年零維護的大量人流公共空間（如高鐵站、捷運站） |
| 塑鋁板(ACP) | 低價位、輕量裝飾用、非結構性 | 預算有限的外牆裝飾、招牌，**防火要求高或結構防護場合不適用** |

> [!warning] 金庫選材結論
> 金庫這類需高防護、防火硬指標的場合，塑鋁板因PE芯材可燃直接排除；琺瑯板雖耐久性最佳但不可現場加工開孔，不適合需配合管線施工的金庫牆；**氟碳烤漆鋼板兼具防火(金屬基材)與加工彈性，是金庫牆較合理的選擇**。

## 應用案例：中華郵政臺北郵件處理中心整修統包工程

**用於金庫牆面**（2026-07-16 使用者確認）。本案金庫/庫房分布（詳見 [[2026-07-01_中華郵政臺北郵件處理中心統包工程_技術規格摘要]] 第十二節）：
- 2F：8.47坪、9.09坪兩處
- 4F：4.29坪
- 5F收支股：10.16坪
- 5F票券股：需20坪（兩間各自獨立開放式庫房）
- 6F房貸股：需5坪
- 8F集郵股：需20~30坪

金庫牆面對防護性、耐久性、易清潔要求高，氟碳素鋼板牆的耐候/耐化學腐蝕/長期免維護特性適合此應用。實際規格（塗層等級、板厚、隱扣或明釘系統）待細部設計階段確認。
