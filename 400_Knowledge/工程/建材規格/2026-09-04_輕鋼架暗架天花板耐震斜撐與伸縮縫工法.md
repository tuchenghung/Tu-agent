# 輕鋼架暗架天花板 耐震斜撐與邊緣伸縮縫工法（矽酸鈣板／石膏板）

> 適用於暗架（骨架隱藏）之矽酸鈣板／石膏板懸吊天花板。明架（T-Bar）天花板耐震做法概念相同，
> 但數值以 ASTM E580 lay-in panel 條文為準，兩者不可直接互套。

## 一、關鍵數據（校正後，以中華民國規範為主）

| 項目 | 規範值 | 依據 |
|------|--------|------|
| **強制設耐震斜撐之面積門檻** | 天花板面積 **> 100 m²**（無結構計算時） | 耐震設計規範附錄B |
| 小面積免斜撐豁免 | ≤ 13.4 m²（144 ft²）且四周牆／包板本身有側向支撐 → 免；ASTM E580 另訂 ≤ 92.9 m²（1000 ft²）免「側向力斜撐」 | ASCE 7-16 §13.5.6 / ASTM E580 |
| 斜拉線組組成 | **4 條 Ø2.7 mm（#12）斜拉鋼線 ＋ 1 根垂直抗壓桿**（斜拉線組 splay-wire assembly） | 附錄B |
| 斜拉鋼線固定位置 | 鎖在**主架（Main Runner）**上、距主副架交接處 **5 cm 範圍內** | 附錄B |
| 斜拉鋼線角度 | 與**水平面夾角 ≤ 45°**（規範硬性上限）；實務建議 30°~45°，45° 傳力效果最佳 | 附錄B / ASTM E580 |
| 4 向斜拉線水平投影 | 互為 **90° 垂直** | 附錄B |
| 斜撐組間距 | ≤ **3.66 m（12 ft）**，縱橫雙向 | ASTM E580 |
| 首組斜撐距周邊牆面 | ≤ **1.83 m（6 ft）** | ASTM E580 |
| 斜撐上端錨固 | 膨脹螺栓／化學錨栓直接錨於 RC 樓板或鋼構樑；**嚴禁**錨於風管、消防管、電管、既有吊架 | ASTM E580 / CISCA |
| 斜撐下端錨固 | 牢固鎖附於**主架節點**，不可僅鎖副架或板材 | 附錄B |
| 加強垂直吊筋 | 斜拉線組處須另設 1 根加強垂直吊筋抵抗斜拉線垂直分力 | 附錄B |
| **牆邊自由邊留縫（clearance）** | 每一自由邊 **≥ 19 mm（3/4"）**；實務公共工程抓 19~20 mm（一般裝修可 15~20 mm） | ASTM E580（SDC D–F） |
| 邊角動靜分界 | 相鄰**兩側**主副架固定鎖於邊角料（Wall Angle）；相對之另**兩側**不得鎖死，保持自由滑動 | ASTM E580 |
| 邊角料（Wall Angle）水平翼 | ≥ 50 mm（2"）以容納地震位移（新版 E580 另有 22 mm 窄邊角料＋固定夾做法） | ASTM E580 |
| **抗震分割縫（seismic separation joint）觸發** | 連續天花板面積 **> 232 m²（2500 ft²）**：中段須斷開設分割縫，或以全高隔間分隔 | ASTM E580 |
| 分割縫結構體預留寬 | 20~25 mm（≥ 19 mm）；表面以 Z 型金屬伸縮飾條覆蓋、填彈性矽利康 | ASTM E580 實務 |
| 高低差天花交接處 | 交接處（立面封板、層板、光溝）須足夠補強，不得僅靠板材銜接 | 附錄B（明列） |
| 重型燈具／設備 | 一律正向固定於主架；重型者（超出主架承載）須**獨立吊筋**，崁燈另加防墜鏈／獨立吊線 | ASCE 7-16 §13.5.6.2.2 |
| 設備／管線吊掛 | 天花板吊筋與 MEP 管線、全熱交換器等設備**各自獨立懸掛**，不得共桿 | CISCA / ASTM E580 |

## 二、耐震斜撐補強（Lateral Force Bracing）

### 原理
傳統天花板僅有垂直吊筋，只抗重力。地震橫向晃動時天花板如鞦韆擺動，
斜撐的作用是形成三角形穩定結構，鎖死水平位移。

```
          [ RC 頂板 / 樑 ]
             /   |   \
   斜拉線 ≤45° /   |    \ 斜拉線 ≤45°
           /  加強垂直桿  \
   ───────[ 主架 Main Runner 節點 ]───────
     （固定點距主副架交接 ≤5cm，鎖主架不鎖副架）
```

### 設置時機
- 天花板面積 **> 100 m²**（無結構計算）→ 強制設斜拉線組。
- 面積未達 100 m² 但屬下列情形，建議每 9~12 m² 佈一組：
  - 高樓層（層間位移大）
  - 天花板上方附掛重型設備（大型風管、全熱交換器、AHU 等）
  - 醫療／實驗室等震後須維持機能之空間

### 組成
- **規範基本要求**：4 條 Ø2.7 mm（#12）斜拉鋼線 ＋ 1 根垂直抗壓桿，4 向互為 90°，與水平面夾角 ≤ 45°。
- **加強做法（非規範最低要求）**：以角鐵、槽鋼或加厚鍍鋅鋼管作剛性斜撐（rigid brace），
  適用於重載或高規格公共工程，須有結構計算或廠商型錄承載值佐證。

### 佈設
- 斜撐組間距 ≤ 3.66 m（雙向）。
- 首組距周邊牆 ≤ 1.83 m。
- 上端錨 RC／鋼樑（膨脹或化學錨栓）；下端鎖主架節點。

## 三、邊緣伸縮縫與周邊交接（Peripheral Clearance & Seismic Joints）

### 3-1 牆邊緩衝伸縮縫
- 骨架與板材距四周牆面／RC 柱保持 **≥ 19 mm** 物理間隙（一般裝修 15~20 mm，公共工程依 E580 抓 19 mm）。
- **動靜分界**：
  - 固定端：相鄰兩側牆面，主副架鎖死於邊角料。
  - 滑動端：相對之另兩側牆面，主副架**不鎖死**，地震時可在牆邊自由推移。
- 邊角料水平翼 ≥ 50 mm（或新版窄邊角料＋固定夾系統）。

### 3-2 大面積抗震分割縫
- 連續面積 **> 232 m²** 或明顯過長／過寬 → 中段斷開設分割縫，或以全高隔間分隔。
- 結構體分割縫預留 20~25 mm。
- 收邊：Z 型金屬伸縮飾條覆蓋，表面填彈性矽利康或壓克力膠。

### 3-3 高低差天花交接
- 交接處立面封板、層板、光溝須獨立補強骨架，不得僅以板材銜接（附錄B 明列項目）。

## 四、選用判斷

| 情形 | 是否須耐震斜撐 |
|------|----------------|
| 單一封閉天花板 > 100 m²（無結構計算） | ✅ 強制 |
| 天花板 ≤ 13.4 m² 且四周牆／包板有側撐 | ❌ 可免（ASCE 7 豁免） |
| 13.4~92.9 m²、房間四周牆能承受天花板側力並依 E580 做周邊支撐 | ⚠️ 可免側向力斜撐，仍須周邊支撐 |
| 上方附掛重型設備／醫療實驗室機能空間 | ✅ 建議加密至 9~12 m²／組 |
| 明架 T-Bar lay-in 天花 | ⚠️ 改依 ASTM E580 lay-in panel 條文，數值不可直接沿用本文暗架描述 |

> [!warning] 施工禁令
> - **斜撐固定點嚴禁**鎖在冷氣風管、消防管、電管或既有吊架上（地震會拉斷管線）。
> - 斜拉鋼線**不得**只鎖副架或天花板材，必須鎖主架節點、且距主副架交接 ≤ 5 cm。
> - 滑動端牆面**嚴禁**把主副架或板材鎖死／批土貼牆（地震必剪裂崩落）。
> - 天花板吊筋**不得**與 MEP 設備（全熱主機等）共用吊桿。
> - 重型燈具**嚴禁**直接掛在矽酸鈣板／石膏板上。

> [!tip] 施工要點
> - 斜拉線組：4 條 Ø2.7 mm 鋼線＋1 垂直抗壓桿，4 向 90°、與水平面夾角 ≤ 45°。
> - 斜撐間距 ≤ 3.66 m，首組距牆 ≤ 1.83 m。
> - 牆邊自由邊留縫 ≥ 19 mm；相鄰兩側固定、另兩側自由滑動。
> - 連續面積 > 232 m² 設抗震分割縫，Z 型飾條收邊填彈性膠。
> - 高低差交接處獨立補強骨架。

> [!info] 驗收稽核清單
> - 斜撐固定點是否直連 RC 樓板／鋼樑（非管線、非既有吊架）。
> - 斜拉線規格 Ø2.7 mm、每組 4 條＋垂直桿、角度 ≤ 45°、固定於主架 5 cm 內。
> - 斜撐間距 ≤ 3.66 m、首組距牆 ≤ 1.83 m。
> - 牆邊留縫 ≥ 19 mm，且僅相鄰兩側固定、對側自由滑動。
> - 面積 > 232 m² 是否設抗震分割縫並正確收邊。
> - 高低差天花交接處補強骨架。
> - 重型燈具（超出主架承載）／崁燈是否獨立吊筋＋防墜措施。
> - 吊筋與 MEP 管線／設備是否各自獨立懸掛。

## 常見錯誤（工務避坑）

| 檢核項目 | 合格標準 | 常見錯誤 |
|---|---|---|
| 斜撐固定點 | 直連 RC 樓板或鋼樑 | 誤鎖在冷氣風管、消防管或吊頂軟管上（會拉斷管線） |
| 牆邊收邊 | 留縫 ≥ 19 mm 並以軟質膠封填 | 矽酸鈣板直接貼緊牆面批土，地震必裂 |
| 管線獨立 | 吊筋與 MEP 管線各自獨立懸掛 | 天花板吊筋與設備（全熱主機）共用吊桿 |
| 燈具設備加固 | 重型燈具／崁燈獨立加吊筋＋防墜 | 重型燈具直接掛在矽酸鈣板上，震動撕裂板材 |
| 斜拉線鎖點 | 鎖主架節點、距交接 ≤ 5 cm | 鎖在副架或板材上 |
| 面積門檻判斷 | > 100 m² 即須斜撐（無結構計算） | 誤用 144 m²（實為 144 ft² = 13.4 m²）當門檻，大面積漏設 |
