# Gili A16 單向連動門(鋁框玻璃連動橫拉門)

## 產品資訊
- 品牌：Gili集力門(GILI DOOR TAIWAN)
- 型號：A16
- 16mm極致四邊框、45度對接、無下軌設計
- 適用玻璃：5-10mm
- 通過10萬次來回開關測試

## 關鍵數據
| 項目 | 數值 |
|------|------|
| 單片寬度 | 50~200 cm |
| 單片高度 | 30~300 cm |
| 單片最大載重 | 90 kg |
| 整堂門最大載重 | 300 kg |
| 門片寬高比例限制 | 1:4.5內 |

### 緩衝器選配(依整堂門總重)
| 等級 | 承重範圍 |
|------|----------|
| 輕 | 20~40 kg |
| 中 | 40~80 kg |
| 重 | 80~110 kg |
| 輕+重 | 100~130 kg |
| 中+重 | 140~200 kg |
| 重+重 | 200 kg 以上 |

### 軌道配置(命名系統)
單拉門1S、二~四連動2S~4S、一固一~一固四連動1F1S~1F4S、二固連動對開2F2B、雙門互開D2B、連動對開2B、一固連動對開1F2B，皆可搭配L型雙開拉門。

## 選用判斷
| 需求 | 適合？ |
|------|--------|
| 室內鋁細框玻璃隔間/多片連動拉門 | ✅ |
| 需極簡邊框視覺、無下軌地面平整效果 | ✅ |
| 戶外安裝(防水氣密需求) | ❌ 非防水氣密產品 |
| 上方為矽酸鈣板天花板或輕鋼架 | ❌ 承重不足需加強結構 |
| 現場地板落差過大 | ⚠️ 需落差≤10mm |

> [!warning] 施工禁令
> - 不可安裝於戶外，無防風雨及完全氣密之功能
> - 上方結構承重不足(矽酸鈣板天花板/輕鋼架)不得直接安裝，須加強為RC、木角料/板材(≥5cm)、黑鐵方管或折板(≥3mm)
> - 天地壁完成面未確認前不可丈量，尺寸會不準

> [!tip] 施工要點
> - 軌道須與現場上方結構牢固結合，軌道盒尺寸須依Gili集力標準圖面施作
> - 預留維修孔至少寬50cm高40cm
> - 門片行走路徑水平落差需≤3mm，硬地板(石材/磁磚)為佳，軟地板(木地板/塑膠地板)長期使用易留痕
> - 安裝門止(土地公)前須確認下方無管線

> [!info] 驗收稽核清單
> - 單片寬高是否在50~200cm / 30~300cm範圍內，寬高比≤1:4.5
> - 緩衝器等級是否依整堂門總重正確選配
> - 開關順暢無夾手、無下軌地面平整
> - 交期約15工作天，保固1年(人為/天災不保)
