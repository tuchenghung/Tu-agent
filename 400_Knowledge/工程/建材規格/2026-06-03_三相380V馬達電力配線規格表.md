## NFB 選用規則（手寫備註）

### 個迴路 NFB（AT 選用）
```
全載電流（運轉電流）× 1.5 → 取上一個標準 AT 值
確認：NFB 框架電流（AF）> FLA × 1.1
```

**實例（ACP-401 SLD）**：
- MAU-405 15kW：FLA = 30A → 30×1.5 = 45 → **NFB 3-50/100**（50AT, 100AF）
- MAU-404 18.65kW：FLA = 38A → 38×1.5 = 57 → **NFB 3-60/125**（60AT, 125AF）
- 加濕器 0.1kW 1φ：FLA = 0.45A → **NFB 2-15/100**

### AF（框架容量）選用邏輯
- AF ≈ 2×AT（取下一個標準框架）
- 50AT → 100AF；60AT → 125AF；100AT → 125AF；225AT → 225AF

### 主配電盤總 NFB
```
總 NFB AT = 最大馬達 FLA × 1.5 + Σ其餘設備 FLA
```

**ACP-401 計算實例**：
```
28A × 1.5 + 38 + 30 + 30 + (0.45×4) = 156.8A → 選 175A NFB
```

### EMT 選管邏輯（3條以上導線）
```
法規填充率上限：40%
管路有效截面積 = π × (內徑/2)² × 40%
導線總截面積 = Σ(各導線截面積 × 根數，含絕緣層)
選用：導線總截面積 ≤ 管路有效截面積 的最小管徑
```

## ⚖️ 現行法規基準（用戶用電設備裝置規則）

**最新修正日期**：民國 110 年 03 月 17 日  
**查詢來源**：全國法規資料庫 J0030018

### 第214條 — 導線安培容量（法定下限）
```
分路導線安培容量 ≥ 馬達滿載電流（表258-3）× 1.25倍
```
- Y-△ 啟動時：操作器側 ×1.25、電動機側 ×72%
- 小型電動機最小線徑：3.5mm²

### 第220條 — 分路 NFB 過電流保護（法定上限）
```
反時限斷路器（NFB）AT 上限：
  滿載電流 ≤ 100A → AT ≤ FLA × 4倍
  滿載電流 > 100A → AT ≤ FLA × 3倍
```
> ⚠️ 法規是**上限**，工程實務慣用 ×1.5 做馬達短路保護（NFB 只管短路，過載靠 MC 保護繼電器）

### 第258條 — 滿載電流查表依據
三相交流電動機全載電流依「**表二五八～三**」選定，  
該表以 **CNS-2934** 為基礎（與電力系統1.pdf Table 6-3 相同）
