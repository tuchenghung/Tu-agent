# D8鉛板自動門施工詳圖（碘131病房防護鉛門）

## 產品資訊
- 用途：核醫/同位素治療病房（碘131病房）入口輻射屏蔽自動門
- 繪圖單位：泰臣室內裝修事業有限公司
- 所屬工程：國立臺灣大學醫學院附設醫院 西址五西一樓病房整修工程

## 關鍵數據

構造（由外而內對稱夾層）：

| 層次 | 材料 |
|------|------|
| 1 | 面貼美耐板 |
| 2 | 6mm鍍鋅鋼板 |
| 3 | 2×2cm方管（骨架） |
| 4 | 1.5cm鉛皮 |
| 5 | 2×2cm方管（骨架） |
| 6 | 6mm鍍鋅鋼板 |
| 7 | 面貼美耐板 |

| 項目 | 數值 |
|------|------|
| 門片寬度 | 130cm |
| 門片高度 | 220cm |
| 門片厚度 | 7.9cm |
| 鋼板夾鉛高度（隔間複牆段） | 255cm |
| 牆體總高 | 220cm |
| 門機類型 | 重型自動門機 |

其他構造細節：上掀維修孔（不鏽鋼機箱外蓋）、門框內包鉛皮、收邊條、水泥砂漿崁縫填塞。

## 選用判斷

| 需求 | 適合？ |
|------|--------|
| 核醫/同位素治療病房輻射屏蔽門洞 | ✅ |
| 一般無輻射防護需求的隔間門 | ❌（鉛皮夾層增加造價與重量，無必要） |

> [!warning] 施工禁令
> - 此圖未標示鉛當量厚度換算或防護等級認證（如 mmPb 當量），實際採用前**必須**要求廠商提供對應鉛當量測試報告，不可僅憑「1.5cm鉛皮」規格描述判定符合法規防護要求
> - 門框、牆體交接處鉛皮須連續包覆無斷點，否則形成輻射洩漏路徑

> [!tip] 施工要點
> - 門片為對稱夾層構造（美耐板/鋼板/方管/鉛皮），骨架用2×2cm方管固定鉛皮避免下垂變形
> - 上掀維修孔需預留不鏽鋼機箱外蓋位置，供門機日後維修
> - 門框內包鉛皮與牆體鉛皮須搭接，水泥砂漿崁縫填塞前確認鉛皮無破損

> [!info] 驗收稽核清單
> - 核對鉛皮鉛當量測試報告與圖面標示是否一致
> - 檢查門框與牆體鉛皮搭接處是否連續無斷點
> - 確認重型自動門機運作順暢、上掀維修孔可正常開啟
