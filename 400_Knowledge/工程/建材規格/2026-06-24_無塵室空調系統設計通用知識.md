> 來源：信天翁嘉義廠（細胞備製廠）空調規劃討論 2026-06-24
> 適用：無塵室、GTP廠、生技廠、半導體廠空調設計

## 一、三控分離架構（FFU + MAU + D/C）

### 1.1 架構說明

| 設備 | 控制目標 | 冰水溫度 | 說明 |
|---|---|---|---|
| FFU（Filter Fan Unit）| **潔淨度** | 無（HEPA循環）| 變頻調速，依粒子計數器 |
| MAU（Make-up Air Unit）| **濕度** | Cold CHW 7/12°C | 外氣除濕主力 |
| D/C 乾盤管（Dry Coil）| **溫度（顯熱）** | Warm CHW 14/18°C | 不結露，純顯熱 |
| VAV排氣閥 | **壓差** | — | DDC控制各區 ΔP |

### 1.2 為何D/C溫度不能低於14°C

- 露點約束：若設計條件 22°C / 50%RH → 露點 = **11.1°C**
- D/C 盤管表面溫度必須 > 露點，否則結露
- Warm CHW 供水最低 14°C → 盤管表面約 16°C > 11.1°C ✅
- 若用 7°C CHW 給 D/C → 盤管表面低於露點 → 結露 → GMP/GTP 違規

### 1.3 MAU 功能說明

- MAU 補充外氣，主要任務是**除濕**（非單純換氣）
- 外氣：35-37°C / 70-75%RH（嘉義夏季）→ MAU處理後送入潔淨室
- MAU提供外氣量決定正壓大小，排氣閥微調

### 1.4 MAU 盤管 ADP 關鍵限制（2026-06-25 修正）

**盤管出口溫度不能只看 13°C，必須從室內露點反推：**

| 室內條件 | 22°C / 50%RH |
|---|---|
| 室內露點 | 11.1°C |
| 室內 W（絕對濕度）| 0.00826 kg/kg |
| MAU 出口 W 必須 | **< 0.00826 kg/kg** |
| 對應 ADP | **≤ 11°C** |
| 對應出口狀態 | 11°C / 95%RH → W=0.0077 kg/kg ✅ |

> ⚠️ 若設計 MAU 出口 13°C → W=0.0088 > 0.00826 → MAU 送入的空氣反而**加濕**，長期導致室內濕度上升
> **採購規格須明訂 ADP ≤ 11°C，不可讓廠商設計到 13°C**

### 1.5 MAU 冷量計算（焓值法）

嘉義夏季 / 室內 22°C/50%RH 案例：

| 參數 | 數值 |
|---|---|
| 室外進口 h₁ | 91.6 kJ/kg（36°C/WB28.5°C）|
| MAU 出口 h₂ | 30.4 kJ/kg（11°C/95%RH）|
| 焓差 | 61.2 kJ/kg |
| 空氣密度 | 1.15 kg/m³ |
| 冷量（kW）| 風量(m³/hr) ÷ 3600 × 1.15 × 61.2 |
| 冷量換算 RT | kW ÷ 3.517 |

### 1.6 D/C 冷量計算原則

D/C 只處理室內**顯熱**，計算方式：

```
D/C 需求 = 室內總顯熱 - MAU 帶走的顯熱
         = (FFU馬達 + 設備 + 照明 + 人員 + 外皮) - (MAU質量流 × Cp × ΔT_室內vs出口)
```

MAU 帶走的顯熱（以 11°C 出口為例）：
= m_MAU × 1.006 × (T_室內 - T_MAU出口)
= (風量/3600×1.15) × 1.006 × (22-11)

> 設計時 D/C 負荷通常遠小於 MAU 負荷，Warm CHW 冰水機可比 Cold CHW 小很多

## 二、FFU 天花覆蓋率與 ACH

| 潔淨等級 | ISO等級 | 天花FFU覆蓋率 | 換氣次數（ACH）|
|---|---|---|---|
| Class 100 | ISO 5 | 35-70% | 240-480次/hr |
| Class 1,000 | ISO 6 | 25-35% | 150-240次/hr |
| Class 10,000 | ISO 7 | 15-20% | 40-100次/hr |
| Class 100,000 | ISO 8 | 5-8% | 10-25次/hr |

FFU 尺寸標準：0.6m × 1.2m = 0.72m²/台，額定風量 600-800 m³/hr/台

**佈滿率計算範例**（來源：老余Jason Yu，2026-07-06）：
```
單台FFU面積 = 1.2m × 0.6m = 0.72 m²
假設無塵室配置 200 台FFU
FFU總面積 = 200 × 0.72 = 144 m²
FFU佈滿率(%) = 144 m² ÷ 該無塵室淨面積 × 100%
```
算出的佈滿率再對照上表判斷是否符合目標潔淨等級（如 Class 1,000 需 25-35%）。

## 三、壓差梯級設計

### 3.1 壓差要求（ISO 14644-4）

- 相鄰潔淨等級間：**≥5-10 Pa**
- 潔淨區對一般空間：**≥10-15 Pa**

### 3.2 典型壓差梯級

```
Class 1,000（+25 Pa）
    ↓ 更衣室/緩衝室
Class 10,000（+15 Pa）
    ↓ 緩衝室
Class 100,000（+10 Pa）
    ↓
走廊/一般空調（+5 Pa）
    ↓
大氣（0 Pa）
```

### 3.3 目標壓差如何達成：孔口流量公式（2026-08-27補充，來源：南港GTP壓差診斷案）

**重要觀念釐清**：3.1的目標壓差數值是「規範+經驗值訂出來的設計目標」，不是物理公式算出來的；公式是用來算「要達成這個目標值，需要多少新鮮風流量、進而反推風管管徑/風車選型」，這是設計的第二步。

$$Q = C_d \times A_{洩漏} \times \sqrt{\frac{2\Delta P}{\rho}}$$

| 符號 | 意義 | 常用值 |
|---|---|---|
| $Q$ | 維持該壓差所需的新鮮風洩漏流量(m³/s) | 待求 |
| $C_d$ | 孔口流量係數（銳緣開口，如門縫、傳遞箱縫隙）| 0.6-0.65 |
| $A_{洩漏}$ | 房間洩漏面積(m²)——門縫周長×縫隙寬、傳遞箱漏氣面積 | 單扇門縫約0.015-0.02m²(視封條品質) |
| $\Delta P$ | 目標壓差(Pa) | 依3.1節設計目標 |
| $\rho$ | 空氣密度 | 約1.2 kg/m³ |

**設計流程**：
1. 依3.1/3.2訂目標ΔP
2. 估算房間洩漏面積 $A_{洩漏}$（門數量、傳遞箱、貫穿孔洞，可用上表經驗值或現場門封條規格）
3. 代入公式算出所需新鮮風流量 $Q$
4. 加15-20%安全餘裕（洩漏面積估算本有不確定性，且門開關會瞬間洩壓）
5. 用 $Q$ 反推支管管徑（風管流速法 D=√(4Q/πv)，見第七節）跟MAU總風量、風車選型

**反向驗證用法（診斷既有系統時）**：若已知現況ΔP與現況風量Q（現場實測或依支管管徑理論反推），可反解出該房間的隱含洩漏面積 $A_{洩漏}=Q/(C_d\sqrt{2\Delta P/\rho})$，跨房間比較這個隱含面積是否落在合理範圍（單門房間約0.01-0.02m²、多門/多貫穿孔房間可達0.02-0.04m²以上），可作為系統合理性的初步判斷依據；但若Q本身是理論估算值（非現場實測），這個反推面積只能當「一致性檢查」，不能當「獨立驗證」（因為Q本身已經隱含了同一組物理關係，兩者互相印證有一定程度的循環論證性質，真正的獨立驗證仍需現場實測）。

### 3.4 壓差控制邏輯

- 每區設 DDC 電動 VAV 排氣閥 + 壓差計（DP Transmitter）
- MAU 定風量 → 排氣閥開度調節 → 維持設定 ΔP
- FFU 轉速獨立調節（粒子計數），不影響壓差

## 四、排氣系統設計原則

### 4.1 排氣功能

1. MAU 進氣的出口（質量守恆）
2. 壓差梯級的調節機構
3. 補償製程排氣

### 4.2 排氣量 ≈ MAU 量

- 排氣量 = MAU 供氣量 × 85-90%
- 剩餘 10-15% 通過門縫/密封逸流，維持正壓

### 4.3 排風機控制

- **常運轉**（24/7），不是閥門啟動才開
- 開機順序：MAU 啟動 → 排風機同步啟動 → VAV 排氣閥依壓差調節
- 建議 1 用 1 備，VFD 變頻調速
- 排風機故障 → 聯鎖停 MAU + BAS 警報

## 五、冰水系統設計

### 5.1 雙迴路設計

| 迴路 | 溫度 | 用途 |
|---|---|---|
| Cold CHW | 7/12°C | MAU 除濕（低溫除水分）|
| Warm CHW | 14/18°C | D/C 乾盤管顯熱冷卻 |

### 5.2 氣冷 vs 水冷選擇

| 項目 | 氣冷式 | 水冷+密閉塔 |
|---|---|---|
| COP（嘉義夏季36°C）| 2.6-2.8 | 5.0-5.5 |
| 適用情境 | 小規模、短期用 | 長期自有廠房 |
| 回收期（400RT以上）| — | **約15個月** |
| GMP/GTP 合規 | 一般可接受 | 密閉式冷卻塔更優（無退伍軍人菌風險）|

> 長期持有廠房：水冷+密閉式冷卻塔，15年可省NT$9,000萬以上

### 5.3 冷卻塔選型

- **開放式冷卻塔**：退伍軍人菌（Legionella）風險，GTP/GMP 廠**不建議**
- **密閉式冷卻塔（Closed Circuit Cooler）**：水不接觸大氣，GTP 廠推薦

### 5.4 冰水機冗餘建議

| 系統 | 建議配置 | 理由 |
|---|---|---|
| Cold CHW（大容量）| **N+1（3台，任1台故障仍100%）** | 濕度失控=細胞批次報廢 |
| Warm CHW（小容量）| **1用1備（2台）** | 短暫故障較可接受 |

## 六、MAU 配置原則

### 6.1 台數與備用

- 主要生產區（Class 1,000/10,000）：**一用一備**
- 非直接生產支援區（Class 100,000）：視批次重要性決定

### 6.2 放置位置

| 服務樓層 | 推薦位置 | 理由 |
|---|---|---|
| 最高潔淨樓層 | 正上方夾層（如3MF）| 供氣管路最短 |
| 中間樓層 | 就近外牆機房 | 不走豎管，外牆開進氣口 |
| 低樓層 | 就近外牆機房 | 同上 |
| 不建議 | RF集中供遠樓層 | 豎管過長，熱損大，截面積大 |

### 6.3 外氣比例（依廠房類型）

| 廠房類型 | 外氣最低比例 | 法規依據 |
|---|---|---|
| 藥廠（GMP）| ≥20% | PIC/S GMP PE 009-16 |
| 細胞備製廠（GTP）| 10-15%（無強制比例）| GTP / 21 CFR Part 1271 |
| 半導體廠 | 5-10% | SEMI S2 |

## 八、細胞備製廠（GTP）特殊規範要點

| 項目 | GMP（藥廠）| GTP（細胞備製廠）|
|---|---|---|
| 主要法規 | PIC/S GMP | 再生醫療製劑管理條例（2023）|
| 外氣比例 | ≥20% | 10-15%（無強制）|
| 開放操作環境 | ISO 5 | ISO 5（BSC內）|
| 操作室環境 | ISO 7 | ISO 7（Class 10,000）|
| 壓差方向 | 全正壓 | 全正壓（BSL-1）/ 特定區負壓（BSL-2）|

BSC 型號影響排氣：
- Class II A2：70%循環，不需獨立排氣管
- Class II B2：100%排至室外，需獨立排氣管至RF
