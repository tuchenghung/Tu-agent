# 愛克軟片 Altyno系列（表面裝飾材）

## 產品資訊
- 原廠：日本AICA
- 台灣代理：台灣愛克工業股份有限公司
- 產品性質：表面裝飾軟片（貼於基材表面的裝飾用膜/軟片，俗稱愛克板/波音軟片）

## 產品線

### Altyno EX（戶外系列）
- 可用於戶外，具優異耐候性與耐久性的高候規格愛克軟片
- 透過特殊表面加工技術，日本國內環境垂直面施作約可維持5年耐候強度
- 目前已推出15款與室內用愛克軟片同花色款式

| 色號 | 花色 |
|------|------|
| VEX 573M | 斑馬木直紋 |
| VEX 461M | 橡木直紋 |
| VEX 18000M | 橡木直紋 |

### Altyno HD（抗磨系列）
- 具備極佳的抗刮與抗污性，能長久維持外觀美感（與愛克過往產品相比）
- 特別推薦用於電梯車廂或廁所隔間翻新等高頻率使用的重度磨損環境
- 抗污性強（測試：黑色橡皮擦）、耐刮傷性強（測試：鋼絲絨）皆優於常規產品

| 色號 | 花色 |
|------|------|
| VDL 18218HD | — |
| VDV 18205HD | — |
| VDM 18204HD | — |

## 選用判斷

| 場景 | 適合？ |
|------|--------|
| 戶外垂直面裝飾（立面、外牆） | ✅（選EX系列） |
| 電梯車廂、廁所隔間等高頻磨損環境 | ✅（選HD系列） |
| 需要與室內款統一花色的戶外案場 | ✅（EX系列15款與室內同花色） |
| 水平面/地面使用 | ⚠️（型錄未載明，需另確認是否適用） |

> [!info] 驗收稽核清單
> - 確認施工面為垂直面或水平面，選對應系列
> - 戶外施作前確認耐候年限預估基準（僅限日本國內環境使用下的測試值，非保證值，實際使用年限受基材、施工位置/方位、氣候等環境影響）
> - HD系列的抗污/耐刮測試結果為代表性數值，非產品性能保證值
