## SP-IC-FS01：MAU 控制流程圖（DDC 架構）

### 控制架構宣告
- 系統採用**獨立運作 DDC 控制箱（STAND-ALONE 型）**
- 每台 MAU 配置一套獨立 DDC

### MAU 控制點位（IC-01 / IC-02 兩種配置）

#### IC-01（含加濕功能，完整配置）
| 控制點類型 | 點位 | 功能 |
|---------|------|------|
| **DI**（數位輸入）| Di1 | 風壓差壓開關（DPS）— 確認風車運轉 |
| **DI** | Di1 | SD（煙霧偵測/防火風門）狀態 |
| **DI** | Di1 | 各閥門開關回饋 |
| **AI**（類比輸入）| Ai3 | RT（室溫）、RH（室濕）、RP（室壓）三合一感測器 |
| **AO**（類比輸出）| Ao1 | 冰水閥（AoV1）0~100% 調節 |
| **AO** | Ao1 | 熱水閥（AuV1）0~100% 調節 |
| **AO** | — | INV（變頻器）風量控制 |
| 特殊設備 | ISA | 加濕器（含 TS/HS 感測器前後對比）|
| 特殊設備 | M/D | 混合風門（Mixing Damper）|
| 特殊設備 | B/P | 旁通閥（Bypass）|
| **控制閥** | AoV1×2 + AuV1×2 | 冰水+熱水雙道控制 |

#### IC-02（標準配置，無加濕）
- 與 IC-01 相似，差異：
  - 無 M/D（混合風門）
  - 無 B/P（旁通閥）
  - ISA 連接加濕器（簡化版）
  - AI 點位：Ao2（室溫+室濕）

### MAU DDC 連線說明
- DDC 連線 BUILDING 控制室（中央監控）
- DDC 依設定值控制冰水閥/熱水閥開度
- 風車採 INV（變頻）控制，依室壓調整

## SP-IC-FS02：乾式盤管 + FFU + 排氣控制圖

### IC-03A：FFU + 乾式盤管控制（主區域）

**控制架構**：STAND-ALONE DDC，每區一個 Ao 輸出控制一組 MV（電動閥）

| DDC 點位 | 控制設備 | 數量 |
|---------|---------|------|
| Ao1 | MV（#1台 乾式盤管區）| 1台 |
| Ao3 | MV（#3台 乾式盤管區）| 3台 |
| Ao5 | MV（#2.5台 乾式盤管區）| 2~3台 |
| Ao12 | MV（#12台 乾式盤管區）| 12台 |
| Ao22 | MV（#4台 乾式盤管區）| 4台 |
| Ao27 | MV（#2台 乾式盤管區）| 2台 |
| Ao33 | MV（#1台 乾式盤管區）| 1台 |
| Ao42 | MV（#1台 乾式盤管區）| 1台 |
| DM5 | FFU（Fan Filter Unit）群組 | 多台 |

> **FFU 群組控制**：由 DDC Dm 點（數位輸出）開關，每組 FFU 共用一個控制點

### IC-03B：乾式盤管控制（次區域）

| DDC 點位 | 控制設備 | 數量 |
|---------|---------|------|
| Ao2 | MV（#2台）| 2台 |
| Ao7 | MV（#7台）| 7台 |
| Ao7 | MV（#7台）| 7台 |

| Aoi1 | MV（#1台）| 1台 |

備注（圖面手寫）：
1. 室外吸入温度感測器一個，但若各盤管有單獨控制需求，則需個別加裝 RT（室溫感測器）
2. 控制架構（STAND-ALONE）：電控箱獨立運作，DDC 控制 MV 閥；可上傳 BMS 監控，當 MV 異常時由 DDC 聯鎖警報

## 控制系統架構總結

```
┌─────────────────────────────────────────────┐
│              中央 BMS 監控                    │
└──────────────────┬──────────────────────────┘
                   │（網路通訊）
    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
  MAU DDC      乾盤/FFU DDC   排氣 DDC
  (STAND-ALONE) (STAND-ALONE) (STAND-ALONE)
    │              │              │
  冰水閥          MV閥群組        INV
  熱水閥          FFU開關
  INV風機
  TS/HS/DPS感測
```

|------|--------|------|

| 冰水控制閥（AoV）| 2 | 含回饋信號 |
| 熱水控制閥（AuV）| 2 | 含回饋信號 |
| 差壓開關（DPS）| 1 | 風車確認 |
| 溫濕度感測器（TS/HS）| 2~3 | 進出口各一 |

## 對程式設計的影響（待更新時參考）

1. **控制費用估算**：每台 MAU 需含 DDC 控制箱費用（尚無參考報價）
2. **乾式盤管控制**：以區域分組，每區一個 MV + DDC Ao 點，非每台個別控制
3. **FFU 控制**：DM（數位輸出）群組控制，非類比調節
4. **BMS 整合**：STAND-ALONE 架構可獨立運作，BMS 為選配監控
