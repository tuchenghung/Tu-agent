下載連結：https://www.kuenling.com.tw/upload-files/catalog/KLFW_V_.pdf

## B1 電力需求合計（3×200RT + 2×150RT，全部同時運轉、未計需量因數）

| 項目 | 數值 |
|---|---|
| 總輸入功率 | 3×123.3 + 2×92.6 = **555.1 kW** |
| 380V 總電流 | 3×213 + 2×160 = **959 A** |
| 440V 總電流 | 3×184 + 2×138 = **828 A** |
| 總冷媒填充量 | 3×260 + 2×195 = 1,170 kg |
| 總機組重量（B1空間驗算用） | 3×5000 + 2×3600 = 22,200 kg |
| 總運轉重量 | 3×5300 + 2×3900 = 23,700 kg |

> 電流為滿載運轉電流(FLA)，實際配電設計需另加啟動電流裕度、同時使用率(需量因數)，建議與電機技師確認變壓器容量與饋線規格。
