# 施工紀錄 SOP

現場照片 → Dropbox → Mac 自動通知 → Claude 分析 → Notion 紀錄建立

---

## 手機端（現場）

1. 現場拍完照
2. 打開 iPhone「**📸 施工照片**」捷徑
3. 選取要上傳的施工照片（非施工照不要選）
4. 照片自動存入 `Dropbox/宏祐/施工照片待處理/`

> [!tip] 捷徑設定
> 捷徑動作：選取照片 → 儲存至檔案（`Dropbox/宏祐/施工照片待處理/`）→ 顯示通知

---

## Mac 端（自動通知）

- Mac 每 **3 分鐘**自動掃描 `施工照片待處理/` 資料夾
- 偵測到新照片 → 右上角彈出通知：「📸 新施工照片就緒」
- Mac 關機時不偵測，開機後補跑一次

---

## Claude Code 執行

收到通知後，在 Claude Code 輸入：

```
/施工紀錄 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/施工照片待處理
```

### Claude 會自動完成：

| 步驟 | 動作 |
|------|------|
| 1 | 顯示案件清單，選擇照片所屬案件 |
| 2 | 將照片移至 `[案件]/M照片/YYYY-MM-DD/` |
| 3 | 逐張分析照片，產生施工描述 |
| 4 | 詢問天氣（晴／陰／雨） |
| 5 | 取得 Dropbox 嵌入連結 |
| 6 | 查詢 Notion Projects 資料庫，取得案件 ID |
| 7 | 建立 Notion 施工紀錄頁面（含照片） |

---

## Notion 施工紀錄欄位

| 欄位 | 說明 |
|------|------|
| 紀錄標題 | `案件名 — YYYY-MM-DD 施工紀錄` |
| 案件/專案 | 關聯 Projects 資料庫 |
| 日期 | 施工日期 |
| 工項 | 拆除/泥作/水電/空調/消防/弱電/天花/油漆/地坪/隔間/其他 |
| 位置/區域 | AI 從照片推測 |
| 施工內容/摘要 | AI 統整說明 |
| 天氣 | 晴／陰／雨 |
| 追蹤狀態 | 預設「待確認」 |

---

## 注意事項

> [!warning] 照片資料夾規則
> 照片必須放進 **M照片** 資料夾，不是 H照片（H照片另有用途）。
> Claude 會自動搬移，勿手動放錯位置。

> [!warning] 非施工照片
> 捷徑選照片時，**只選施工相關照片**。其他照片（如捷運、餐廳）勿選入，Claude 會分析每張，會浪費時間。

> [!info] Notion 搜尋問題
> Notion 搜尋 API 對中文標題不穩定，Claude 改用直接查詢 Projects 資料庫。若案件找不到，會跳出清單讓你手動選。
