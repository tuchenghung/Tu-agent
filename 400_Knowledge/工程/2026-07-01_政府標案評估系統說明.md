# 政府標案評估系統

> 建立日期：2026-07-01
> 對應 Notion 資料庫：[政府標案評估系統](https://app.notion.com/p/41f86280980045c38a523176fd6de199)
> Database ID：`41f86280-9800-45c3-8a52-3176fd6de199`
> 搭配 SOP：`200_Reference/templates/政府標案投標SOP.md`（Phase 2 可行性評估）

## 用途

每個政府標案在投標前，用 4 個構面快速打分，系統自動算出總分並給出「投/不投/待觀察」建議，取代單純憑經驗判斷。

## 4 構面評分（各 0-10 分，總分 40）

| 構面 | 評分重點 |
|------|---------|
| 資格合規 | 廠商資格符合度、有無拒絕往來/退票紀錄、押標金備妥狀況 |
| 財務獲利 | 預算金額、預估毛利率、與近期報價案例的行情比對 |
| 產能時程 | 工期能否配合現有工地排程、施工難度、人力調度可行性 |
| 競爭得標 | 決標方式（最有利標/最低標）、是否第二次招標、過去類似標案得標紀錄 |

## 決策建議公式（自動計算，不可手動改）

```
總分 = 資格合規_分數 + 財務獲利_分數 + 產能時程_分數 + 競爭得標_分數

總分 ≥ 28（70%）→ ✅ 建議投
總分 18-27（45-69%）→ ⚠️ 待觀察
總分 < 18 → ❌ 建議不投
```

「最終決策」欄位是手動選擇，可覆蓋系統建議（例如策略性考量、關係案件等系統評分無法涵蓋的因素）。

## 欄位總覽

- **基本資訊**：標案名稱、招標機關、標案編號、工程類型、決標方式、是否第二次招標、預算金額、截止投標日、開標日
- **4 構面**：各含「分數」+「備註」欄位，備註寫評分理由
- **自動判斷**：總分（formula）、決策建議（formula）
- **人工決策**：最終決策、狀態（評估中/已投標/得標/未得標/放棄投標）
- **後續追蹤**（對應 SOP Phase 6）：得標廠商、得標金額、未得標分析
- **關聯**：相關案件（連結「Projects（專案與指標）」資料庫）、報價案例（連結「報價案例資料庫」）
- **文件**：公告網址、標案文件路徑（Dropbox 連結）

## 使用時機

收到新標案公告 → 先在此系統開一筆記錄，填基本資訊 → 依 SOP Phase 2 評估 4 構面並打分 → 看「決策建議」欄位 → 若決定投標，後續走 SOP Phase 3-5 → 開標後回填「狀態」「得標廠商/金額」或「未得標分析」，並在 Projects 資料庫建立正式案件（透過「相關案件」關聯）。

```bash

  -H "Authorization: Bearer <NOTION_API_KEY>" \
  -H "Notion-Version: 2022-06-28" \
```
