# 龍潭1F無塵室 FFU數量不足＋回風柱共用分離式冷氣進氣 → 壓差異常40Pa 診斷

> ⚠️ **樓層澄清（2026-07-13）**：本檔案標題原寫「1F4F」，經比對施工圖面確認，130m²/18台FFU（全數1200×600mm）這個問題房間是**1F**主無塵室（對照 `K施工圖面/...-1天花板配置圖.pdf`，圖面FFU數量20台，數量相近）。**4F 另有一個獨立的小無塵室（20.7m²，5台1200×600mm+1台600×600mm=6台FFU，覆蓋率19.1%/ACH93.7次/hr，符合Class 10,000且有餘裕）**，配置正常、與本檔案診斷的壓差問題無關，詳見 [[2026-07-13_龍潭4F無塵室FFU配置驗算]]。兩者是同案不同樓層的獨立房間，不可混淆。

## 一、房間基本條件

| 項目 | 數值 |
|---|---|
| 淨面積 | 130 m² |
| 淨高 | 3 m |
| 室內體積 | 390 m³ |
| 目標潔淨等級 | Class 10,000（ISO 7）|
| 設計條件 | 22°C / 50%RH（露點11.1°C）|

## 二、FFU數量核算

採用 **FFU-T15M**（1200×600mm，15 CMM=900CMH/台，面風速0.4m/s，規格出處：`2026-06-03_FFU風車濾網箱規格與報價參考.md`）

```
Class 10,000 標準 ACH = 75次/hr（庫內既有算例precedent值，落在通用範圍40-100內）
需求風量 = 390m³ × 75 = 29,250 CMH
應設台數 = 29,250 ÷ 900 = 32.5 → 33台
覆蓋率驗證 = 33×0.72m² ÷ 130m² = 18.3%（落在Class10,000建議15-20%區間內）
```

**現場實際只有18台**：
```
實際風量 = 18×900 = 16,200 CMH
實際ACH = 16,200÷390 = 41.5次/hr（勉強壓在40-100下限）
實際覆蓋率 = 18×0.72÷130 = 9.97%（低於15-20%要求下限）
```

**判定**：18台無法穩定達成Class 10,000（覆蓋率不足，氣流均勻度會有死角），但ACH與覆蓋率都舒適超過Class 100,000（ISO8）要求（ACH10-25、覆蓋率5-8%），**建議降級為Class 100,000**。

## 三、回風柱風速異常與壓差40Pa根因

**回風柱精確規格**（現場實量）：1×0.54m×0.65m(0.351m²) + 3×0.39m×0.70m(0.273m²×3=0.819m²) = 合計 **1.17 m²**（先前估算值0.27m²×3+0.35m²×1=1.16m²，誤差可忽略）

**根因1：回風柱斷面積對FFU回風需求本身就偏小**
```
FFU回風風速 = 16,200CMH÷3600 ÷ 1.17m² = 3.85 m/s
```
超過常規回風柱設計風速上限（2.5~3.5m/s）。

**根因2：回風柱進氣端與分離式冷氣（8.6kW室內機）共用，且為原始設計**
- 分離式冷氣**進氣端**（已現場確認，非送風端）**原始設計**就接在回風柱上（非現場違規加裝），量測當下**仍在運轉**
- 依和平案FXV-40實績（4.0kW額定→15.0CMM/900CMH，出處`2026-05-24_和平案空調工程圖說規範比對.md`）等比例反推：
  ```
  8.6kW室內機風量估算 = 8.6 × (900÷4.0) = 1,935 CMH
  ```
- 合併負載：
  ```
  總負載 = 16,200 + 1,935 = 18,135 CMH = 5.04 m³/s
  修正後回風風速 = 5.04 ÷ 1.17m² = 4.31 m/s（超出設計上限約45%）
  ```

**結論**：回風柱斷面積在設計階段就沒把分離式冷氣的進氣負載算進去，屬**設計階段容量核算遺漏**，非施工缺失。這是現場量測壓差達40Pa（遠高於通用知識庫壓差標準：潔淨區對一般空間10-15Pa、Class1,000對大氣25Pa）的直接根因。

## 四、MAU排除為成因（現場驗證）

- 現場實測：MAU風門開/關，室內壓差**無變化**
- 已確認風門實際有風量進出（排除機械故障/訊號脫鉤可能）
- **結論：正式排除MAU為此壓差問題成因**。依三控分離架構設計理論，MAU-排氣平衡本應是壓差主導機制、FFU不應影響壓差；但現場異常洩流路徑（回風柱受阻）的影響力已蓋過設計預期的MAU控制權，代表壓差目前完全由FFU循環風受阻主導。待回風路徑問題排除後，MAU-排氣平衡機制才會重新拿回壓差控制主導權。

## 五、最終定案方案（回風柱擴大不可行）

**限制條件**：現場條件不允許擴大回風柱斷面積，方案B（擴大至1.3~1.5m²達標3.0~3.5m/s）**排除**。

| 措施 | 效果 | 狀態 |
|---|---|---|
| 分離式冷氣進氣脫離回風柱 | 回風風速 4.31→3.85 m/s（改善約11%，仍超標）| ✅ 執行 |
| **增加壓力平衡氣**（洩壓風門或60×60固定回風口，洩往更衣室方向）| 主動洩除殘餘壓力堆積，是唯一能讓壓差回到正常範圍的手段 | ✅ 執行，**升級為關鍵措施**（非輔助）|
| 洩壓方向 | 更衣室在走廊側、壓力低於本房間，**方向已確認正確** | ✅ 確認 |
| 洩壓風門開啟門檻 | 建議設低段0.5~1.0mmWG（≈5~10Pa），避免本房間壓力降到目標值(10-15Pa)後風門不開、更衣室收不到補氣 | 待設定 |
| 調整MAU/排氣閥 | 已驗證對壓差無效 | ❌ 不執行 |
| FFU台數18→33台 | 影響潔淨等級（現況僅達Class100,000水準），不影響壓差 | 另案處理，降級為Class 100,000 |

**策略總結**：回風柱先天斷面不足且無法擴大，策略由「降低阻力」改為「分離負擔＋主動洩壓」雙軌並行，洩壓路徑（風門/回風口）是現況下唯一能讓壓差回歸正常範圍（潔淨區對一般空間10-15Pa）的關鍵手段。

## 六、洩壓風門裝設方案細節

### 6.1 分兩處裝設（入口更衣室＋出口更衣室）

- 技術上可行，且優於單一大開口：分散後單處風速更低、噪音/亂流較小，並有備援（一處堵塞另一處仍可運作）
- **前提**：兩間更衣室壓力都必須低於本房間（同前述更衣室方向確認邏輯），須個別核對，不可假設兩邊都低於本房間
- 若僅其中一間實測壓力不足（如先前3Pa案例），另一間本來就足夠：**不建議平均分配**，應加大缺氣那間的開孔面積或僅裝該側，避免稀釋效果

### 6.2 可裝在門片上

- 業界標準做法（門用洩壓風門/Transfer Grille），不需破牆破天花，剛好卡在人員動線過渡點
- **前提確認**：該門若為防火區劃邊界之防火時效門，**不可自行開孔**，須採購整組通過CNS/UL認證的防火型洩壓風門總成，依原廠認證固定尺寸施作，否則喪失防火時效
- 一般非防火區劃內部隔間門則無此限制，可用一般規格品（現貨品，非訂製）
- 建議安裝於門片中下段置中位置，避開鉸鏈/鎖具/門框結構補強料，方便日後維護校正彈簧張力

### 6.3 安裝步驟（門片開孔式）

1. 定位畫線（避開結構料），開孔尺寸依風門選型（彈簧式專用洩壓風門約20×20~30×30cm即可，效率較固定格柵高，不需開到60×60）
2. 開孔（線鋸機/開孔鋸，金屬門片注意保溫材/補強料，切割後處理毛邊）
3. **若門片為庫板（岩棉/PU發泡夾芯板）材質，開孔後芯材外露，必須先用鋁製收邊條收邊＋矽利康氣密封閉**，才能崁入風門本體——外露芯材會持續逸散纖維/發泡粒子汙染潔淨室，且會讓氣流繞過風門本體導致壓力門檻校正失準
4. **收邊順序須在風門裝設之前**，先收邊、後裝風門，避免風門框裝上去後收邊條無法施工，需拆兩次工
5. 風門框崁入開孔、鎖固，四周再做第二層氣密處理
6. 校正彈簧張力，設定開啟壓力門檻（建議0.5~1.0mmWG≈5~10Pa）
