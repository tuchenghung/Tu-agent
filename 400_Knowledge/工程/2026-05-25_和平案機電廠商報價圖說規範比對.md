## 四、規格比對

### 4.1 給水管材壁厚（SUS#304）

```
Ø13mm → 0.8t
Ø20mm～Ø25mm → 1.0t
Ø30mm～Ø50mm → 1.2t
Ø65mm以上 → SCH10S
```

嵩泰報價對照：

| 管徑 | 規範要求 | 報價標示 | 是否符合 |

| ∮20 | 1.0t | 1.0mm-t | ✓ |
| ∮25 | 1.0t | 1.0mm-t | ✓ |

## 八、未來相似案件參考要點

1. **醫院病房整修機電發包**，衛生設備本體通常是業主自購，廠商只報安裝。若業主未自購，衛生設備本體缺口極大（15項 × 23-25個 ≈ 估計 80-150 萬）。
2. **給水管壁厚規範**：SUS#304壓接管 Ø30mm起要 1.2t，廠商常報 1.0t，須在合約中明訂依圖施作。
3. **消防撒水頭**一定要對圖面數量，差幾頭在驗收時容易被刁難。
4. **PVC-M1電纜線槽**是醫療院所弱電工程的標準要求，一般 PVC 線槽不符合，注意品牌送審。
5. 嵩泰機電消防項目數量與發包圖高度一致（除撒水頭差1頭），表示廠商有詳細對圖。
