# 雙系統同步架構｜Mac + Windows

> 建立日期：2026-05-10（pro-kit 07）
> 狀態：✅ 運作中

## 是什麼
讓 Claude Code 的設定、Skills、記憶在 Mac 和 Windows 之間自動同步的架構。

## 架構圖

```
~/.claude/ (Mac)                    .claude/ (Windows)
├── settings.json ──→ symlink      ├── settings.json（複製版）
├── commands/     ──→ symlink      ├── commands/ ──→ Junction
├── keybindings.json → symlink     └── skills/   ──→ Junction
└── skills/       ──→ symlink
         ↓                                  ↓
    Dropbox/Tu-agent/（母體）        D:\Dropbox\Tu-agent\
```

## 同步管道
- Dropbox（Mac + Windows 跨系統）
- GitHub 私有 repo：`tuchenghong/Tu-agent`（版控備份）

## 自動化
- Mac：cron 每週五 09:00 執行 `sync-health.sh` 體檢
- Windows：開機執行 `claude-startup.bat`，偵測 symlink 是否設定

## 踩坑紀錄
- Windows 檔案 symlink 需要系統管理員權限，`mklink` 仍可能失敗 → 改用 `Copy-Item` 複製 `settings.json`
- Windows Dropbox 在 D: 槽（非 C:），路徑偵測需明確加入 `D:\Dropbox\Tu-agent`
- PS1 腳本含中文 here-string → Windows 編碼錯誤，改為全英文
