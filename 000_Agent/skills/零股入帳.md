# 零股入帳 Skill

自動從玉山證券成交通知 Email 讀取交易紀錄，寫入 Notion 各個股頁面的「零股買進明細」表格。

---

## 執行步驟

### STEP 1：解析玉山成交 Email

```bash
python3 /Users/tuzhenghong/Library/CloudStorage/Dropbox/Tu-agent/000_Agent/scripts/parse_esun_email.py --days 2
```

- 讀取 Mac Mail（Exchange/Hotmail 帳號）最近 2 天的玉山交易明細通知
- 輸出 JSON array，每筆成交一個物件
- 欄位：成交日期、股票代號、股票名稱、成交股數、成交單價、淨收付金額

若無成交紀錄，回報「近 2 日無新成交」並結束。

---

### STEP 2：查詢 Notion 對應個股頁面

對每筆成交，使用 `mcp__notion__API-post-search` 搜尋股票名稱：

```
query: "{股票名稱}"  （e.g. "格斯科技"）
filter: { property: "object", value: "page" }
```

從結果中找標題包含該股票名稱的頁面（通常格式為「股票名稱（代號）」）。

記錄該頁面的 `page_id`。

---

### STEP 3：找到「零股買進明細」表格的 block_id

使用 `mcp__notion__API-get-block-children` 取得該頁面的所有 block：

掃描 block list，找到：
1. 段落 (paragraph) 文字包含「零股買進明細」
2. 緊接在其後的 table block

記錄該 table block 的 `id`（這是要 append 新行的目標）。

---

### STEP 4：防重複檢查

使用 `mcp__notion__API-get-block-children` 讀取表格所有既有行 (table_row)，
檢查是否已存在相同的：成交日期 + 成交股數 + 成交價。

若已存在 → 跳過，告知使用者「{日期} {股票} {股數}股 已存在，跳過」。
若不存在 → 繼續 STEP 5。

---

### STEP 5：在 Notion 表格新增一行

使用 `mcp__notion__API-patch-block-children`，對 table block 新增一個 `table_row`：

```json
{
  "children": [
    {
      "type": "table_row",
      "table_row": {
        "cells": [
          [{ "type": "text", "text": { "content": "{成交日期}" } }],
          [{ "type": "text", "text": { "content": "{成交股數}" } }],
          [{ "type": "text", "text": { "content": "{成交單價}" } }],
          [{ "type": "text", "text": { "content": "{淨收付金額}" } }],
          [{ "type": "text", "text": { "content": "" } }]
        ]
      }
    }
  ]
}
```

欄位對應（5 欄）：
| 欄位 | 內容 |
|------|------|
| 成交日期 | `成交日期`（格式 YYYY/MM/DD） |
| 股數 | `成交股數` |
| 成交價 | `成交單價` |
| 成本（元） | `淨收付金額`（含手續費，負值表示付出） |
| 委託書號 | 空白（信件未提供，可手動補填） |

---

### STEP 6：更新表格標題的筆數

找到段落 block「═══ 零股買進明細（N 筆）═══」，更新 N 為新的總筆數。

使用 `mcp__notion__API-update-a-block` 更新該 paragraph block 的 rich_text。

---

### STEP 7：回報結果

```
✅ 零股入帳完成

新增紀錄：
  - 2026/05/22 格斯科技（6940）　300股 × 22.65　成本 -6,804

跳過（重複）：無

委託書號欄位為空白，可至 Notion 手動補填。
```
