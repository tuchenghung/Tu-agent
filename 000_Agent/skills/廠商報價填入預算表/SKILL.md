# 廠商報價填入預算表

先讀 [報價共用規則](../報價單輸入資料庫/references/quote-analysis.md)。已授權批次處理就連續完成，關鍵歧義只暫停相關項目；只要求比較或預覽不寫檔。報價入庫不產生帳務，公司記帳僅 YASHI／YUSHI。

## 1. 來源與即時檔案

- 保留原報價／歷史價格的ID、版次、原項次與頁碼／儲存格。尚未分析入庫則接報價入口，已有紀錄沿用。
- 原數量、單位、單價、複價、折讓、稅額與總額分別保留；重算差額另列，不能自行宣告成交額改變。稅別衝突先釐清。
- 使用當次 Spreadsheet 能力讀目標即時狀態、公式、合併格、隱藏列欄、列印區與跨表引用，不沿用上次列號。
- A–G對外、H–L成本只是既有宏祐範本例子，不是固定規則；每檔定位真正非輸出成本區。

## 2. 分流與映射

- 公共正式標單或已核定清單：保留原項次、品名、規格、單位、數量及列結構，只填內部成本區。
- 明確可重編的一般草稿：可在授權區以實際工項取代占位列；不能因廠商漏報刪除業主原需求。
- 用途未知先保護正式區，核對後才改結構。
- 完全對應：廠商數量只填成本數量；設計量、廠商量、對外量各自留來源，不自動互相覆蓋。
- 合包對多列：內部補充表記整包總額並映射各項次，只計一次；無拆價依據不平均攤單價、不挑近似列硬塞。
- 多報列成本差異項；漏報標未報價、不填0、不清空正式列。一般草稿中已確認不需保留的占位列才可整理。
- 規格、單位、範圍不同須有換算依據才能填調整成本，不靠同名匹配。

## 3. 寫入及輸出

原則另存工作副本；已授權覆寫時保留可恢復版本。不得改未授權的正式數量或售價。

草稿增刪列需檢查整個活頁簿的公式、命名範圍、合併格、列高及列印區；不要用正規表示式全面移動公式列號。依工具能力處理並重新計算或獨立驗算；不能將舊公式快取當作新結果。不支援巨集或其他原檔功能的工具不可直接覆寫原檔。

成本、議價、配價依據放內部區，不放對外G欄。隱藏欄不等於已移除成本；對外Excel另產乾淨副本，檢查隱藏頁、公式、連結，PDF檢查列印範圍及版面。

## 4. 驗收及售價

讀回映射及明細、小計、折讓、稅額；差額不湊平。對照正式區改前改後及公式。回報實際改動欄位、已填／待補項、驗算及成果檔；若改過數量或公式，不得固定宣稱「報價區沒有動」。

只有使用者明確指定售價或方法才填對外單價。歷史售價仍需比對條件，不自動套同廠商加價率或30–40%毛利。區分加價率與毛利率，記核定方法、取位及稅別；成本不是售價。
