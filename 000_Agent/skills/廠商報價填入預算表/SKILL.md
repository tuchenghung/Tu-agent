# 廠商報價填入預算表

宏祐集團工程預算報價表固定格式（見 `reference_quote_excel_template.md`）：A-G欄是給業主看的「報價區」（項次/名稱/單位/數量/單價/總價/備註），H-L欄是內部用的「成本區」（成本數量/成本單價/成本總價/毛利/毛利率）。本skill處理「廠商報價 → 成本區」這段，報價區怎麼定價是business decision，交給使用者主導。

## 觸發條件

- 使用者提供廠商報價檔案（PDF/圖片/xlsx）+ 一份既有的 `D預算報價/` 底下的 xlsx 路徑
- 訊息含「依照廠商報價填入成本區」「照今天的方法」「報價區我來填/我會指示你」等字樣

## SOP 步驟

### STEP 1：讀取廠商報價單，逐項列出品項/單位/數量/單價/金額

用 `Read` 工具讀 PDF/圖片（Claude 直接看內容），或 openpyxl 讀 xlsx。列出每一項的品名、單位、數量、單價、金額，並加總比對是否等於廠商單上寫的「合計」。

**逐項驗算金額＝單位價×數量，不要照單全收廠商寫的「複價/金額」欄**：曾發生廠商Excel裡有兩格是殘留舊值（沒有隨公式更新），複價欄跟數量×單價對不起來，且錯誤還連動污染了後面的手續費/管理費公式與報價總額。如果驗算不合，用「數量×單價」重新算出正確值，並在回報時明確告知使用者「廠商單本身有誤，正確總額應為XXX非廠商寫的YYY」，不要因為要湊廠商寫的總額而扭曲個別品項數字。

留意廠商單上「部分項目含稅、部分未稅、另計稅金」這種混合稅務標示（常見於設備類報價），照實記錄不要自行換算合併，並在備註/回報中提醒使用者這個狀態。

### STEP 2：讀取目標預算表現況

用 openpyxl（`data_only=False`）讀出目標 xlsx 對應章節（例如「甲.柒 消防工程」「甲.陸 空調工程」）目前每一列的 A(編號)/B(品名)/C(單位)/D(報價數量)/E(報價單價)/F(報價總價公式)/G(備註)/H(成本數量)/I(成本單價)/J(成本總價公式)/K(毛利公式)/L(毛利率公式)。

**在動手改之前，一定要重新讀取檔案的即時狀態，不要沿用上一輪對話記住的列號**——這份檔案可能在對話輪次之間被使用者用 Excel 打開手動編輯過（曾發生使用者插入空白分隔列、把寫死的小計金額改成即時SUM公式，導致列號跟上次不一樣）。

### STEP 3：品項對應——照廠商原文填，不要勉強塞進舊分類

逐一比對廠商品項跟預算表既有列的品名：

- **完全對應**（品名/性質一致）→ 直接把數量填入 D 與 H（報價區數量／成本區數量共用同一個物理數量，只是單價欄位D/E跟H/I分開），單價填入 I，備註可留白或視需要加註
- **部分對應但廠商合併了幾個子項**（例如廠商把「銅管+控制線」寫成一筆，但預算表拆成兩列）→ 挑一個較貼切的列放全部金額，另一列在G欄註明「費用已併入OO列（廠商合併報價未拆分）」
- **完全對不上、預算表沒有對應列**（廠商多報了一個預算表沒預留位置的項目）→ **不要因為找不到合適列名就硬塞**，兩種處理方式擇一：
  1. 若預算表同分類下還有其他「用不到的空白占位列」→ **直接覆蓋改寫**那一列的 A/B/C（編號/品名/單位），改成廠商的原文品名，不要保留原本猜測性質的占位名稱
  2. 若空白列不夠用 → 用 `ws.insert_rows()` 插入新列（見 STEP 4 的公式修正流程）
- **預算表原有列廠商沒報到** → 清空整列（A~L 全部設 None），不要留著不相關的舊占位名稱＋一堆「廠商未列此項」的備註造成報表雜亂。**這是使用者2026-08-30明確糾正的做法**：一開始把湊不齊的品項勉強塞進「戶外置放架」之類不相關舊分類、又為了另一個湊不進去的品項另外insert新列，被使用者說「原本有空調項目可以覆蓋」——意思是預算表原本11個占位品項只是草稿架構，廠商報價幾項就用幾列、直接覆蓋成廠商原文命名，多的空白列清掉，不用勉強保留舊架構

### STEP 4：插入/刪除列時的公式位移修正（必做全表掃描）

若空白列不夠必須 `insert_rows()`（或需要 `delete_rows()` 復原多插的列），這個檔案量體大、上層總表(甲/乙分類)與各段小計都有大量交叉引用公式，openpyxl 插入/刪除列**不會**自動更新公式裡的儲存格參照（見 `reference_openpyxl_row_insert_formula_bug.md`），必須手動修正：

```python
import re
pattern = re.compile(r'(\$?[A-Z]{1,2}\$?)(\d{1,4})')
def shift_formula(formula, insert_at, n, sign=1):
    def repl(m):
        col, row = m.group(1), int(m.group(2))
        if row >= insert_at:
            return f"{col}{row + sign*n}"
        return m.group(0)
    return pattern.sub(repl, formula)

# insert_rows(163, 5) 後：對全表每個以'='開頭的公式呼叫 shift_formula(f, 163, 5, sign=1)
# delete_rows(163, 5) 復原時：sign=-1
```

**掃描範圍是整張工作表所有儲存格，不是只改插入點附近幾列**——上層總表（如 `E16='=F167'`）跟很遠的小計公式（如消防工程小計的 `=SUM(J146:J166)`）都可能引用到位移範圍，漏改任何一處都會讓總表金額算錯且不容易發現。

新插入列要複製鄰近同類列的字型/格式（`copy.copy(cell._style)`），不要留白預設格式。

### STEP 5：驗算後才算完成

改完後，重新讀回整段（H×I 加總），核對是否等於廠商報價正確總額（STEP 1 驗算過的數字，不是廠商可能有誤的印刷總額）。對不上要抓漏項，不要略過差額。

### STEP 6：回報

列出品項對照表（品名/單位/數量/單價/對應廠商哪個原始項目），標明：
- 哪些是直接對應、哪些是合併、哪些是新增列、哪些原占位列被清空
- 稅務混合狀態（若有）
- 驗算結果是否與廠商報價（或修正後正確金額）吻合
- 明確提醒：**報價區(D/E/F)沒有動**，等使用者指示或自行填寫

## 報價區（D/E）填法——僅在使用者明確指示時才做

若使用者要求「參考OO案報價單價填入報價區」：
1. 先找到參考案件的內部預算表（含成本H/I欄的版本，不是給業主的乾淨版），Grep `400_Knowledge/工程/報價單圖說對應分析/`或直接找該案 `D預算報價/` 底下的 xlsx
2. 品名/規格完全相同的品項 → **直接沿用參考案的賣價**（同一種標準商品，公司通常用同一個報價）
3. 無直接同名品項可查 → 用參考案「同類別/同廠商」品項的「成本／賣價」加價比例，套用在本案該品項的成本上，四捨五入到合理位數（通常抓最接近十位數）
4. 每一列在G欄註明賣價依據（直接沿用 vs 比例估算 vs 哪個參考案/哪個比例），讓使用者一眼看出哪些數字是精確引用、哪些是估算
5. 完成後算一次該段落賣價/成本/毛利率，跟全案其他項目的margin水準（通常30-40%）比較，落差太大要提醒使用者
