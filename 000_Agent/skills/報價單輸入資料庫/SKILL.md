# 報價單輸入資料庫

收到報價 → 原檔／版次辨識 → 逐項轉錄驗算 → 單價分析 → 入庫及歸檔。所有廠商均執行，不以是否採用區分。先讀 [共用分析與引用規則](references/quote-analysis.md)。

已授權完整匯入時摘要後執行，不逐步重問；只預覽不寫入。缺關鍵資料只暫停受影響項目，說明未完成部分。確認報價內容或匯入不代表發包。

## 1. 辨識原檔及案件

依當次PDF／Spreadsheet能力讀原檔，不用文字讀取工具硬解二進位或固定Windows套件路徑。

記錄供應商、案件ID／集團、報價日期／編號／版次、幣別、稅別及原檔位置。民國日期轉換保留原文。相似案名不可代替唯一識別；案名select顯示完整名稱，relation才是身分依據。案件未找到可暫存待補，但不得宣稱正式入庫完成或可供新案採用。圖說未提供不阻擋算術及條件分析，規格符合性列待核對。

搜尋既有文件、明細及供應商。廠商同日可能有多案／多版，不能只以名稱＋日期認重複。核對文件雜湊／原項次／版本；完全相同沿用結果，新版留舊版，歧義才問。名稱及統編要核對來源，不因網路同名就補入聯絡資料。

## 2. 逐項轉錄及分析

保留原項次、原文品名規格、單位、數量、原單價、原複價與頁碼／工作表位置。分清小計、折讓、稅額及未報價列；未知不是0。

逐項算術與整單金額核對，原值不覆寫；差異列待確認，不自動認定重算值為核定成交額。所有品項完成基礎單價分析；有工料依據才接 [工程單價契約分析](../工程單價契約分析/SKILL.md)。

一價多項保留原整包明細及子項範圍，不漏子項、不捏造分攤或把整包價重複列在每個子項。整包數量依原文，不一律假定1。

## 3. 歸檔、文件與品項

依案件確認的集團及階段定位實際Dropbox根目錄：Windows常見 `D:/Dropbox/宏祐`、`D:/Dropbox/yushi`；Mac以實際Dropbox位置解析。規劃案常用 `F供應商報價與資料`，施工案依既有結構查證，不另建猜測路徑。

預設複製原檔並保留來源，不覆蓋已有不同版本。檔名含日期、廠商、工種、版次；若含金額，使用該版文件自身金額及已知稅別，不拿後續議價金額替原檔命名。記錄原名、歸檔相對路徑與雜湊。分享連結優先重用既有可存取連結；僅以受授權工具建立符合既有權限的連結，不讀取腳本中的憑證或擴大公開範圍。失敗標待同步，不能冒稱已完成。

在文件中心查重後建立／沿用文件頁，類別報價單；存原檔連結、版本、案件、來源、分析報告。圖說或規範文件已存在則連結，不重建。

逐項建立／沿用工程報價明細：編號、品項名稱、規格、單位、數量、單價、工種、日期、完整案名select、Projects案件relation、供應商relation、報價單及圖面relation。保留已有關聯，新增合併去重，不整組覆蓋。總價公式不寫值。

- 顯示編號可用廠商簡稱-日期-版次-序號，穩定識別依文件版次＋原行，不靠簡稱唯一。
- 現有單價欄沿用可確認的未稅基準；原價／稅額／換算依據完整保留。稅別或稅率未知不猜、不把含稅价塞進未稅欄，金額暫存在原文及待確認資訊。
- 新設計欄位未建時用備註／頁面固定章節記「來源版本、價格類型、採用狀態、分析狀態、範圍、可引用狀態」，不得自行假設schema已存在或為本次匯入改schema。
- 統編原始文字保留；number欄無法忠實存前導零時不靠轉型修復，列schema遷移待辦。工種與單位選項用當次schema，不按最接近文字強配。

## 4. 完成及恢復

分析報告沿用本案既有報告；沒有時存 `400_Knowledge/工程/報價分析/YYYY-MM-DD_案件_工種_報價分析.md`，指定位置優先。報告、原檔、Notion明細及來源關聯是完整入庫的交付，不只寫本機檔。

每步保存operationId、來源識別及已建page ID至本次操作紀錄，不存憑證。逾時先查已存在結果，保留同一識別只補缺步驟；不能重跑整份而重複建檔。原檔、報告、Notion任一未完成分別標pending。

讀回文件、明細數量、數值、來源與案件／供應商關聯，列已分析及待核對項。對話提供真實成果連結；沒有圖面或工料資料不標全部分析完整。

## 5. 發包與其他交接

只有明確選定廠商、案件範圍及成交條件才接 [廠商發包登記](../vendor-award-registration/SKILL.md)，交接來源版次、Projects ID、已核對財務案件映射、供應商ID、工項、成交含稅額與依據、核定日期及檔案。報價日期不作發包日期，成交价不覆寫原價。

現有發包／記帳入口為YUSHI：宏祐工程發包若尚無核對後的路由，整理交接資料並標待建路由，不將宏祐掛入YUSHI案件財務。只有YASHI／YUSHI實際付款且已授權才接付款流程；報價／分析／發包本身不產生現金分錄。

需要填成本接 [廠商報價填入預算表](../廠商報價填入預算表/SKILL.md)，保護公共標單原結構。
