# 報價單歸檔小助手 — 設計文件

**日期：** 2026-04-15
**狀態：** 已確認，待實作

---

## 一、目標

當使用者將報價單（圖片或 PDF）丟給 Claude 時，Claude 自動解析內容並同步寫入三個 Notion 資料庫，實現報價單的一鍵歸檔。

---

## 二、涉及的 Notion 資料庫

| 資料庫 | Database ID | 用途 |
|---|---|---|
| 工作文件中心 | `2617aebd-089f-80e8-90b1-faae6e0bc21a` | 存放報價單文件摘要頁面 |
| 供應商資料庫 | `8ed44912-2c9e-4c9a-bbd1-d7bbc1933b3b` | 存放廠商基本資料 |
| 工程報價管理系統 | `a1e36c9f-f084-4965-ac76-33e51e53f711` | 存放逐筆品項明細 |

### 現有關聯
- 供應商資料庫 ↔ 工程報價管理系統（雙向：`工程報價` ↔ `供應商`）

### 需新建關聯（首次執行時建立）
- 工程報價管理系統 → 新增「來源文件」Relation 欄位 → 雙向連回工作文件中心

## 三、完整工作流程

### 使用者操作
1. 在 Claude 對話中丟入報價單（圖片貼入 或 指定 PDF 路徑）
2. 告知工程案件名稱（例如：「這是南港實驗室GTP工程的報價」）

### Claude 執行步驟

```
① 解析報價單
   └─ 用視覺辨識提取：廠商名稱、統編、電話、地址、聯絡人、
      報價日期、報價單號、每筆品項（品名、規格、單位、數量、單價）

② 列出摘要供使用者確認
   └─ 顯示：廠商、日期、品項數量、合計金額、工程案件

③ 使用者確認後，依序寫入 Notion

④ 工作文件中心 — 建立文件頁面
   └─ 文件名稱：YYYYMMDD+案名簡稱+工種+報價-廠商縮寫
      （例：20251230南港實驗室空調工程報價-嘉祿）
      • 案名簡稱：保留能區分不同期工程的關鍵詞（如「南港實驗室GTP實驗室修改工程」→「南港GTP實驗室」）
      • 廠商縮寫：公司名稱前兩字（如「嘉祿工業股份有限公司」→「嘉祿」）
   └─ 類別：報價單
   └─ 頁面內文條列：
      • 原始檔案名稱（提示使用者手動上傳）
      • 合計：NT$ XXX（未稅）
      • 報價日期：YYYY-MM-DD
      • 廠商：XXX
      • 工程案件：XXX

⑤ 供應商資料庫 — 查詢或建立廠商
   └─ 以廠商名稱搜尋是否已存在
   └─ 若存在但有空白欄位 → 上網搜尋補齊
   └─ 若不存在 → 新建一筆 → 上網搜尋補齊
   └─ 填入欄位：供應商名稱、統編、電話、地址、聯絡人、
      電子郵件、網址、工種類別（依品項判斷）
   └─ 合作狀態預設：評估中（新廠商）
   └─ 搜尋不到的欄位：通知使用者

⑥ 工程報價管理系統 — 逐筆建立品項
   └─ 每筆品項建立一列，填入：
      編號、品項名稱、品項規格、工種、單位、數量、單價、
      報價日期、工程案件名稱、產品歸類、類別（報價單）
   └─ 關聯：供應商（連結至⑤的廠商）、來源文件（連結至④的頁面）

⑦ 回報結果
   └─ 成功建立 N 筆品項
   └─ 廠商狀態（已有/新建/補齊哪些欄位）
   └─ 文件頁面連結（提醒手動上傳原始檔案）
```

## 四、欄位對應細則

### 工作文件中心
| 欄位 | 值 |
|---|---|
| 文件名稱（title） | `YYYYMMDD案名工種報價-廠商縮寫` |
| 類別 | 報價單 |

### 供應商資料庫
| 欄位 | 來源 |
|---|---|
| 供應商名稱 | 報價單抬頭 |
| 統編 | 報價單（若有） |
| 電話 | 報價單 或 網路搜尋 |
| 手機 | 報價單 或 網路搜尋 |
| 地址 | 報價單 或 網路搜尋 |
| 聯絡人 | 報價單（若有） |
| 電子郵件 | 網路搜尋 |
| 網址 | 網路搜尋 |
| 工種類別 | 依品項內容自動判斷（multi-select） |
| 合作狀態 | 評估中（新廠商預設） |

### 工程報價管理系統
| 欄位 | 來源 | 說明 |
|---|---|---|
| 編號（title） | 自動產生 | `廠商縮寫-YYYYMMDD-序號`，例：嘉祿-20251230-01 |
| 品項名稱 | 報價單品名欄 | |
| 品項規格 | 報價單規格欄 | |
| 工種 | Claude 自動判斷 | 對應現有 26 個選項 |
| 單位 | 報價單單位 | 若選項不存在則新增 |
| 數量 | 報價單數量 | |
| 單價 | 報價單單價（未稅） | |
| 總價 | 公式自動計算 | 不需填入 |
| 報價日期 | 報價單日期 | 民國年自動換算西元 |
| 工程案件名稱 | 使用者告知 | 對應現有選項，若不存在則新增 |
| 產品歸類 | Claude 自動判斷 | 對應現有選項 |
| 類別 | 固定 | 報價單 |
| 供應商 | Relation | 連結至供應商資料庫 |
| 來源文件 | Relation（新建） | 連結至工作文件中心 |

## 五、Schema 異動

首次執行時，Claude 將自動在 **工程報價管理系統** 新增：
- 欄位名稱：`來源文件`
- 類型：Relation（雙向）
- 目標資料庫：工作文件中心

---

## 六、已知限制

1. **無法自動上傳原始檔案**：Notion API 不支援檔案上傳，使用者需手動將原始 PDF/圖片拖入工作文件中心的文件頁面。
2. **廠商網路搜尋**：若廠商資訊網路上找不到，Claude 會列出缺少的欄位通知使用者補填。
3. **工程案件名稱**：若使用者未告知，Claude 會在步驟②詢問，不猜測。

## 七、範例

**輸入：** 嘉祿工業股份有限公司報價單（2025-12-30，3筆乾盤管）+ 「南港實驗室GTP工程」

**輸出：**
- 工作文件中心：`20251230南港GTP實驗室空調工程報價-嘉祿`
- 供應商資料庫：嘉祿工業股份有限公司（新建，補齊資料）
- 工程報價管理系統：3 筆品項（嘉祿-20251230-01 ~ 03），工種：空調工程
