# 工程單價契約分析

裝修/建築工程標單上每一列品項（例如「C1天花板，暗架，矽酸鈣板，耐燃一級，批土，白色乳膠漆」）通常只有一個總單價，但發包核價、跟廠商核對、或判斷單價是否合理，需要把它拆成工料組成（骨架/板材/人工/批土/油漆…），並標明各項屬於人工、機具、材料還是雜項。這個 skill 把拆解流程、驗算規則、輸出格式固定下來，避免每次臨時現想公式、格式跑掉、或悄悄湊數字而不說明依據。

**與「系統傢俱單價試算」skill 的分工**：FIX家具/系統傢俱（W×D×H尺寸換算台尺、加成30%簡易法）用另一個 skill；本 skill 專門處理**一般裝修/建築工程品項**（天花板、隔間、圍籬、玻璃工程、金屬工程等），一律用**契約單價分析表格式**，不用加成法。

## SOP 步驟

### 1. 確認案件與定位

對照案件名稱找到 `400_Knowledge/工程/報價單圖說對應分析/` 對應的既有分析檔案。找不到對應案件檔案、或只收到簡稱時，先問使用者案件全名，不要用簡稱猜測建檔。

### 2. 查詢知識庫基準

動手拆解前，先 Grep：
- `400_Knowledge/工程/建材規格/`（同材質/工法的行情基準）
- 同案件檔案裡既有章節（本案其他項次是否已用過同款材料/單價，優先沿用，不要重新查一次造成同案件同材料兩個不同單價）

**沒有資料庫依據時，用 WebSearch 上網查價**，不要直接憑空抓數字。查到的單價一律在備註標明來源網址與查詢日期，並提醒「網路查價，非本案廠商正式報價」。若網路也查無明確行情（例如小眾/客製化工法），才退回市場概估反推，並如實標明「無公開行情，市場概估」。

網路查到的單價完成本次拆解後，比照 [[feedback_websearch_price_must_record]] 原則，用 `/工法入庫` 存回 `400_Knowledge/工程/建材規格/`，備註「網路查價」＋來源網址／日期，避免下次同材料又要重查一次。

### 3. 拆解工料組成

依品項描述文字（材質、工法、施工方式關鍵字）列出合理的工料清單，常見類別：

| 類別 | 範例 |
|------|------|
| 骨架/結構 | 輕鋼架、C型鋼、鋁框骨架、鋼構承載 |
| 面材/板材 | 矽酸鈣板、玻璃、金屬烤漆板、愛克板 |
| 安裝人工 | 骨架安裝、封板人工、吊裝 |
| 表面處理 | 批土、油漆、面貼 |
| 五金/配件 | 收邊條、燈條、變壓器 |
| 雜項 | 損料、清運、垂直運輸、五金耗損 |

每個工料項目抓一個單價（沿用本案同款單價 > 資料庫行情 > 市場概估反推，並標明來源）。

### 4. 分類人工／機具／材料／雜項

**計算方式是整項歸類加總**：每一項工料本身整項歸到材料/人工/機具/雜項四類之一，再把同類別的複價加總得出小計——**不是套用固定比例分攤到總價**，也不是把單一工料項目拆成多個子比例分別歸入不同類別（士林TOD案曾誤套項次16-19「反推自使用者確認版」的21.05%/8.95%/60%/10%比例分攤法，那只是那組品項的特例，不是通用方法論）。

**分類判斷原則**：
- **材料**＝會變成永久結構/成品的實體建材（板材、五金、防水材等）
- **人工**＝現場或廠內施工人力（組裝、安裝、丈量放樣、結構計算與簽證等專業服務費）
- **機具**＝設備/器材租用或使用性質（吊車、施工架、**安全防護器材/安全母索固定點**等），**不要籠統丟進雜項**——吊車、安全防護器材本質上都是機具/設備
- **雜項**＝真正無法歸類的零星管理/協調/保險費用，應該是分類到最後剩下的少數項目，**不是預設分類**，遇到不確定的項目先想「這是不是設備/器材性質」再決定要不要放機具，不要圖方便都丟雜項
- 「現場吊裝與安裝」這種**複合工序**（同時包含操作吊車設備與人力安裝）不是整項二選一歸機具或歸人工，而是要先問使用者拆分比例（士林TOD案使用者指示30%機具/70%人工）
- **「不要拆分材料施工」≠放棄精確歸類**（2026-08-10士林TOD案第48項）：使用者說「不需要再拆分施工材料」時，是指**不要把一個工料行拆成材料+施工兩個獨立列**（避免行數暴增），不是要求全部項目都塞同一類。保持原本行數的前提下，每一整行仍要判斷歸屬（例如「XX，供料含安裝」這種連工帶料描述，若是實體板材/骨架→整項歸材料；若描述是純施工/加工服務動作→整項歸人工），不能因為不拆分就讓某一類別佔比失衡（如全部歸材料導致材料佔98%）。

**機具小計不可為$0**（2026-08-06使用者糾正）：施工不會沒有使用工具，即使清單裡沒有吊車/施工架這種大型機具，手工具/小型機具使用費仍是必要成本。**預設做法：從人工小計抓10%轉為機具**——挑一個安裝/施工性質的人工線項，扣掉「人工小計×10%」的金額另立一行「施工手工具/小型機具使用費」歸機具類，讓小計不再是$0。若清單裡本來就有吊車/施工架/安全防護器材等明確機具項目，就不用再另外抓10%（已經有實質機具項目了，不要疊加）。

**⚠️「提列/轉列」必須是零和調整，不是憑空新增**（2026-08-06、2026-08-10兩度發生同一錯誤）：不論是機具10%抓取、或雜項固定金額提列，本質都是「把來源項目的一部分金額移到另一個類別」——來源項目金額必須同步減少對應數字，新類別的金額才不會是重複計算出來的。2026-08-10士林TOD案第48項曾把「金屬骨架施工」維持原始全額，又另外新增一行「機具$137,046」，導致逐行加總比複價合計多算$137,046。**ALWAYS**：任何提列/轉列動作做完後，不能只看小計文字或心算，一定要用程式把所有工料行的數量×單價實際加總一次，確認精確等於複價合計/既有Excel單價，才能進入下一步（呈現或寫入）。

小計欄位在Excel「契約單價分析表」分頁採**純文字**格式（如`人工：X　機具：Y`），不用公式，跟既有項次風格一致。

### 5. 核對總價（**只用契約單價分析格式，不用加成法**）

- 加總工料複價 vs 既有Excel單價（或廠商報價）比對
- **差距在合理範圍內（約±10%以內）**：用「雜項」項目吸收尾差，讓複價精確湊回既有單價，並在備註說明尾差對應的可能原因（不要不說明就默默湊數字）
- **差距過大（>15-20%）**：不強制湊數，如實列出兩個數字與差距金額/百分比，列出可能原因供使用者判斷，另外提醒確認——不能為了讓表格好看而扭曲拆解邏輯
- 使用者若提供「使用者版本」數字（例如像六-1甲種圍籬案例，使用者直接給出正確的人工/機具/材料/雜項分類），以使用者版本為準，AI初版標明「取代AI初版反推分析」

### 6. 驗算複價

數量 × 單價 = 複價，必須與 Excel 既有複價一致（若不一致要在備註點出差異）。

### 7. 標注單價來源

逐項備註來源類別，四選一：
- 使用者提供／確認
- 沿用本案第X項同款單價
- 資料庫查價（附連結 `[[檔名]]`）
- 市場行情反推（非正式報價）

非「廠商正式報價」的一律加 ⚠️，並在待辦列「正式發包前需與OO廠商核對」。

### 8. 先在對話框呈現表格，等確認後才寫入

完成拆解後，**先用表格呈現在對話裡給使用者看**，不要自動寫檔案。口頭說「單價分析」「拆這項」不等於授權寫入任何檔案，要等使用者明確說「寫入」「寫回」「幫我存進XX」才動手（[[feedback_record_only_no_modify]]）。

**知識庫（.md）跟Excel是兩個分開的寫入目標，各自需要明確指示，不能因為授權了一邊就順便寫另一邊**：
- 只說「記錄/拆分/做表格」→ 只在對話呈現，兩邊都不寫
- 說「寫回Excel」「存進OO.xlsx」且指定明確路徑 → 只寫Excel，知識庫視情況（若該案件已有既有分析檔案在同步維護，仍應補上，除非使用者說不用）
- 說「寫入知識庫」「入庫」 → 只寫.md
- 兩邊都要時使用者通常會分兩句話講清楚，不確定就問

**方向性指示不等於數字授權**（2026-08-06士林TOD案C3/C4曾誤判）：使用者說「依照XX邏輯修正」「綜合雙方優點」這類方向性指示，只是**授權方法/格式**，不是授權裡面的具體單價/金額——只要有任何一項因為新規則（例如10%機具）或新指示而**重新算出一組新數字**，就是全新內容，使用者沒看過就不算確認過。即使前面已經對規則本身取得確認，連續處理多個項次時，每一項次各自最終算出的表格都要重新貼出來等看過，不能因為「規則剛剛才確認過」「前一項才過關」就對後面幾項跳過這一步直接寫入。

寫入Excel前務必核對路徑是否為「複製/副本」檔案；若使用者要求寫入非複製的原始檔，依 [[feedback_never_overwrite_without_explicit_confirm]] 提醒先確認是否要另存新檔。用 openpyxl 寫入時依 [[feedback_xlsx_openpyxl_safe_editing]]：寫入前掃 MergedCell，存檔後比對其他分頁的維度/公式數量未變動。

### 9. 確認後寫入知識庫檔案

- 接續案件檔案既有章節編號，新工項類別另開一節（例如已有六/七/八章，新增就是「九、XX工程單價分析」）
- 段落固定結構：
  ```
  ### X-Y、項次N 品項描述（樓層/位置）

  **位置**：Excel「詳細表」第X列，備註「...」，單分欄有V標記，單位...，數量...，單價$...，複價$...。

  #### 成本組成（依Excel既有單價拆分/AI依市場行情反推，YYYY-MM-DD）

  | 工料名稱 | 單位 | 數量 | 單價 | 複價 | 工料分類 |
  |---|---|---|---|---|---|
  | ... | | | | | 材料/人工/機具/雜項 |
  | **複價合計** | | | | **$X/單位** | |

  **人工/機具/材料/雜項小計**：
  > 人工：　　　$X　　機具：　　　　$X　　　　每 單位 單價計　　$X
  > 材料：　　　$X　　雜項：　　　　$X

  數量 × 單價 = $X（未稅），與Excel第X列複價一致。

  > ⚠️ 各單價來源備註...

  **待辦**：
  - [ ] ...
  ```
- 同步更新檔案 frontmatter「狀態」欄，加入本次異動一句話摘要（日期＋項次＋結論）

### 10. 互動節奏

一次處理一個項次，處理完主動問「繼續下一項嗎？」。使用者若一次貼多列，先確認是否要逐項確認公式，還是使用者已講清楚整批規則可以連續處理（比照系統傢俱單價試算 skill 的節奏判斷邏輯）。

## 完整範例（士林TOD大樓商場空間案，2026-08-05～06）

- **六-1 甲種施工圍籬**（335m，$3,800/m）：使用者提供7項工料修正版，人工$800＋機具$340＋材料$2,280＋雜項$380＝$3,800，與Excel第5列複價$1,273,000一致，取代AI初版反推分析
- **六-2 室內保護工程地坪**（1,066.5m²，$250/m²）：AI依市場行情反推6項工料（防潮布/PP瓦楞板/薄夾板/收邊/鋪設人工/拆除清運），人工$70＋材料$170＋雜項$10＝$250/m²，與Excel複價一致
- **七-1 活動隔間**（2組，$890,000/組）：使用者提供完整6大類版本（結構計算簽證$35,000＋軌道承載鋼結構$95,000＋隔音門板本體$400,000＋軌道五金系統$180,000＋現場吊裝安裝$135,000＋雜項管理$45,000），取代AI初版反推
- **九-1 C1天花板**（131.0m²，$1,700/m²）：拆解為暗架骨架$300＋矽酸鈣板$230＋骨架安裝人工$250＋封板人工$200＋批土$250＋油漆$300＋雜項$170（吸收尾差）＝$1,700/m²，人工小計$1,000／材料小計$530／雜項小計$170／機具$0
