# Email Sort

自動將 Gmail 收件匣的未讀信件分類到三個標籤資料夾。

## 標籤定義

| 標籤名稱 | 適用信件 |
|----------|----------|
| `整理/廣告信件` | 促銷、電子報、行銷活動、優惠通知、訂閱通知 |
| `整理/帳單收據` | 發票、繳費通知、訂單確認、付款收據、水電瓦斯帳單 |
| `整理/金融相關` | 銀行對帳單、信用卡、投資報告、保險、稅務、股票通知 |

未符合任何分類的信件：**不移動**，留在收件匣。

---

## 執行步驟

### Step 1：確保標籤存在

使用 `mcp__gmail__get_or_create_label`，確保以下三個標籤都存在（若無則建立）：
- `整理/廣告信件`
- `整理/帳單收據`
- `整理/金融相關`

記錄每個標籤的 `id`，後續步驟會用到。

### Step 2：取得未讀信件清單

使用 `mcp__gmail__search_emails`：
- query: `in:inbox is:unread`
- maxResults: 50

取得信件清單，每封記錄：`id`、寄件人（`from`）、主旨（`subject`）。

### Step 3：分類判斷

**根據寄件人 + 主旨**判斷分類，不需要逐封讀取內容（節省時間）。

分類判斷邏輯：

**廣告信件** — 符合以下任一條件：
- 寄件人含 `noreply`、`no-reply`、`newsletter`、`marketing`、`info@`、`promo`
- 主旨含：優惠、折扣、特賣、限時、電子報、訂閱、活動通知、unsubscribe

**帳單收據** — 符合以下任一條件：
- 主旨含：發票、收據、帳單、繳費、訂單、付款、invoice、receipt、payment、order confirmation
- 寄件人為已知電商、水電公司、電信業者

**金融相關** — 符合以下任一條件：
- 主旨含：對帳單、信用卡、存款、轉帳、匯款、利率、保單、股票、基金、稅務、報稅
- 寄件人為銀行、證券商、保險公司

**無法判斷** → 歸類為「不移動」，保留在收件匣。

如果同時符合多個分類，優先順序：帳單收據 > 金融相關 > 廣告信件。

### Step 4：批次搬移信件

對每個分類（有信件才執行），使用 `mcp__gmail__batch_modify_emails`：
- `ids`：該分類的所有信件 id
- `addLabelIds`：對應標籤的 id
- `removeLabelIds`：`INBOX` 的 label id（Gmail 系統標籤）

### Step 5：輸出執行摘要

用繁體中文輸出結果表格：

```
## 信箱整理完成

| 分類 | 封數 |
|------|------|
| 廣告信件 | X 封 |
| 帳單收據 | X 封 |
| 金融相關 | X 封 |
| 留在收件匣（無法分類） | X 封 |

共處理 X 封未讀信件。
```

若有「留在收件匣」的信件，列出前 5 封的寄件人和主旨，讓使用者自行判斷。

---

## 注意事項

- 若未讀信件為 0，直接回報「收件匣目前無未讀信件」
- 分類有疑慮寧可「不移動」，不要誤移工程相關的重要信件
- 執行前不需要使用者確認，直接執行並回報結果
