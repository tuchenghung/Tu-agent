# 公共工程領標整理

先讀 [公共工程領標與詢價 SOP](../../../100_Todo/projects/公共工程領標與詢價SOP.md)，依使用者當次要求執行對應步驟。這份 SOP 是五步流程的共用來源；只要求核對或修改 SOP 時，不代替使用者改標單、發送詢價或填寫事件日期。

## 執行重點

- 先辨識案件、來源版次與使用者最新人工修正，保留原檔、原尺寸、續文及列印範圍。已有驗收成果先沿用。
- 無原生 Excel 才從相應 PDF 轉檔；原式總表、詳細表、單價分析、資源統計依來源分頁，中文與公式均核對。
- 詢價包須有獨立可填 Excel、圖說、規範、必要共通資料及來源清單。按實際頁碼核對，不套 B10 固定頁差；完成包後交使用者檢查。
- 追蹤表保留真實寄出、預計回覆、實際收到三種日期；工種、廠商、輪次與版本可追溯。資料備妥不等於已寄出。
- 廠商回覆或歷史價格填成本時，讀 [廠商報價填入預算表](../廠商報價填入預算表/SKILL.md)。逐檔定位成本區，不能固定套 B10 H:I。售價與成本分開，空白不當零。
- 同案舊報價分清成本／售價，保留規格、數量、稅別及版本差異，不整張硬套。需要更深入單價合理性時參考 [工程單價契約分析](../工程單價契約分析/SKILL.md)。
- 行政摘要保留 B10 六段架構與來源；個案勾選、金額、比例及日期依本案文件。外部任務及提醒依當次授權，不從範例推定。
- 工具與連線依當次可用能力；不在 Skill 保存或輸出憑證。電子領標憑據原檔保留。

## 歷史核對入口

- [B10 成本區核對](../../../100_Todo/projects/工程管理SOP_B10成本區核對.md)：欄位只是該案指定版本的證據。
- [西址六東分類與詢價拆包更正](../../../400_Knowledge/AI工作流/2026-09-11_公共工程標案分類與詢價拆包_踩坑紀錄.md)：人工修正、原尺寸、缺圖、漏附標單與廠商版處理。

交付時分清本次已完成、歷史已修正、待處理與未驗證項目，不能把 SOP 更新當作實檔修正或詢價已寄出。
