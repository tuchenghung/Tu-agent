# 公共工程領標整理

政府採購（尤其國防、公家機關）的電子領標包下載後是一包散檔（目次、契約範本、圖說、施工規範、空白標單、投標須知、聲明書、招標公告、電子領標憑據），格式固定但每次都要人工拆。這個 skill 把「歸檔 → 讀重點 → 建索引 → 拆工種 → 排提醒」的流程固定下來，讓每個新標案都用同一套產出。

**範例基準案**：B10多功能訓練館整修工程（案號 115HIB1001640962920，國防部軍事情報局），已完成的產出可參考：
- `宏祐/規劃中案件/20260826-B10多功能訓練館整修工程/E業主合同資料/合約摘要.md`
- `宏祐/規劃中案件/20260826-B10多功能訓練館整修工程/F供應商報價與資料/詢價勾選表.xlsx`

## 前提檢查

案件的 A-I 標準資料夾（`A業主提供資料`…`I其他`）必須已存在。
- 有 → 繼續
- 沒有 → 停下，回覆「請先執行 `/建立規劃案件 <案名> <公司別>`，建好資料夾再回來跑領標整理」

### Step 1：掃描領標包，辨識檔案

```bash
find "$SRC" -type f ! -name ".DS_Store" | sort
```

依檔名前綴／關鍵字對應（政府電子領標固定命名）：

| 檔案 | 內容 | 後續用途 |
|---|---|---|
| `0.目次` | 招標文件目次 | 確認這次領標包含哪幾份 |
| `1.工程契約範本` (.docx) | 契約條款（約 90% 通用 + 個案勾選欄） | → Step 4 合約摘要 |
| `2.工程圖說` (.pdf) | 細部設計圖，首 1-3 頁有「A0-1 索引表」 | → Step 5 圖說索引 |
| `3.施工規範` (.pdf) | CSI 章節式規範，前段有目錄 | → Step 6 規範索引 |
| `4.空白標單` (.xls) | 預算總表／詳細表／單價分析表／資源統計表 | → Step 7 工種拆解 |
| `5.投標須知` (.odt/.pdf) | 押標金、資格、決標方式細節 | → Step 4、Step 8 |
| `6.投標聲明書` / `8.聲明書` | 廠商聲明書 | 併入清單，投標時填 |
| `招標公告` (.pdf) | 案號、機關、預算金額、截標/開標時間、押標金%、決標方式 | → Step 4、Step 8 |
| `電子領標憑據` (.pdf/.tkn) | 領標證明 + 上傳投標用 token | 保留原檔勿動，投標時要 |
| `index.html` | 領標系統產生的檔案索引 | 保留 |

### Step 4：`合約摘要.md`（沿用 B10 六段結構）

讀 `1.工程契約範本`＋`5.投標須知`＋`招標公告`。**只擷取「本案已勾選／填入的個案條件」＋「特殊條款」**，通用條款不抄。存 `$CASE/E業主合同資料/合約摘要.md`，固定六段：

```markdown
# <案名> — 合約摘要

- 案號 / 機關 / 來源文件 / 契約範本版本 / 摘要建立日
- 說明：契約 XX% 為通用條款，本摘要只擷取個案條件＋特殊條款。

## 一、契約摘要頁（首頁載明事項）
履約地點、結算方式（總價承包/實作實算）、預付款、估驗計價週期、保留款%、
履約期限（通知起N日開工、開工次日起M工作天竣工）、天數計算（工作天/日曆天）、
逾期違約金（每日 X‰、上限 X%）、履約保證金%、保固保證金%、保固年限（結構/非結構）

## 二、付款流程
估驗審核天數、請款到付款天數、尾款條件、跨年度預算風險、進度落後暫停計價門檻、
數量增減變更門檻（±X%）

## 三、罰則（懲罰性違約金）
逐項條列：事由 → 金額。含品質查核缺失、重複性缺失、品管職安兼職、
原產地不實、減價收受等。標注違約金總額上限。

## 四、保險
營造綜合保險＋雇主意外責任險，第三人責任額度、雇主責任額度、自負額、
附加條款、保險期間（開工起至履約期滿加N個月）

## 五、特殊條款（一般民間案沒有）
※ 國防／國安案重點：禁用陸港澳產品與廠牌、禁用中國製施工機具、入營管制
（前兩週提名冊）、作息配合機關、國安法查驗、**禁用生成式 AI 提供本案保密資訊**、
保密切結、特殊查核。非國防案則列該案獨有的加註條款。

## 六、其他要注意
契約文件優先順序、竣工圖提送期限、有無初驗、驗收改正次數上限、轉包罰則、
最低工資倍數、物價指數調整門檻、土方去化地點
```

若同性質摘要值得沉澱，比照 CLAUDE.md「案件特定時間規則不可當通用標準」：**具體天數/金額標「本案」，格式/流程才是通用**。

### Step 7：標單工種拆解 → 詢價勾選表

讀 `4.空白標單.xls`：
- `預算總表`：工程大分類（壹 直接工程 → 一 假設工程／二 拆除／三 結構／四 整修／五 鐵皮／六 外牆／七 機電／八 弱電／九 空調…）
- `預算詳細表`：欄位 `項次 / 項目及說明 / 單位 / 數量 / 單價 / 複價 / 編碼`。**品項說明常跨兩列**（第二列是接續文字，項次欄空白），讀取時要往下合併。

依品項把工程拆成「發包工種」（拆除、泥作、鐵工、鋁窗、機電、空調、天花輕鋼架、油漆、防水、木作木門、地坪PVC、高架地板、樓梯止滑磚、系統櫃、碳纖維補強、外牆塗料、廣告字、球場地墊、防撞墊、籃球架、座椅…）。自辦 vs 發包由使用者主導，不替他決定。

產出／更新 `$CASE/F供應商報價與資料/詢價勾選表.xlsx`，欄位固定：

| 項次 | 工種 | 廠商名稱 | 寄出資料日期 | 收到報價日期 | 勾選欄 | 備註 |
|---|---|---|---|---|---|---|

- **已存在就更新不覆蓋**：保留已填的廠商名稱／日期／勾選欄，只補新工種列。
- 日期沿用民國格式（`115/8/27`）與既有檔一致。
- 用 openpyxl 寫入，保留原格式（見 [[reference_xls_format]]）。

### Step 8：關鍵日期 → Notion 任務 ＋ Google Calendar

從招標公告／投標須知擷取，**民國轉西元**後建立：

| 事項 | 資料來源欄位 | 提醒設定 |
|---|---|---|
| **截止投標** | 招標公告「截止投標」 | 硬截止：當天 08:00＋前一天＋前 3 天各一次 |
| 開標時間 | 招標公告「開標時間」 | 前一天＋前一小時 |
| 領標有效期間截止 | 目次「有效期間」 | 前一天 |
| 押標金繳納 | 投標須知（報價總額 5%，且是否線上繳納） | 併入截標任務備註 |

⚠️ **過期日期不建提醒**：整理日若已晚於截標／開標日（例如補整理舊案、驗證用），跳過建立 Notion 任務與 Calendar，只在 `領標包清單.md` 記錄「此二日期已過期，未建提醒」。

Notion 任務：用 `/新增任務` 精神寫入行動任務資料庫，關聯到本案專案頁；有 Deadline → 依 [[feedback_task_calendar_reminder]] 自動建 Google Calendar 全天行程，**前一天＋前一小時提醒**（[[feedback_calendar_reminders]]）。

任務備註帶上：預算金額、決標方式（最低標/最有利標/複數決標）、是否訂底價、履約期限、押標金額度與繳納方式。

## NEVER / ALWAYS

- **ALWAYS 民國年 +1911**：領標文件全用民國年，每個日期都要換算西元後再寫入檔案／建提醒。
- **ALWAYS 用索引表實際核對 PDF offset，且圖說與規範各自獨立**：兩份 PDF 的 offset 不一樣（B10：圖說 +2、規範 +4），各翻第一張圖／第一章實際確認，再抽驗最後一張／中段一章，不要互相套用、也不要套 B10 的數字。
- **ALWAYS 合約摘要只擷取個案條件＋特殊條款**：契約範本 90% 是政府通用條款，全抄沒意義。抓「已勾選欄」「已填空格」「軍事/國安加註」。
- **ALWAYS 詢價勾選表更新不覆蓋**：檔案已存在時保留使用者已填的廠商與日期，只補列。
- **ALWAYS 缺章／不一致要標紅**：標單有、規範無專章的工種，或標單品名與圖說大樣不符（B10「明架矽酸鈣」vs 圖說「純岩棉明架吸音」），在索引檔標 ⚠️，這是報價風險點。
- **NEVER 替使用者決定自辦或發包**：工種拆出來，勾選由使用者主導。
- **NEVER 動電子領標憑據（.tkn/.pdf）**：那是投標上傳要用的，原檔原位保留。
- **NEVER 把國防／國安案的圖說、標單、規範內容整段貼進對外服務或非必要的 AI 查詢**：合約有禁用生成式 AI 保密條款，摘要時引用最小必要片段。
- **報價合理性／單價分析**：本 skill 只做「索引與歸檔」；要拆某項單價合理性，接 `/工程單價契約分析`，成果存 `400_Knowledge/工程/報價單圖說對應分析/`。
