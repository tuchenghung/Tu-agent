# 系統傢俱單價試算

裝修工程報價時，系統傢俱/固定家具（常標記為 FIX01、FIX02...）多半用「W×D×H公分」標尺寸，但骨架/檯面等單價卻是用「台尺」或「公分」計價，混用單位很容易算錯或漏乘。這個 skill 把換算公式跟輸出格式固定下來，讓你只要丟尺寸跟單價基準就能拿到一致格式的試算結果，不用每次在對話裡重新講一次公式。

## 核心換算：1台尺 = 30.3cm

這是裝修業界慣用換算基準，不是精確物理量。**換算時用完整精度（至少4位小數）去乘，不要先四捨五入到2位小數的中間值再乘**——量體越大，提早四捨五入造成的誤差會被單價放大，尤其是$/尺這種高單價項目，差個0.01尺乘上$5,000/尺就是$50的落差，在乘上多個品項後很容易讓總報價兜不起來。最終金額才四捨五入到整數元。

## 计算流程

### 1. 決定「長度基準」

大多數項目的成本是照長度（寬度W，或使用者指定的其他長度）去乘單價，但要先確認用哪個維度：

- 一般情況：用寬度 W
- 使用者明確指定其他長度（例如「檯面長度抓80」代表只取80cm而非整個W）：照使用者指定的走
- **雙段/多段品項**（例如一字型沙發座分兩段：W515×D70 + W429×D70）：兩段個別換算成台尺後**分別**乘單價，再加總。或等效地先把cm加總再一次換算——結果一樣，但分段呈現方便使用者核對。
- **L型/轉折型品項**（例如L型吧檯 W375×214）：使用者通常會說「長度計算是A+B」，代表把兩邊長度相加當作單一總長度去乘單價（不是像雙段那樣分開算，是先加總cm再換算一次）。

不確定要用哪個維度、或使用者的指定跟你的預設認知不一致時，直接問，不要自己猜——尺寸算錯直接反映在報價金額上，比模糊回答風險大得多。

### 2. 拆解成本組成項目

每個品項的成本可能由多種計價方式混合組成，常見的有：

| 計價方式 | 範例 | 計算基準 |
|---------|------|---------|
| 每公分計價 | 桌面人造石 $70/cm | 長度(cm) × 單價 |
| 每台尺計價 | 造型櫃體 $5,500/尺 | 長度(台尺) × 單價 |
| 拆分費率（如上下櫃分開） | 上櫃$3,000/尺、下櫃$3,500/尺 | 各自的長度(台尺) × 各自單價 |
| 固定單價（論件） | 水槽$4,500/個、龍頭$4,500/組 | 直接帶入，不需換算尺寸 |
| 固定抓價（取代尺價） | 「櫃體抓$10,000」 | 直接帶入固定金額，忽略尺數換算 |

使用者會用像「同01」「跟01一樣」這種說法，代表沿用前面已經算過的某個品項的**成本組成邏輯與單價基準**，只是這次的尺寸不同——這時候要記得前面那個品項用了哪些單價，套用到新尺寸上，而不是重新問一次。如果現有對話紀錄裡找不到「01」對應的公式（例如是全新對話、沒有前情提要），才需要請使用者說明。

### 3. 判斷利潤演算法

**預設用加成法：售價 = 成本 × (1 + 利潤率)**

這跟業界另一種常見算法「毛利率法：售價 = 成本 ÷ (1 − 利潤率)」結果差很多（例如成本$100,000、30%利潤：加成法得$130,000，毛利率法得$142,857，差距超過1萬元），兩者都合理存在，只是計算邏輯不同。**如果使用者沒有明確講過要用哪一種，先問清楚再算，不要預設**——這類差距在單一品項就上萬元，累積到整個系統傢俱案子的落差會更可觀。已經在同一輪對話裡確認過的話，後續同案件的品項可以沿用同一個答案，不用每項都重問。

### 4. 主動抓矛盾/風險點

有些單價欄位看起來像是分開的兩個成本，但實際上可能互相重疊（例如「沙發泡棉含人造皮 $1,200/尺」這個報價，賣家可能已經把骨架成本算在裡面，如果同時又另外計算了「造型櫃體 $4,000/尺」，就有重複計價的風險）。遇到這種情況：
- 主動跟使用者提醒這個疑慮，說明為什麼可能重複（例如來源網頁沒寫清楚是否含骨架）
- 如果使用者確認要直接用（例如「直接用這個數字算」），照做但在輸出結果附註警示，方便使用者日後正式報價前回頭核實
- 不要自己默默排除某個成本項目去「修正」重複計價問題——你不確定實際狀況，擅自調整反而可能算錯

## 輸出格式

每算完一個品項，用這個表格格式呈現（維持既有慣例，方便使用者複製貼到報價單或知識庫）：

```markdown
## FIXxx 品項名 單價試算

**基礎尺寸**：WxxxxDxxxHxxxcm（換算 W = xxx÷30.3 = xx.xxxx 台尺）

| 項目 | 計算式 | 金額 |
|------|--------|------|
| 成本組成項目1 | xxx × $xx/單位 | $xx,xxx |
| 成本組成項目2 | ... | ... |
| **成本小計** | | **$xx,xxx** |
| 加成30%（或實際利潤率） | ×1.3 | **$xx,xxx** |

**FIXxx 品項名 單價 ≈ $xx,xxx**（未稅）
```

- 「基礎尺寸」列出原始cm尺寸與換算後的台尺（附精確小數，讓使用者能核對），雙段/L型品項則分別列出每段的換算過程
- 表格逐行列出每個成本組成，最後一行才是加成後金額
- 結尾用粗體單句總結最終單價，方便使用者快速抓數字

## 互動節奏

延續一次算一項的節奏，不要因為使用者一開始丟了整批清單就自作主張把所有品項一次全部算完——多數情況下每個品項的單價基準都要使用者個別提供或確認（同01/跟09一樣等），一次全上反而容易套錯公式。每算完一項，主動問「繼續算下一項嗎？」，並在有需要的時候（例如下一項看起來性質不同，如含設備、含骨架抓價）先問清楚要用哪種公式，而不是照搬前一項的邏輯硬套。

如果使用者一開始就提供了完整的「每項對應公式」清單（例如「FIX01~05用同一套公式，FIX06~08是另一套」），可以照著清單一次算完，不用逐項確認——判斷依據是使用者有沒有把規則講清楚到不需要你再問。

## 完整範例（士林TOD大樓商場空間案，2026-07-27）

這是本skill邏輯的原始驗證案例，供參考輸出品質與格式：

- FIX01 高桌（W400×D40×H115cm）：桌面人造石$70/cm + 造型櫃體$5,500/尺，加成30% → **$130,789**
- FIX02 櫃台（W410×D60×H90cm）：同FIX01公式，櫃體改$4,700/尺 → **$119,987**
- FIX03 沙發座（W319×D70×H105cm）：造型櫃體$4,000/尺 + 沙發泡棉含人造皮$1,200/尺（⚠️提醒可能與骨架重複），加成30% → **$71,170**
- FIX06 高櫃內嵌洗手台（W160×D70×H400cm）：檯面人造石$70/cm×80cm(使用者指定長度) + 水槽$4,500/個 + 龍頭$4,500/組 + 櫃體固定抓$10,000（使用者事後修正，取代原本的$/尺算法），加成30% → **$31,980**
- FIX07 沙發座雙段（W515×D70 + W429×D70cm）：沿用FIX03公式，兩段分別換算尺寸、分別乘$5,200/尺(=$4,000+$1,200)、加總後才乘1.3 → **$210,608**
- FIX08 L型吧檯（W375×214×H110cm，長度取375+214=589cm）：沿用FIX01公式，用加總後的589cm換算 → **$192,587**
