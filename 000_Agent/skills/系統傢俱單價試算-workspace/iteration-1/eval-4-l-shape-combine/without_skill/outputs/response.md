## L型吧檯單價試算

**條件確認：**
- L型兩邊長度：280cm + 150cm，依指示直接相加計算 → 總長度 **430cm**
- 深度 D：兩邊皆 65cm
- 檯面：人造石，75元/cm
- 櫃體：5800元/尺（台尺，1尺 = 30.3cm）
- 利潤加成：25%

---

### Step 1｜總長度

280 + 150 = **430cm**

### Step 2｜檯面成本（人造石）

430cm × 75元/cm = **32,250元**

### Step 3｜櫃體成本

先將長度換算成台尺：
430cm ÷ 30.3cm/尺 = 14.1914尺

14.1914尺 × 5,800元/尺 = **82,310元**（四捨五入至個位）

### Step 4｜成本小計

32,250 + 82,310 = **114,560元**

### Step 5｜加計利潤 25%

114,560 × 1.25 = **143,200元**

---

## 最終單價結果

| 項目 | 明細 | 金額 |
|---|---|---|
| 檯面（人造石） | 430cm × 75元/cm | 32,250元 |
| 櫃體 | 14.19尺 × 5,800元/尺 | 82,310元 |
| 成本小計 | | 114,560元 |
| 利潤加成 25% | ×1.25 | +28,640元 |
| **報價總額（未稅）** | | **約 143,200元** |

換算成每公分平均單價（含利潤）：143,200 ÷ 430cm ≈ **333元/cm**

---

**備註：**
1. 計算採「長度直接相加」方式，未依L型轉角處另做扣減或補料處理，若轉角有收邊、封板或加工費用，需另計。
2. 深度 D=65cm 假設已包含在檯面（75/cm）與櫃體（5800/尺）的單價基準內，未另外依深度加價；若此深度超出廠商標準報價深度（一般人造石標準深度多為60cm），建議跟供應商確認是否有加價區間。
3. 尺寸換算採 1台尺 = 30.3cm 標準值。
4. 上述金額為未稅價，如需開立發票另計5%營業稅。
