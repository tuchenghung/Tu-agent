# 早晨日報 SOP

每次執行依序完成以下所有段落，一次輸出。

---

## PART 1：記憶與待辦提醒

1. 讀取 `MEMORY.md` 的「⚠️ 待辦提醒」區段，逐條列出
2. 若有待辦事項，主動說明目前狀態

---

## PART 2：今日行事曆

使用 `mcp__google-calendar__list-events` 列出今天的行程，格式：
```
📅 今日行程（YYYY-MM-DD）
- HH:MM 行程名稱
```

---

## PART 3：持股財經新聞摘要 ⭐

### 台股持倉（依市值排序優先）
針對以下分類，各搜尋 1 則最新相關新聞（今天或近 3 天內）：

**主動持倉分類：**
- 半導體/IC：台積電（2330）、同欣電（2409）、祥碩（5269）
- AI/機器人：上銀（2049）、台達電（2308）、達明（4585）、所羅門（2359）
- 電力設備：華城（1519）
- 能源/儲能：格斯科技（6830）
- 軍工/國防：台船（2208）、雷虎（8033）
- 防禦/傳統：台肥（1722）、永豐餘（1907）、中鋼（2002）

**美股主要持倉：**
- AI/半導體：NVDA、TSM、SMCI、INTC、PLTR
- 太空：RKLB、PL
- 核能：SMR、OKLO

### 搜尋與呈現規則

1. 每個分類用 **一則** `WebSearch` 搜尋（搜尋詞：`{股票名稱} 新聞 {今天日期}`）
2. 若無今日新聞則略過，不強行填充
3. 每則摘要格式：
   ```
   📌 {股票名稱}｜{一句話重點，30字以內}
   ```
4. **不主動提供連結**，等使用者說「想看 XX 完整新聞」再給 URL

### 輸出範例
```
📊 今日持股新聞（2026-06-01）

🇹🇼 台股
📌 台積電｜CoWoS 需求旺盛，法人上調目標價至 2,800 元
📌 上銀｜人形機器人訂單能見度提升，Q3 出貨量估增 30%
📌 台船｜潛艦國造進度超前，軍方加碼訂單傳聞持續

🇺🇸 美股
📌 NVDA｜Blackwell Ultra 樣品出貨，AI 伺服器需求加速

---
如需完整文章連結，請說「看 XX 的新聞」
```

---

## PART 4：今日重點提醒

整合以上資訊，輸出一段 3-5 行的今日重點摘要：
- 有無緊急待辦
- 有無重要行程
- 持股有無重大消息需注意

---

## 注意事項

- 新聞搜尋若無結果，該股略過，不輸出空白
- 摘要以**繁體中文**呈現
- 全程不超過 500 字，保持精簡
- 使用者要求某股完整新聞時，才用 WebSearch 搜尋該股並給出連結
