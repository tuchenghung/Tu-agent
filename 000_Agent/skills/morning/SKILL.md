# 早晨日報 SOP

每次執行依序完成以下所有段落，一次輸出。

---

## PART 1：記憶與待辦提醒

1. 讀取 `MEMORY.md` 的「⚠️ 待辦提醒」區段，逐條列出
2. 若有待辦事項，主動說明目前狀態

---

## PART 1.5：踩坑提醒 ⚠️

目的：已記錄的踩坑（feedback 型記憶）常常「有記錄但沒被主動查」而重複發生（2026-07-23 使用者指出這點）。此段落強迫每天重新過一次腦。

1. 掃過 Claude Code 自動記憶系統（session 開頭已載入的 `MEMORY.md` 索引，位於 `~/.claude/projects/<專案>/memory/`）裡所有 `type: feedback` 的記憶檔案
2. 挑出以下兩類，各列 1-3 條（沒有就略過該類，不強行湊數）：
   - **近期新增**（30 天內建立或修改）
   - **高風險常踩**（描述中出現「重複」「二度」「已犯錯 N 次」等字樣，代表過去曾在同一類任務上再犯）
3. 輸出格式：
   ```
   ⚠️ 踩坑提醒
   - {規則一句話}（適用場景：{何時該注意}）
   ```
4. 若近 30 天內完全沒有新增或被引用的 feedback 記憶，此段落可省略不輸出

### 搜尋與呈現規則

1. 每個分類用 **一則** `WebSearch` 搜尋（搜尋詞：`{股票名稱} 新聞 {今天日期}`）
2. 若無今日新聞則略過，不強行填充
3. 每則摘要格式：
   ```
   📌 {股票名稱}｜{一句話重點，30字以內}
   ```
4. **不主動提供連結**，等使用者說「想看 XX 完整新聞」再給 URL

## PART 4：今日重點提醒

整合以上資訊，輸出一段 3-5 行的今日重點摘要：
- 有無緊急待辦
- 有無重要行程
- 持股有無重大消息需注意

---

## 注意事項

- 新聞搜尋若無結果，該股略過，不輸出空白
- 摘要以**繁體中文**呈現
- 全程不超過 500 字，保持精簡
- 使用者要求某股完整新聞時，才用 WebSearch 搜尋該股並給出連結
