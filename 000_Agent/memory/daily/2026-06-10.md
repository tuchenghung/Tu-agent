- 解法：DELETE 舊表 → 記錄 blocks[i-1].id 為 afterId → 重建新表加 `after` 參數
- 代碼位置：/tmp/notion_add_pct2.mjs

- 問題：8 欄的 table 設 table_width:9 導致 row cells 數量不符
