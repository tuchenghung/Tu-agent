## 技術筆記
- Notion API 限制：私人整合無法在工作區頂層直接建頁面，需由用戶先建空白頁共用
- `PATCH /blocks/{id}/children` 建立 column_list 時，children 需放在 `column_list.children` 與 `column.children` 內層，不能放在區塊頂層
- Notion API 不支援直接上傳檔案到資料庫，只能建立 URL 欄位連結
- Google Slides 可用 `/export/pptx` 直接 curl 下載（需公開分享）
