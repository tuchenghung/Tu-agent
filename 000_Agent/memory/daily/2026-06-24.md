### 2. 信天翁 2F 冷凍冷藏庫建置規劃
深度討論並完成完整規劃摘要，涵蓋：

**空間確認（圖面來源）：**
- 圖面：`B規劃圖面/PDF/2F冷凍庫規劃圖面115.04.20-模型.pdf`
- 4°C 冷藏庫 757㎡、-20°C 冷凍庫 820㎡
- 2F 樓高 5m，有效儲存淨高 **3,600mm**

**關鍵決策：**
| 項目 | 決定 | 理由 |
|---|---|---|
| 防凍裝置 | 電熱線（非架高地板）| 10年省NT$85萬，不損失淨高 |
| 冷凍系統 | 氣冷式（非水冷）| RF露天遮雨棚配置，氣冷最自然 |
| 冷凝器型式 | V型（非H型平板）| 抗東北季風側風 |
| 除霜方式 | 電熱融霜（冷凍庫）/ 自然停機（冷藏庫）| 標準配置 |

**重要注意事項確認：**
- RF 樓板載重問題：設備總重約 12,500 kg，必須結構技師確認
- 冷媒回油：吸氣立管每 3-5m 設反 U 型油彎
- 排水管電熱帶：穿越庫板段必裝
- 嘉義東北季風：V型冷凝器＋導流擋板＋朝向規劃

**用電量：** 尖峰約 110 kW / 日常平均 56 kW / 申請 160 kVA
**月電費：** 約 NT$16-18 萬/月
**建置費用：** 粗估 NT$1,940-3,425 萬
