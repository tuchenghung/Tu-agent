回答空調規劃問題時必須依序查詢以下來源，不得只用其中一種：

1. **本機知識庫**（優先）：`400_Knowledge/工程/建材規格/` grep 空調相關資料
2. **中華民國法規**：室內空氣品質管理法（CO₂≤1,000ppm）、CNS 標準、建築技術規則相關條文
3. **工程慣例**：台灣業界通用設計基準（如 5坪/RT、1RT=2,500kcal 等）
4. **網路資料**：查不到時主動 WebSearch 補充最新資訊或規範

**Why:** 本次西湖6F規劃一開始未查知識庫，導致換算值有誤（用國際標準而非台灣慣用值），使用者指正後才修正。

**How to apply:** 空調相關問題（冷房負荷計算、換氣量、機器選型、風管設計、造價估算）一律先查知識庫，再核對法規，最後才憑空計算。
