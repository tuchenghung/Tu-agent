# 新增任務（Notion 行動任務庫）

在 Notion Tasks（行動任務庫）新增一筆任務，透過互動問答填入欄位後自動建立。

觸發方式：
- `/新增任務`
- `/新增任務 任務名稱`（直接帶入名稱，跳過第一問）

---

## 執行步驟

### Step 1：確認任務名稱

若使用者已在觸發指令後面帶了名稱（如 `/新增任務 追業主簽合約`），直接使用該名稱，跳過此問。

否則用 **AskUserQuestion** 詢問：
- 問題：「這個任務叫什麼名稱？」
- 選項提示用戶可自由輸入（Other）

記為 `$TASK_NAME`。

---

### Step 2：問優先級（必填）

用 **AskUserQuestion** 詢問：
- 問題：「優先級？」
- 選項：
  - 緊急重要（紅色，立刻做）
  - 高（重要但不一定緊急）
  - 中（正常排程）
  - 低（有空再做）
  - 緊急不重要（應委外或快速處理）
  - 不緊急重要（排進計畫）
  - 不緊急不重要（可放棄）

記為 `$PRIORITY`。

---

### Step 3：問 Deadline（必填，可選「不設定」）

用 **AskUserQuestion** 詢問：
- 問題：「截止日期？」
- 選項：
  - 今天（今日日期）
  - 本週五（計算當週星期五的日期）
  - 下週五（計算下週星期五的日期）
  - 不設定

若選「今天」或「本週五」或「下週五」，自動計算對應的 `YYYY-MM-DD`。
若選「不設定」，記 `$DEADLINE = null`。
若使用者透過 Other 自訂輸入，轉換為 `YYYY-MM-DD` 格式。

記為 `$DEADLINE`。

---

### Step 4：搜尋並關聯 Project（選填）

呼叫 `mcp__notion-win__API-query-data-source`，查詢 Projects 資料庫：

```
database_id: 3355cac1-0351-4ef4-8eb1-8b8f0bb619c3
filter:
  property: 狀態
  status:
    does_not_equal: 完成
sorts:
  - property: 最後更新（或 last_edited_time）
    direction: descending
page_size: 8
```

從結果取得專案名稱清單，用 **AskUserQuestion** 顯示：
- 問題：「要關聯到哪個專案？」
- 選項：列出搜尋到的專案名稱（最多 4 個，若超過 4 個取最近編輯的 4 個）
- 最後一個選項：「不關聯專案」

若選「不關聯專案」，`$PROJECT_ID = null`。
否則記下對應的 page_id 為 `$PROJECT_ID`。

---

### Step 5：問備註（選填）

用 **AskUserQuestion** 詢問：
- 問題：「需要加備註嗎？」
- 選項：
  - 不用（跳過）
  - 我來輸入（顯示 Other 讓使用者輸入）

若選「不用」，`$NOTE = ""`。
否則記使用者輸入為 `$NOTE`。

---

### Step 6：建立 Notion Task

呼叫 `mcp__notion-win__API-post-page`，依以下 JSON 建立：

```json
{
  "parent": { "database_id": "f1dc0829-774c-493a-aa21-eefc6e35b034" },
  "icon": { "emoji": "⏩" },
  "properties": {
    "任務": {
      "title": [{ "type": "text", "text": { "content": "$TASK_NAME" } }]
    },
    "優先級": {
      "select": { "name": "$PRIORITY" }
    },
    "狀態": {
      "status": { "name": "待處理" }
    },
    "負責人": {
      "people": [{ "id": "261d872b-594c-8188-8718-000252a44fde" }]
    }
  }
}
```

若 `$DEADLINE` 不為 null，加入：
```json
"Deadline": { "date": { "start": "$DEADLINE" } }
```

若 `$PROJECT_ID` 不為 null，加入：
```json
"Project": { "relation": [{ "id": "$PROJECT_ID" }] }
```

若 `$NOTE` 不為空，加入：
```json
"備註": { "rich_text": [{ "type": "text", "text": { "content": "$NOTE" } }] }
```

記下回傳的 `id`（page_id），格式化為不含連字號的 URL。

---

### Step 7：輸出確認

```
✅ 已建立任務：「$TASK_NAME」

優先級：$PRIORITY
Deadline：$DEADLINE（若無則顯示「未設定」）
關聯專案：$PROJECT_NAME（若無則顯示「—」）
備註：$NOTE（若無則省略此行）

→ https://www.notion.so/$PAGE_ID（不含連字號格式）
```

## 關鍵常數

| 項目 | 值 |
|---|---|
| Tasks DB ID | `f1dc0829-774c-493a-aa21-eefc6e35b034` |
| Projects DB ID | `3355cac1-0351-4ef4-8eb1-8b8f0bb619c3` |
| 政宏 User ID | `261d872b-594c-8188-8718-000252a44fde` |
| Notion MCP（Windows） | `mcp__notion-win__` |
| Notion MCP（Mac） | `mcp__notion__` |

---

## 平台判斷

```bash
uname -s 2>/dev/null || echo Windows
```

- Mac (Darwin) → 使用 `mcp__notion__`
- Windows → 使用 `mcp__notion-win__`
