# 報價單開單

從參考報價單自動複製品項結構，清空數字後產生新案報價 Excel，
使用者調整完成後自動讀取最終品項並連同案件特點存入知識庫。

觸發方式：
- `/報價單開單`
- `/報價單開單 案件名稱`

---

## 執行步驟

### Step 0：偵測平台 + 取得日期

```bash
uname -s 2>/dev/null || echo Windows
```

依平台設定：
- **Windows**：`$DATE` = `powershell -Command "Get-Date -Format 'yyyyMMdd'"`
- **Mac (Darwin)**：`$DATE` = `date +%Y%m%d`

---

### Step 1：收集新案基本資料

用 **AskUserQuestion** 收集（若觸發指令已帶案名則跳過第一問）：
- 問題 1：「新案工程名稱？」
- 問題 2：「業主名稱？」
- 問題 3：「工程地點？」
- 問題 4：「存到哪個資料夾？（貼 D預算報價 的完整路徑）」
- 問題 5：「有無參考報價單？」
  - 選項 A：「有，貼路徑」（Other 輸入）→ 進入 Step 2a（複製品項結構）
  - 選項 B：「沒有（全新類型案件）」→ 進入 Step 2b（Notion 查單價）

記為：`$CASE_NAME`、`$CLIENT`、`$LOCATION`、`$TARGET_DIR`、`$REF_PATH`（或 null）

---

### Step 2：讀取參考報價，複製品項 + 保留單價

用 Python + openpyxl 讀取 `$REF_PATH`，提取所有非空白列的：
- A欄：項次
- B欄：名稱
- C欄：單位
- E欄：單價（**保留**，作為新案報價起點）
- G欄：備註
- I欄：成本單價（**保留**）
- 所在 Sheet 名稱

**不讀取 D欄（數量）**——新報價數量欄將全部清空。

```python
import openpyxl

wb = openpyxl.load_workbook(REF_PATH, data_only=True)
items = []
for sheet_name in wb.sheetnames:
    ws = wb[sheet_name]
    for row in ws.iter_rows(values_only=True):
        row = list(row) + [None]*14
        idx, name, unit, _, price, _, remark = row[:7]
        cost_price = row[8] if len(row) > 8 else None
        if name and str(name).strip():
            items.append({
                'sheet': sheet_name,
                'idx': idx, 'name': name, 'unit': unit,
                'price': price, 'cost_price': cost_price,
                'remark': remark
            })
```

整理後呈現品項清單給使用者確認：

```

項次              名稱                    單位  單價    成本單價

```

### Step 3：複製範本並填入表頭 + 品項

**3.1 複製範本（保留格式）**

```python
import shutil, os

TEMPLATE = '~/Library/CloudStorage/Dropbox/Tu-agent/000_Agent/templates/報價單範本.xlsx'
filename = f'{DATE}-{CASE_NAME}-報價.xlsx'
target = os.path.join(TARGET_DIR, filename)
os.makedirs(TARGET_DIR, exist_ok=True)
shutil.copy2(TEMPLATE, target)
```

> 必須用 `shutil.copy2` 二進位複製，禁用 openpyxl 寫入（會毀公式）。

**3.2 填入表頭（用 win32com / Mac 用 subprocess）**

- Windows：用 `win32com` 填入
- Mac：提示使用者手動填表頭，或呼叫 AppleScript

**表頭欄位對應（報價單 Sheet）：**
- C3 = `$CASE_NAME`（中文案名）
- F4 = `$CASE_NAME`
- F3 = `$CLIENT`
- F5 = `$LOCATION`

**3.3 品項填入規則：**

- 填入：項次、名稱、單位、**單價**、**成本單價**、備註（來自參考報價）
- **清空**：數量欄（D欄）→ 總價公式自動歸零，等使用者依新案尺寸填入
- 不填：總價（公式欄，自動計算）

> 注意：不要用 openpyxl 寫入品項到 Excel（會毀公式）。
> 正確做法：
> - Windows → `win32com` 逐格填入（項次/名稱/單位/單價/成本單價/備註，D欄數量留空）
> - Mac → 輸出品項清單 .txt，提示使用者對照手動貼入

### Step 5：讀取最終調整後的 Excel

使用者確認完成後，重新用 openpyxl 讀取 `$target`（最終版），提取所有品項：

```python
import openpyxl

wb = openpyxl.load_workbook(target, data_only=True)
final_items = []
for sheet_name in wb.sheetnames:
    ws = wb[sheet_name]
    for row in ws.iter_rows(values_only=True):
        idx, name, unit, qty, price, total, remark = (list(row)+[None]*7)[:7]
        if name and str(name).strip():
            final_items.append({
                'sheet': sheet_name,
                'idx': str(idx or ''),
                'name': str(name),
                'unit': str(unit or ''),
                'qty': qty,
                'price': price,
                'remark': str(remark or '')
            })
```

## 注意事項

- Excel 寫入一律用 win32com（Windows）或 AppleScript（Mac），禁用 openpyxl 寫入（會破壞所有公式）
