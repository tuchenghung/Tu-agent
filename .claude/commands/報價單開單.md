# 報價單開單

從案件資訊自動完成：
1. 從標準範本複製報價單 Excel
2. 用 win32com 填入表頭（案名/業主/地點/編號）
3. 自動用 Excel 開啟

觸發方式：
- `/報價單開單`
- 例：`/報價單開單 羅東聖母醫院S棟5樓耳鼻喉科整修工程`

---

## 執行步驟

### Step 0：偵測平台 + 取得日期

```bash
uname -s 2>/dev/null || echo Windows
```

依平台設定：
- **Windows**：`$DATE` = `powershell -Command "Get-Date -Format 'yyyyMMdd'"`
- **Mac (Darwin)**：`$DATE` = `date +%Y%m%d`

範本路徑（兩個平台）：
- **Windows**：`D:\Dropbox\Tu-agent\000_Agent\templates\報價單範本.xlsx`
- **Mac**：`/Users/tuzhenghong/Library/CloudStorage/Dropbox/Tu-agent/000_Agent/templates/報價單範本.xlsx`

### Step 1：用 AskUserQuestion 收集資料

使用 **AskUserQuestion** 收集以下四個欄位（一次問）：
- 問題 1：「工程名稱（案名）？」（短輸入，預填來自參數的案名）
- 問題 2：「業主名稱？」（短輸入）
- 問題 3：「工程地點？」（短輸入）
- 問題 4：「存到哪個資料夾？（請貼 D預算報價 的完整路徑）」（短輸入）

---

### Step 2：複製範本

用 Python 二進位複製（保留所有公式格式）：

```python
import shutil, os, sys

TEMPLATE = r'D:\Dropbox\Tu-agent\000_Agent\templates\報價單範本.xlsx'
TARGET_DIR = r'{目標資料夾路徑}'   # 來自 Step 1 的輸入
DATE = '{DATE}'                    # 來自 Step 0
CASE_NAME = '{工程名稱}'

filename = f'{DATE}-{CASE_NAME}-報價.xlsx'
target = os.path.join(TARGET_DIR, filename)

os.makedirs(TARGET_DIR, exist_ok=True)
shutil.copy2(TEMPLATE, target)
print(f'複製完成：{target}')
```

> **重要**：只能用 `shutil.copy2` 二進位複製，絕對不可用 xlutils.copy 或 openpyxl 讀寫（會毀掉所有公式）。

---

### Step 3：用 win32com 填入表頭

```python
import win32com.client as win32

CASE_NAME  = '{工程名稱}'
CLIENT     = '{業主名稱}'
LOCATION   = '{工程地點}'
PROJ_NO    = ''   # 工程編號留空，由使用者自填

xl = win32.Dispatch('Excel.Application')
xl.Visible = False
xl.DisplayAlerts = False
wb = xl.Workbooks.Open(target)

# 主報價 Sheet
ws1 = wb.Sheets('報價單')
ws1.Cells(3, 1).Value = CASE_NAME
ws1.Cells(4, 6).Value = CASE_NAME
ws1.Cells(3, 6).Value = CLIENT
ws1.Cells(5, 6).Value = LOCATION

# 機電空白標單 Sheet
ws3 = wb.Sheets('機電空白標單')
ws3.Cells(3, 1).Value = CASE_NAME + '機電工程標單'
ws3.Cells(4, 6).Value = CASE_NAME
ws3.Cells(3, 6).Value = CLIENT
ws3.Cells(5, 6).Value = LOCATION

wb.Save()
wb.Close()
xl.Quit()
print('表頭填寫完成')
```

---

### Step 4：用 Excel 開啟

```python
import subprocess, os

# Windows
subprocess.Popen(['start', 'excel', target], shell=True)
```

Mac 版：
```bash
open -a "Microsoft Excel" "$TARGET"
```
