# 建立規劃案件

從案件名稱自動完成：
1. 在 Dropbox 建立 A-I 標準資料夾結構
2. 在 Notion Projects 資料庫建立新專案頁面（狀態：規劃中）
3. Notion 頁面內建立 A-I 折疊標題

觸發方式：
- `/建立規劃案件 案件名稱 公司別`
- 例：`/建立規劃案件 台中榮總內視鏡中心 宏宇智慧`

---

## 執行步驟

### Step 0：偵測平台 + 取得參數

```bash
uname -s 2>/dev/null || echo Windows
date +%Y%m
```

- Darwin → Mac 模式：Dropbox 根目錄 = `~/Library/CloudStorage/Dropbox/宏祐/`
- 其他 → Windows 模式：Dropbox 根目錄 = `D:\Dropbox\宏祐\`

從使用者輸入取得：
- `$CASE_NAME`：案件名稱（第一個參數）
- `$COMPANY`：公司別（第二個參數，若未輸入預設「宏宇智慧」）
- `$YYYYMM`：當前年月（`date +%Y%m`）
- `$BASE`：完整路徑 = `Dropbox根目錄/YYYYMM-案件名稱/`

---

### Step 1：建立 Dropbox 資料夾結構

```bash
BASE="$DROPBOX_ROOT/$YYYYMM-$CASE_NAME"

# 建立 A-I 主資料夾
for folder in "A業主提供資料" "B規劃圖面" "C簡報資料" "D預算報價" \
              "E業主合同資料" "F供應商報價與資料" "G進度計畫管理" "H照片" "I其他"; do
  mkdir -p "${BASE}/${folder}"
done

# 建立 D 的子資料夾
mkdir -p "${BASE}/D預算報價/參考報價"

# 建立 F 的子資料夾
mkdir -p "${BASE}/F供應商報價與資料/廠商報價"
```

建立完成後列出資料夾確認。

---

### Step 2：Notion 建立新專案頁面

使用 `mcp__notion__API-post-page`（Mac）

```json
{
  "parent": { "database_id": "3355cac1-0351-4ef4-8eb1-8b8f0bb619c3" },
  "icon": { "type": "emoji", "emoji": "🏗️" },
  "properties": {
    "專案": { "title": [{ "text": { "content": "$CASE_NAME" } }] },
    "公司別": { "select": { "name": "$COMPANY" } },
    "狀態": { "status": { "name": "規劃中" } },
    "負責人": { "people": [{ "id": "261d872b-594c-8188-8718-000252a44fde" }] },
    "開始日": { "date": { "start": "YYYY-MM-DD" } }
  }
}
```

記下回傳的 `page_id` 供後續使用。

---

### Step 3：在 Notion 頁面建立 A-I 折疊標題

使用 Node.js 直接呼叫 Notion API：

```bash
~/.nvm/versions/node/v24.14.1/bin/node -e "
const TOKEN = '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';
const PAGE_ID = '< Step 2 取得的 page_id >';

const sections = [
  'A 業主提供資料',
  'B 規劃圖面',
  'C 簡報資料',
  'D 預算報價',
  'E 業主合同資料',
  'F 供應商報價與資料',
  'G 進度計畫管理',
  'H 照片',
  'I 其他',
];

const children = sections.map(title => ({
  object: 'block',
  type: 'heading_2',
  heading_2: {
    rich_text: [{ type: 'text', text: { content: title } }],
    is_toggleable: true,
    children: [{
      object: 'block',
      type: 'bulleted_list_item',
      bulleted_list_item: {
        rich_text: [{ type: 'text', text: { content: '尚無資料' } }]
      }
    }]
  }
}));

fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children', {
  method: 'PATCH',
  headers: {
    'Authorization': 'Bearer ' + TOKEN,
    'Notion-Version': '2022-06-28',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ children })
}).then(r => r.json()).then(d => console.log('Done:', d.results?.length, 'blocks'));
"
```

### Step 4：輸出執行摘要

```
## ✅ 規劃案件建立完成

**案件名稱：** $CASE_NAME
**公司別：** $COMPANY
**Dropbox 路徑：** $BASE
**Notion 頁面：** https://www.notion.so/$PAGE_ID

### 建立的資料夾
- A 業主提供資料
- B 規劃圖面
- C 簡報資料
- D 預算報價（含：參考報價）
- E 業主合同資料
- F 供應商報價與資料（含：廠商報價）
- G 進度計畫管理

- I 其他

### 下一步
把業主提供的標案文件放入 A，自己的報價草稿放 D。
開始跑施工圖時執行 /規劃轉施工 升級資料夾結構。
```
