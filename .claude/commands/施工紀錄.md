# 施工紀錄

現場照片 → 分析照片 → 建立 Notion「案件施工紀錄」資料庫紀錄（含嵌入圖片）→ 將照片移入案件 H照片 資料夾

觸發方式：
- `/施工紀錄 資料夾路徑`
- 例1（手機上傳待處理）：`/施工紀錄 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/施工照片待處理`
- 例2（Mac，指定案件 M照片）：`/施工紀錄 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/202604-國軍左營岡山分院翔青健康管理大樓新建工程/M照片`
- 例2b（中醫診所）：`/施工紀錄 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/20251104羅東聖母G棟中醫診所建置工程/M照片`
- 例3（Mac，已有日期子資料夾）：`/施工紀錄 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/202604-國軍左營岡山分院翔青健康管理大樓新建工程/M照片/2026-05-16`
- 例4（Windows）：`/施工紀錄 D:\Dropbox\宏祐\202604-國軍左營\M照片`

**若路徑為「施工照片待處理」：**
- 用 AskUserQuestion 顯示 `宏祐/` 下所有 2026 開頭的資料夾清單，讓使用者選擇案件
- 選定後將照片移動（`fs.renameSync`）到 `[案件]/M照片/[日期]/`
- 再繼續正常流程

## 執行步驟

### Step 0：偵測平台 + 解析參數

```bash
uname -s 2>/dev/null || echo Windows
```

依平台設定：
- **Mac (Darwin)**
  - `$NODE` = `~/.nvm/versions/node/v24.14.1/bin/node`
  - `$DROPBOX_ROOT` = `/Users/tuzhenghong/Library/CloudStorage/Dropbox`
  - 取得今天日期：`date +%Y-%m-%d`
- **Windows**
  - `$NODE` = `C:\Users\deco01\nodejs\node.exe`
  - `$DROPBOX_ROOT` = `D:\Dropbox`
  - 取得今天日期：`powershell -Command "Get-Date -Format 'yyyy-MM-dd'"`

從使用者輸入取得 `$INPUT_PATH`。

判斷路徑：
- 路徑最後一段符合 `YYYY-MM-DD` 格式 → 直接用，`$DATE` 從路徑取得，`$CONTENT_NAME` 從路徑取得（若有 `_` 後綴則取之，否則為空）
- 否則視為 M照片 資料夾 → `$DATE` = 今天，待 Step 1 詢問施工內容名稱並建立子資料夾

推導：
- `$CASE_ROOT`：去掉 `M照片` 及之後路徑 → 案件根目錄
- `$CASE_NAME`：`$CASE_ROOT` 最後一層資料夾名稱（保留完整名稱含日期前綴）
- `$SHORT_NAME`：去掉前面 `YYYYMM-` 的案件名稱（用於 Notion 欄位）

列出目前目錄內容：
```bash
$NODE -e "const fs=require('fs'); console.log(fs.readdirSync('$INPUT_PATH').join('\n'));"
```

### Step 1：建立日期子資料夾並整理照片

**只有當路徑是 M照片 資料夾（非日期子資料夾）時執行。**

**1a. 詢問施工內容名稱（必做，不得跳過）**

用 **AskUserQuestion** 詢問：
- 問題：「請輸入本次施工內容名稱（將作為資料夾後綴）」
- 說明：例如「FFU軟管安裝」「天花板管路配置」「消防管佈設」
- 選項：直接輸入（Other）

取得後設定 `$CONTENT_NAME`，資料夾名稱格式為 `$DATE_$CONTENT_NAME`

**1b. 建立資料夾並移入照片**

```bash
$NODE -e "
const fs = require('fs');
const path = require('path');
const INPUT = '$INPUT_PATH';
const DATE_DIR = path.join(INPUT, '$DATE_$CONTENT_NAME');
fs.mkdirSync(DATE_DIR, { recursive: true });

const exts = new Set(['.jpg', '.jpeg', '.png', '.heic']);
for (const f of fs.readdirSync(INPUT)) {
  if (exts.has(path.extname(f).toLowerCase())) {
    fs.renameSync(path.join(INPUT, f), path.join(DATE_DIR, f));
  }
}
console.log('照片已整理至', DATE_DIR);
console.log(fs.readdirSync(DATE_DIR).join('\n'));
"
```

`$TARGET_DIR` 設為 `$INPUT_PATH/$DATE_$CONTENT_NAME`。

### Step 3：取得 Dropbox 直接嵌入連結

確認後，Claude 將 `$TARGET_DIR`、`$PHOTOS`（逗號分隔檔名）、`$DROPBOX_ROOT` 直接填入腳本執行（不依賴 shell 傳參，跨平台通用）：

```bash
$NODE -e "
(async () => {
const APP_KEY = 't1n8ea51gyluo9o';
const APP_SECRET = '94re6pu3w7da7ai';
const REFRESH_TOKEN = 'LuH8PZgPJFMAAAAAAAAAAdr6cHmLKVVJlbIMEuT134q6eRdGp7H9rh8Niq_UBsbh';
const TARGET_DIR = '$TARGET_DIR';
const DROPBOX_ROOT = '$DROPBOX_ROOT';
const DROPBOX_PATH = TARGET_DIR.replace(DROPBOX_ROOT, '').replace(/\\\\/g, '/');
const PHOTOS = '$PHOTO_LIST'.split(',').map(s => s.trim()).filter(Boolean);

async function getToken() {
  const r = await fetch('https://api.dropboxapi.com/oauth2/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({ grant_type: 'refresh_token', refresh_token: REFRESH_TOKEN, client_id: APP_KEY, client_secret: APP_SECRET })
  });
  const d = await r.json();
  if (!d.access_token) throw new Error('token 失敗: ' + JSON.stringify(d));
  return d.access_token;
}

async function getLink(token, path) {
  const r = await fetch('https://api.dropboxapi.com/2/sharing/create_shared_link_with_settings', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer ' + token, 'Content-Type': 'application/json' },
    body: JSON.stringify({ path, settings: { requested_visibility: 'public' } })
  });
  const d = await r.json();
  if (d.url) return d.url.replace('www.dropbox.com', 'dl.dropboxusercontent.com').replace('?dl=0', '').replace('&dl=0', '') + '&dl=1';
  if (d.error?.['.tag'] === 'shared_link_already_exists') {
    const r2 = await fetch('https://api.dropboxapi.com/2/sharing/list_shared_links', {
      method: 'POST',
      headers: { 'Authorization': 'Bearer ' + token, 'Content-Type': 'application/json' },
      body: JSON.stringify({ path, direct_only: true })
    });
    const url = (await r2.json()).links?.[0]?.url || '';
    return url.replace('www.dropbox.com', 'dl.dropboxusercontent.com').replace('?dl=0', '').replace('&dl=0', '') + '&dl=1';
  }
  throw new Error(JSON.stringify(d));
}

const token = await getToken();
const result = {};
for (const photo of PHOTOS) {
  try {
    result[photo] = await getLink(token, DROPBOX_PATH + '/' + photo);
    process.stderr.write('✅ ' + photo + '\n');
  } catch(e) {
    process.stderr.write('❌ ' + photo + ': ' + e.message + '\n');
    result[photo] = null;
  }
}
console.log(JSON.stringify(result, null, 2));
})();
"
```

### Step 4：建立 Notion 施工紀錄頁面

**4a. 直接查詢 Projects 資料庫取得 `$PROJECT_PAGE_ID`（勿用 `API-post-search`，中文標題搜尋不穩定）**

```bash
$NODE -e "
(async () => {
const TOKEN = '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';
const DB_ID = '3355cac1-0351-4ef4-8eb1-8b8f0bb619c3';
const KEYWORD = '$SHORT_NAME';
const r = await fetch('https://api.notion.com/v1/databases/' + DB_ID + '/query', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer ' + TOKEN, 'Content-Type': 'application/json', 'Notion-Version': '2022-06-28' },
  body: JSON.stringify({ filter: { property: '專案', title: { contains: KEYWORD } } })
});
const d = await r.json();
if (d.object === 'error') throw new Error(JSON.stringify(d));
d.results.forEach(p => console.log(p.id + ' | ' + p.properties['專案'].title[0]?.plain_text));
})();
"
```

若找到多筆，用 AskUserQuestion 讓使用者確認正確的案件。若找不到，跳過關聯（`案件/專案` 留空），並在摘要中提醒。

**4b. 用 `mcp__notion__API-post-page` 在資料庫建立新紀錄**

```json
{
  "parent": { "database_id": "69ac3178-ec22-4952-baf9-7608079fc746" },
  "icon": { "type": "emoji", "emoji": "📸" },
  "properties": {
    "紀錄標題": { "title": [{ "text": { "content": "$SHORT_NAME — $DATE 施工紀錄" } }] },
    "案件/專案": { "relation": [{ "id": "$PROJECT_PAGE_ID" }] },
    "日期": { "date": { "start": "$DATE" } },
    "工項": { "multi_select": [{ "name": "$工項" }] },
    "位置/區域": { "rich_text": [{ "text": { "content": "$位置" } }] },
    "施工內容/摘要": { "rich_text": [{ "text": { "content": "（AI 統整說明）" } }] },
    "追蹤狀態": { "status": { "name": "待確認" } },
    "天氣": { "select": { "name": "$天氣" } }
  },
  "children": []
}
```

取得回傳的 `page_id`。

**4c. 把照片加入頁面內容（用 Node.js 直接呼叫 Notion API，MCP 工具不支援 image block）**

```bash
$NODE -e "
(async () => {
const TOKEN = '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';
const PAGE_ID = '$PAGE_ID';
const photos = $PHOTOS_JSON; // [{ file, url, caption }, ...]

const children = photos.map(p => ({
  type: 'image',
  image: {
    type: 'external',
    external: { url: p.url },
    caption: [{ type: 'text', text: { content: p.caption } }]
  }
}));

// 每批最多 10 張
for (let i = 0; i < children.length; i += 10) {
  const batch = children.slice(i, i + 10);
  const r = await fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children', {
    method: 'PATCH',
    headers: { 'Authorization': 'Bearer ' + TOKEN, 'Content-Type': 'application/json', 'Notion-Version': '2022-06-28' },
    body: JSON.stringify({ children: batch })
  });
  const d = await r.json();
  if (d.object === 'error') throw new Error(JSON.stringify(d));
  console.log('✅ 插入 ' + d.results.length + ' 張（批次 ' + (i/10+1) + '）');
}
})();
"
```

> HEIC 格式 Notion 無法嵌入，改用 `bookmark` type（`{ type: 'bookmark', bookmark: { url: p.url } }`）替代。
