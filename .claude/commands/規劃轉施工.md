# 規劃轉施工

把現有的規劃案件資料夾結構（A-I）升級為施工案件結構（A-P），並同步更新 Notion 頁面。

觸發方式：
- `/規劃轉施工 資料夾路徑`
- 例：`/規劃轉施工 /Users/tuzhenghong/Library/CloudStorage/Dropbox/宏祐/202604-國軍左營岡山分院翔青健康管理大樓新建工程`

## 執行步驟

### Step 0：確認路徑與平台

```bash
uname -s 2>/dev/null || echo Windows
```

從使用者輸入取得 `$BASE`（資料夾完整路徑）。

使用 **AskUserQuestion** 詢問集團：
- 問題：「這個案件屬於哪個集團？」
- 選項：宏祐集團 / YUSHI

依回答設定 `$集團`。

先列出現有資料夾確認存在：
```bash
ls "$BASE"
```

**執行前提醒使用者：此操作會直接改動資料夾結構，請先確認 Dropbox 已同步完成。**

---

### Step 1：重新命名現有資料夾

依序執行（順序重要，避免衝突）：

```bash
BASE="$DROPBOX_PATH"

# I其他 先改名避免後續衝突（新 I = 會議記錄）
[ -d "${BASE}/I其他" ] && mv "${BASE}/I其他" "${BASE}/Z其他"

# E → B
[ -d "${BASE}/E業主合同資料" ] && mv "${BASE}/E業主合同資料" "${BASE}/B業主提供合同資料"

# C → E（C已搬走所以 E 這個字母現在是空的）
[ -d "${BASE}/C簡報資料" ] && mv "${BASE}/C簡報資料" "${BASE}/E簡報資料"

# F → J
[ -d "${BASE}/F供應商報價與資料" ] && mv "${BASE}/F供應商報價與資料" "${BASE}/J供應商資料"

# B → K
[ -d "${BASE}/B規劃圖面" ] && mv "${BASE}/B規劃圖面" "${BASE}/K施工圖面"

# H → M
[ -d "${BASE}/H照片" ] && mv "${BASE}/H照片" "${BASE}/M照片"
```

### Step 2：建立 G 管理資料(文書) 並搬移進度計畫

```bash
# 建立 G 管理資料(文書) 及所有子資料夾
mkdir -p "${BASE}/G管理資料(文書)/收發公文/來文"
mkdir -p "${BASE}/G管理資料(文書)/收發公文/發文"
mkdir -p "${BASE}/G管理資料(文書)/室裝圖審資料/第一版"
mkdir -p "${BASE}/G管理資料(文書)/室裝圖審資料/第二版"
mkdir -p "${BASE}/G管理資料(文書)/室裝竣工資料"
mkdir -p "${BASE}/G管理資料(文書)/材料證明"
mkdir -p "${BASE}/G管理資料(文書)/保固書"
mkdir -p "${BASE}/G管理資料(文書)/預定進度"

# 把 G進度計畫管理 的內容搬入 G管理資料(文書)/預定進度
if [ -d "${BASE}/G進度計畫管理" ]; then
  for f in "${BASE}/G進度計畫管理/"*; do
    fname=$(basename "$f")
    [ "$fname" = ".DS_Store" ] && continue
    mv "$f" "${BASE}/G管理資料(文書)/預定進度/"
  done
  rmdir "${BASE}/G進度計畫管理" 2>/dev/null || true
fi
```

### Step 4：更新 Notion 頁面

**4a. 搜尋對應的 Notion 頁面（依資料夾名稱關鍵字）：**

使用 `mcp__notion__API-post-search`，query 為案件名稱關鍵字，找到對應 page_id。

**4b. 更新狀態與集團：**

使用 `mcp__notion__API-patch-page`：
```json
{
  "page_id": "$PAGE_ID",
  "properties": {
    "狀態": { "status": { "name": "工程進行中" } },
    "集團": { "select": { "name": "$集團" } }
  }
}
```

> Notion Projects 資料庫可用狀態（依流程順序）：
> 規劃中 → 工程進行中 → 審核中 → 工程驗收中 → 工程完成請款中 → 專案完成
> 其他：延遲、未承接

**4c. 清除現有頁面內容，重建 A-P 折疊標題：**

先取得現有 block 清單並刪除：
```bash
~/.nvm/versions/node/v24.14.1/bin/node -e "
const TOKEN = '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';
const PAGE_ID = '$PAGE_ID';

// 取得所有 blocks
const listResp = await fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children?page_size=100', {
  headers: { 'Authorization': 'Bearer ' + TOKEN, 'Notion-Version': '2022-06-28' }
});
const { results } = await listResp.json();

// 刪除所有現有 blocks
for (const block of results) {
  await fetch('https://api.notion.com/v1/blocks/' + block.id, {
    method: 'DELETE',
    headers: { 'Authorization': 'Bearer ' + TOKEN, 'Notion-Version': '2022-06-28' }
  });
}
console.log('已刪除', results.length, '個舊區塊');
"
```

建立 A-P 新折疊標題：
```bash
~/.nvm/versions/node/v24.14.1/bin/node -e "
const TOKEN = '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';
const PAGE_ID = '$PAGE_ID';

const sections = [
  'A 業主提供資料',
  'B 業主提供合同資料',
  'C 請款資料',
  'D 預算報價',
  'E 簡報資料',
  'F 職安資料',
  'G 管理資料(文書)',
  'H 送審資料',
  'I 會議記錄',
  'J 供應商資料',
  'K 施工圖面',
  'L 日報',
  'M 照片',
  'N 廠商已發包資料',
  'O 自主檢查表',
  'P 請購單',
  'Z 其他',
];

const children = sections.map(title => ({
  object: 'block',
  type: 'heading_2',
  heading_2: {
    rich_text: [{ type: 'text', text: { content: title } }],
    is_toggleable: true,
    children: [{
      object: 'block',
      type: 'bulleted_list_item',
      bulleted_list_item: {
        rich_text: [{ type: 'text', text: { content: '尚無資料' } }]
      }
    }]
  }
}));

// Notion API 每次最多 100 個 children，分批送出
for (let i = 0; i < children.length; i += 10) {
  await fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children', {
    method: 'PATCH',
    headers: {
      'Authorization': 'Bearer ' + TOKEN,
      'Notion-Version': '2022-06-28',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ children: children.slice(i, i + 10) })
  });
}
console.log('A-P 折疊標題建立完成');
"
```
