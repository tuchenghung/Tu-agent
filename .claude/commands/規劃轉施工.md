## 執行步驟

### Step 0：確認路徑與平台

```bash
uname -s 2>/dev/null || echo Windows
```

從使用者輸入取得 `$BASE`（資料夾完整路徑）。

依平台設定：
- **Mac (Darwin)**：`$NODE` = `~/.nvm/versions/node/v24.14.1/bin/node`
- **Windows**：`$NODE` = `C:\Users\deco01\nodejs\node.exe`

使用 **AskUserQuestion** 詢問集團：
- 問題：「這個案件屬於哪個集團？」
- 選項：宏祐集團 / YUSHI

依回答設定 `$集團`。

列出現有資料夾確認：

```bash
$NODE -e "
const fs = require('fs');
console.log(fs.readdirSync('$BASE').sort().join('\n'));
"
```

**執行前提醒使用者：此操作會直接改動資料夾結構，請先確認 Dropbox 已同步完成。**

### Step 1：重新命名現有資料夾

使用 Node.js 依序執行（順序重要，避免衝突）：

```bash
$NODE -e "
const fs = require('fs');
const path = require('path');
const BASE = '$BASE';

function mv(src, dest) {
  const srcPath = path.join(BASE, src);
  const destPath = path.join(BASE, dest);
  if (fs.existsSync(srcPath)) {
    fs.renameSync(srcPath, destPath);
    console.log('✅', src, '→', dest);
  }
}

mv('I其他', 'Z其他');           // 先搬走避免衝突
mv('E業主合同資料', 'B業主提供合同資料');
mv('C簡報資料', 'E簡報資料');
mv('F供應商報價與資料', 'J供應商資料');
mv('B規劃圖面', 'K施工圖面');
mv('H照片', 'M照片');
"
```

### Step 2：建立 G 管理資料(文書) 並搬移進度計畫

```bash
$NODE -e "
const fs = require('fs');
const path = require('path');
const BASE = '$BASE';

// 建立 G 管理資料(文書) 及所有子資料夾
const gDirs = [
  'G管理資料(文書)/收發公文/來文',
  'G管理資料(文書)/收發公文/發文',
  'G管理資料(文書)/室裝圖審資料/第一版',
  'G管理資料(文書)/室裝圖審資料/第二版',
  'G管理資料(文書)/室裝竣工資料',
  'G管理資料(文書)/材料證明',
  'G管理資料(文書)/保固書',
  'G管理資料(文書)/預定進度',
];
for (const d of gDirs) fs.mkdirSync(path.join(BASE, d), { recursive: true });

// 把 G進度計畫管理 內容搬入 G管理資料(文書)/預定進度
const oldG = path.join(BASE, 'G進度計畫管理');
if (fs.existsSync(oldG)) {
  for (const f of fs.readdirSync(oldG)) {
    if (f === '.DS_Store' || f === 'Thumbs.db') continue;
    fs.renameSync(path.join(oldG, f), path.join(BASE, 'G管理資料(文書)/預定進度', f));
  }
  try { fs.rmdirSync(oldG); } catch(e) {}
  console.log('✅ G進度計畫管理 → G管理資料(文書)/預定進度');
}
console.log('✅ G 管理資料(文書) 建立完成');
"
```

### Step 4：更新 Notion 頁面

**4a. 搜尋對應的 Notion 頁面（依資料夾名稱關鍵字）：**

使用 `mcp__notion__API-post-search`，query 為案件名稱關鍵字，找到對應 page_id。

**4b. 更新狀態與集團：**

使用 `mcp__notion__API-patch-page`：
```json
{
  "page_id": "$PAGE_ID",
  "properties": {
    "狀態": { "status": { "name": "工程進行中" } },
    "集團": { "select": { "name": "$集團" } }
  }
}
```

> Notion Projects 資料庫可用狀態（依流程順序）：
> 規劃中 → 工程進行中 → 審核中 → 工程驗收中 → 工程完成請款中 → 專案完成
> 其他：延遲、未承接

**4c. 清除現有頁面內容，重建 A-P 折疊標題：**

```bash
$NODE -e "
const TOKEN = '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';
const PAGE_ID = '$PAGE_ID';

const listResp = await fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children?page_size=100', {
  headers: { 'Authorization': 'Bearer ' + TOKEN, 'Notion-Version': '2022-06-28' }
});
const { results } = await listResp.json();
for (const block of results) {
  await fetch('https://api.notion.com/v1/blocks/' + block.id, {
    method: 'DELETE',
    headers: { 'Authorization': 'Bearer ' + TOKEN, 'Notion-Version': '2022-06-28' }
  });
}
console.log('已刪除', results.length, '個舊區塊');

const sections = [
  'A 業主提供資料', 'B 業主提供合同資料', 'C 請款資料', 'D 預算報價',
  'E 簡報資料', 'F 職安資料', 'G 管理資料(文書)', 'H 送審資料',
  'I 會議記錄', 'J 供應商資料', 'K 施工圖面', 'L 日報',
  'M 照片', 'N 廠商已發包資料', 'O 自主檢查表', 'P 請購單', 'Z 其他',
];
const children = sections.map(title => ({
  object: 'block', type: 'heading_2',
  heading_2: {
    rich_text: [{ type: 'text', text: { content: title } }],
    is_toggleable: true,
    children: [{ object: 'block', type: 'bulleted_list_item',
      bulleted_list_item: { rich_text: [{ type: 'text', text: { content: '尚無資料' } }] }
    }]
  }
}));
for (let i = 0; i < children.length; i += 10) {
  await fetch('https://api.notion.com/v1/blocks/' + PAGE_ID + '/children', {
    method: 'PATCH',
    headers: { 'Authorization': 'Bearer ' + TOKEN, 'Notion-Version': '2022-06-28', 'Content-Type': 'application/json' },
    body: JSON.stringify({ children: children.slice(i, i + 10) })
  });
}
console.log('A-P 折疊標題建立完成');
```
