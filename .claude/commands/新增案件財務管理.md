# 新增案件財務管理

在「案件財務管理」資料庫新增一筆記錄，並自動連結 Projects 對應頁面。

觸發方式：
- `/新增案件財務管理 案件名稱`
- 例：`/新增案件財務管理 西湖辦公室新增VRV空調工程`

---

## 執行步驟

### Step 0：取得參數

從使用者輸入取得 `$CASE_NAME`（案件名稱關鍵字）。

---

### Step 1：搜尋 Projects 對應頁面

使用 `mcp__notion__API-post-search`，query 為 `$CASE_NAME`，filter 為 page，找到對應的 `$PROJECT_PAGE_ID`。

若找到多筆，列出讓使用者確認選哪一筆。
若找不到，提示使用者確認案件名稱是否正確。

---

### Step 2：詢問財務資訊

使用 **AskUserQuestion** 詢問（可同時問）：
- 問題 1：「承攬金額是多少？（含稅）」
  - 選項：請使用者輸入數字（Other 輸入）
- 問題 2：「開始日期？」
  - 選項：今天 / 其他（Other 輸入 YYYY-MM-DD）

取得 `$承攬金額`（數字）、`$開始日期`（YYYY-MM-DD）。

---

### Step 3：建立案件財務管理記錄

使用 `mcp__notion__API-post-page`：

```json
{
  "parent": { "database_id": "2f97aebd-089f-80f7-9607-df6dc41ab3bd" },
  "properties": {
    "專案名稱": { "title": [{ "text": { "content": "$CASE_NAME" } }] },
    "承攬金額": { "number": $承攬金額 },
    "開始日期": { "date": { "start": "$開始日期" } },
    "專案管理": { "relation": [{ "id": "$PROJECT_PAGE_ID" }] },
    "狀態": { "status": { "name": "進行中" } }
  }
}
```

---

### Step 4：輸出執行摘要

```
## ✅ 案件財務管理記錄建立完成

**案件：** $CASE_NAME
**承攬金額：** $承攬金額（含稅）
**稅金：** $稅金（自動計算）
**開始日期：** $開始日期
**連結專案：** Projects 已連結

下一步：進入發包項目填入各廠商發包金額，毛利與毛利率將自動更新。
```
