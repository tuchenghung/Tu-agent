# 政府標案投標 SOP

> 建立日期：2026-05-23
> 參考案例：202605-市醫和平院區醫療大樓8樓婦兒科病房整修
> 適用範圍：裝修工程類政府採購標案

---

## 整體流程概覽

```
Phase 1 取得資料 → Phase 2 可行性評估 → Phase 3 成本估算 → Phase 4 技術標準備 → Phase 5 投標送件 → Phase 6 開標後處理
```

---

## Phase 1｜取得招標文件（D-14 以前）

- [ ] 從政府電子採購網下載公告
- [ ] 電子領標（繳納系統使用費 20 元）
- [ ] 下載文件包：公告、投標須知、圖說、標單、規範、契約
- [ ] 建立本案專案資料夾（路徑：`宏祐/YYYYMM-案名/`）
- [ ] 在 `Tu-agent/100_Todo/projects/` 建立追蹤資料夾

**注意：** 第二次招標文件若與第一次相同，可沿用已下載文件，但截止日要自行修正。

---

## Phase 2｜可行性評估（D-12 以前）

### 2.1 確認廠商資格
- [ ] 確認本公司資格符合（如：綜合營造業乙等 / 室內裝修業 E801060）
- [ ] 確認無拒絕往來紀錄、近 3 年無退票

### 2.2 評估投標條件
| 項目 | 評估重點 |
|------|---------|
| 決標方式 | 最有利標（技術+價格）vs 最低標（只比價） |
| 押標金 | 金額是否備妥，有效期是否足夠 |
| 工期 | 能否配合現有工地排程 |
| 工程性質 | 是否有相關施工能力與實績 |
| 競爭狀況 | 是否為第二次招標（競爭較少）|

### 2.3 決策結論
- [ ] **投** / **不投** / **待觀察**

---

## Phase 3｜成本估算（D-10 至 D-5）

### 3.1 標單解析
- [ ] 將 Excel 標單轉換，列出所有工項
- [ ] 標記：已有廠商報價 / 需自估單價

### 3.2 廠商詢價
- [ ] 列出需詢價工種清單
- [ ] 發出詢價（電話/Email），設定回覆截止日（D-3）
- [ ] 追蹤未回覆廠商

### 3.3 缺漏單價自估
針對無廠商報價的工項，參考：
- 近期同類型工程實際成本
- 臺北市工程採購單價資料庫
- 公共工程委員會物價指數

### 3.4 成本彙整試算
| 項目 | 計算方式 |
|------|---------|
| 直接工程費 | 各工項小計加總 |
| 管理費 | 直接費 × __% |
| 利潤 | 直接費 × __% |
| 營業稅 | 含稅總額 = 以上合計 × 1.05 |
| **報價合計** | |
| 與預算比較 | 報價 / 預算 × 100% |

## Phase 4｜技術標準備（最有利標適用）（D-8 至 D-3）

- [ ] 施工計劃書（含施工步驟、時程、分區管制）
- [ ] 品質管理計劃
- [ ] 人員資歷（專任工程師、工地主任）
- [ ] 類似工程實績（近 5 年，金額、業主、內容）
- [ ] 環境保護與感染管控計劃（醫院工程必備）
- [ ] 廠商資格文件彙整

**醫院工程特別注意：**
- 施工動線不得影響病患及醫護動線
- 需有負壓隔離/塵埃管控計劃
- 施工時段可能受限制（夜間/假日）

---

## Phase 5｜投標送件（D-2 至 D-1）

### 5.1 文件確認清單
- [ ] 投標封套（填寫截止收件時間、開標時間）
- [ ] 廠商資格文件（稅籍證明、信用證明、執照）
- [ ] 押標金（支票/保單，抬頭確認）
- [ ] 報價標單（蓋章）
- [ ] 技術標文件（最有利標）

### 5.2 送件方式
- 書面投標：掛號寄件或親送至指定地點
- 截止前送達（逾時判定不合格）

---

## Phase 6｜開標後處理

### 得標
- [ ] 確認決標金額
- [ ] 準備履約保證金（通常為合約金額 10%）
- [ ] 開工通知前提交施工計劃書
- [ ] 建立施工記錄追蹤資料夾
- [ ] 將本案移至 `宏祐/執行中/`

### 未得標
- [ ] 記錄決標金額、得標廠商、得標價格
- [ ] 分析輸標原因（價格差距？技術標分數？）
- [ ] 更新 `400_Knowledge/工程/競標分析/` 供下次參考
- [ ] 將本案移至 `100_Todo/archive/`

## 常用參考資料

| 資源 | 用途 |
|------|------|
| 政府電子採購網 | 標案查詢、領標、投標 |

| 臺北市工務局 | 臺北市採購案件 |
| 建築物室內裝修管理辦法 | 資格法規依據 |
