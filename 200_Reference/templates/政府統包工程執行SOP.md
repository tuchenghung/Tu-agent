# 政府統包（設計施工合一）工程執行 SOP

> 建立日期：2026-07-01
> 參考案例：202511-中華郵政臺北郵件處理中心整修統包工程（標案編號 A114012-1，宏宇智能營造得標）
> 適用範圍：政府「統包」類工程（決標後由廠商負責基本設計/實施設計+施工），與一般裝修分包案不同，履約期程橫跨「設計審查」與「施工」兩大階段
> 前置作業（招標公告→投標→開標）請先參考 `200_Reference/templates/政府標案投標SOP.md` Phase 1-5，本文件從「服務建議書準備」接續到「保固」

---

## 整體流程概覽

```
Phase 0 服務建議書準備 → Phase 1-5 投標送件（同一般SOP）→ Phase 6 決標後行政 →
Phase 7 設計審查期 → Phase 8 施工期 → Phase 9 驗收 → Phase 10 請款 → Phase 11 保固
```

統包案的關鍵特性：**決標≠開工**。中華郵政案決標（2026-02-02）到預定開工（2026-12-01）之間有將近 10 個月的「設計審查期」，這段時間要完成基本設計定稿、三書送審核定、各項執行計畫核定，才能真正動工。排程規劃務必把這段時間算進去，不要誤以為決標後馬上開工。

## 標準案件資料夾結構

統包案沿用公司「施工中案件」標準 A-Z 結構（見 `.claude/commands/規劃轉施工.md`，由 `/規劃轉施工` skill 自動改組建立），**不是另一套獨立命名**。政府統包案特有的文件（基本設計報告書、三書、統包執行計畫書、履約保證金、拆除計畫書），全部歸在既有的 **H送審資料** 與 **G管理資料(文書)** 底下，不新增頂層字母：

| **H送審資料** | 送審機關/PCM 核定的文件 | **基本設計報告書**（第一版→定稿版）、**三書**（整體施工計畫/整體品質計畫/職業安全衛生計畫）、**拆除計畫書** |

## Phase 0｜服務建議書準備（最有利標特有）

最有利標決標前，機關通常會安排廠商簡報評選。統包案金額大（本案 9.25 億），投標資格文件本身就很龐大。

- [ ] 準備投標資格文件（公司/商業登記、稅籍證明、工商團體證明、相關專業登記證書、信用證明）
- [ ] 準備各項技師證照
- [ ] 準備服務建議書（技術建議、執行團隊、類似實績）
- [ ] 準備簡報資料，配合機關通知安排評選簡報
- [ ] 標單價目表核算、議約（若進入議價程序）

**中華郵政案時間軸**：
- 2025-11-06 第一次領標
- 2025-12-08 第二次公告
- 2025-12-12 更正公告：①評選須知五、(三)服務建議書版面規定（A4/A3彈性化）②投標須知第20/21條新增釋疑期限、第27開標時間調整為12/19 10:00、第81截標時間調整為12/18 17:00 ③抽換投標須知/評選須知電子檔
- 2025-12-18 17:00 截止投標
- 2025-12-19 10:00 開標

**實務技巧**：機關每次發「更正公告」，領標文件資料夾裡都會附一份 `更正對照表.pdf`（新舊條文並排比對），直接讀這份就能精確掌握改了什麼，不用自己土法比對兩份公告全文。

## Phase 6｜決標後行政（決標 → 簽約）

決標後不代表案子結束，還有一段行政作業要跑：

- [ ] 決標公告確認（金額、廠商名稱）
- [ ] 提交統包廠商承諾書
- [ ] 履約保證金/保險安排（工程險、雇主意外責任險）
- [ ] 契約用印、正式簽約
- [ ] 廉政相關規定告知書簽署（各協力廠商、建築師事務所都要簽）

**中華郵政案時間軸**：
- 2026-02-02 決標公告
- 2026-01-20 統包廠商承諾書簽署
- 2026-02-10 契約簽訂
- 2026-04-22 工程保險批改單

## Phase 7｜設計審查期（統包案最容易低估工期的階段）

這是統包案跟一般裝修分包案最大的差異：決標後不能馬上開工，要先完成設計定稿與各項計畫書核定。

- [ ] 業主/專案管理顧問（PCM）現勘與資料提供（CAD、規範、範本）→ 存 A業主提供資料
- [ ] 基本設計報告書撰寫（第一版 → 修正 → 定稿版）→ 存 H送審資料/基本設計報告書
- [ ] 施工圖面持續發展（依業主/專業技師意見修正版次）→ 存 K施工圖面
- [ ] 統包工程計畫書撰寫與核定（可能歷經多版次）→ 存 G管理資料(文書)/統包執行計畫書
- [ ] 簽證執行計畫書核定 → 存 G管理資料(文書)/統包執行計畫書
- [ ] 受雇勞工名冊核定 → 存 G管理資料(文書)/統包執行計畫書
- [ ] 三書提送核定（整體施工計畫、整體品質計畫、職業安全衛生計畫）→ 存 H送審資料/三書
- [ ] 送審時間管制表建立與定期更新（追蹤每項審查進度）→ 存 G管理資料(文書)/預定進度

**中華郵政案時間軸**（決標後約 10 個月的設計審查期）：
- 2026-01-23 現勘
- 2026-01-21 送審時間管制表 H1 版
- 2026-03-06 簽證執行計畫書核定
- 2026-03-12 受雇勞工名冊核定
- 2026-03-19 起 建築師陸續提供設計資料（磁磚範圍、廁所範圍等細部）
- 2026-04-20 送審時間管制表 H2 版
- 2026-06-17 三書提送（整體施工計畫、整體品質計畫、職業安全衛生計畫）
- 預定 2026-12-01 開工（設計審查期約 10 個月）

**契約規定的精確天數（統包案契約第7條通用規則，排未來案子時程時直接套用）**：
| 項目 | 期限 |
|---|---|
| 統包工程執行計畫書、簽證執行計畫、受僱勞工名冊等 | 決標次日起 30 日內；審查意見 10 日內修正 |
| 基本設計成果報告書及圖說 | 決標次日起 75 日內；審查意見 14 日內修正 |
| 細部設計成果報告書及圖說 | 基本設計核定次日起 90 日內；審查意見 14 日內修正 |
| 拆除計畫書 | 基本設計核定次日起 30 日內；審查意見 7 日內修正 |
| 交通影響評估審議＋施工中消防防護計畫審議申請 | 基本設計核定日起 14 日內 |
| 變更使用執照併同室內裝修施工許可申請 | 基本設計核定日起 14 日內 |
| 三書（整體施工/品質/職安衛計畫） | 申請變更使用執照日起 30 日內 |
| 竣工申報 | 取得變更使照函文核發日起 480 日曆天內 |
| 一般送審文件（未另訂期限者） | 7 日內改正重送 |

**設計費六期給付**（依上述里程碑核定後撥付，比例：5%→20%→40%→20%→10%→尾款）：①統包工程執行計畫書核定 ②基本設計核定 ③細部設計核定 ④變更使照+室裝許可+三書核定 ⑤整體進度達60% ⑥完工驗收合格。

**注意**：排程規劃時，這段時間要當作一個獨立的「不可壓縮」工期區塊，不要跟施工期混算。詳細技術規格摘要見 `400_Knowledge/工程/工法踩坑/2026-07-01_中華郵政臺北郵件處理中心統包工程_技術規格摘要.md`。

## Phase 8｜施工期

- [ ] 開工通知、開工報告提交
- [ ] 進度計畫執行與追蹤（對照 G管理資料(文書)/預定進度）
- [ ] 施工進度照片留存（依日期建資料夾，存 M照片）
- [ ] 收發文管理（G管理資料(文書)/收發公文，區分業主/專管往來）
- [ ] 拆除計畫執行（依 H送審資料/拆除計畫書）
- [ ] 每日施工日報留存（存 L日報）
- [ ] 變更設計/追加減簽證處理（存 R變更設計）

**中華郵政案**：預定開工 2026-12-01，履約期限 480 日曆天（約 16 個月），結束日 2028-04-30。（此階段待實際開工後補充）

## Phase 9｜驗收（待補）

- [ ] 初驗申請
- [ ] 缺失改善
- [ ] 正式驗收
- [ ] 驗收合格證明取得（存 Q驗收單）
- [ ] 竣工資料整理（存 S竣工用、G管理資料(文書)/室裝竣工資料）

## Phase 10｜請款（待補）

- [ ] 依契約付款條件申請估驗款（存 C請款資料）
- [ ] 物價指數調整款計算（本案：總指數漲跌幅調整 2.5%）
- [ ] 尾款申請

## Phase 11｜保固（待補）

- [ ] 保固期限確認
- [ ] 保固金/保固保證金處理
- [ ] 保固期間缺失處理紀錄（存 G管理資料(文書)/保固書）
