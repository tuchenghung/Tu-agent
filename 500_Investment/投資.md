## 投資策略架構（長期固定，非每次重新決策）

> 確立時間：2026-07-09｜使用者現年 42 歲

| 項目 | 內容 |
|------|------|
| 全組合目標配置 | 台股 50% : 美股 50% |
| 美股年度定期投入 | 固定 $4,000 美金/年，投入至 65 歲（尚餘 ~23 年） |
| 美股 ETF 底倉比重 | VTI 30% / VGK 25% / VPL 15% / VWO 10% / VGIT 10% / BWX 10% |
| 平衡頻率 | 每年檢視一次 |
| 台股超配觸發 | 台股佔全組合明顯 >50% 時，比照 [[2026-07-09_台股減碼轉美股]] 做法等比例減碼 |
| **台股減碼資金去向** | **併入美股再平衡機制，用「目標權重缺口法」跟年度定期投入合併計算，不單獨切一批買** |
| 下單股數限制 | 只能整股，用四捨五入至最近整股分配，剩餘零頭金額留到下次投入累加 |

**再平衡計算方法（目標權重缺口法）**：
1. 新總值 = 現有六檔ETF總值 + 本次新投入金額
2. 各檔目標金額 = 新總值 × 目標比重
3. 各檔應買金額 = 目標金額 − 現值（若為負表示超配，本次不買該檔，缺口由其餘檔案分攤）
4. 應買金額 ÷ 現價 → 四捨五入至整股

> 只是先抓一個參考上限，實際退休時不一定照這個數字提領（熊市可少領、平常可多留），每年平衡時可重新估算更新。

| 風險提醒 | 4.15%實質報酬 vs 4%提領僅0.15pp緩衝，撐不住報酬序列風險（例如退休初期遇熊市），台股史上最慘單年-61.03%（見03壓力測試工作表），建議實際提領抓3%-3.5%更務實 |
