# 500_Investment 投資記錄系統

## 結構說明

```
500_Investment/
├── 持倉快照/        ← 每月截圖日存一份，格式 YYYY-MM-DD.md
├── 個股/            ← 每檔股票一個 .md，存成本/停損/研究連結
├── 風險管理/        ← 停損追蹤、部位集中度
└── 決策日誌/        ← 每次買賣的理由與事後檢討
```

## 使用流程

1. **每週** 更新 `個股/` 裡的現價欄位
2. **每月底** 新建一份 `持倉快照/YYYY-MM-DD.md`
3. **每次買賣** 在 `決策日誌/` 新增一筆
4. **個股研究** 放 Notion → 個股研究庫（不含金額）

## Notion 對應

| Obsidian（數字/私密） | Notion（分析/研究） |
|---------------------|-------------------|
| 個股成本、損益 | 買進邏輯、目標價、基本面 |
| 停損設定 | 產業研究、新聞追蹤 |
| 決策日誌 | 決策日誌（不含金額版） |
